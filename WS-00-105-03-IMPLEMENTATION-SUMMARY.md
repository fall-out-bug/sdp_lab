## Key Features Implemented

### 1. Naming Style Detection Algorithm
The `detectNamingStyle()` function uses sophisticated pattern matching:
- **snake_case**: Contains underscores, all lowercase
- **camelCase**: Starts lowercase, contains uppercase letters
- **kebab-case**: Contains hyphens, all lowercase
- **PascalCase**: Starts uppercase, contains lowercase letters
- **unknown**: Doesn't match any pattern or is hidden/private

The detector requires at least 5% of directories (minimum 2) to use the same style before reporting it, reducing false positives.

### 2. Enhanced Spec Detection
Improved docker-compose pattern matching to support variant files:
- `docker-compose.yml`
- `docker-compose.yaml`
- `docker-compose.dev.yml` (now detected)
- `docker-compose.prod.yml` (now detected)
- Any `docker-compose*.yml` or `docker-compose*.yaml` variant
