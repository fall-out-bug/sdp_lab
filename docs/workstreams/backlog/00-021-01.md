# WS-021-01: UP-002 multi-role dependency gating

Feature: FR-009 (sdp_dev-986)
Priority: P2
Effort: 3d
Dependencies: FR-002 (AgentRun CRD)

## Goal

Implement DAG-like dependency semantics in operator: analyst+coder run in parallel, reviewer waits for both. **Fork-first:** реализуем в форке kubeopencode, не ждём upstream UP-002.

## Scope

1. **Dependency contract**: Define Task dependency spec (e.g. `dependsOn: [task-a, task-b]`) в форке.
2. **Fork-first**: Реализовать в форке; UP-002 PR в upstream — опционально.
3. **Adapter integration**: AgentRunReconciler creates worker Tasks with dependency annotations; reviewer Task depends on analyst+coder.
4. **Orchestration model**: Matches [MULTI_ROLE_OPERATOR_ORCHESTRATION.md](../../MULTI_ROLE_OPERATOR_ORCHESTRATION.md):
   - analyst + coder in parallel
   - reviewer after both complete
   - mediator-based envelope format for inter-role context

## Design (from MULTI_ROLE_OPERATOR_ORCHESTRATION)

```
Orchestrator → analyst Task (parallel)
            → coder Task  (parallel)
            → wait both terminal
            → reviewer Task (depends on analyst, coder)
            → persist run trace
```
