# 00-150-08: Homebrew formula dry run

Feature: F150 (Product Layering And Release Readiness)

Design reference: [2026-04-27-f150-product-layering-release-readiness-design.md](../../plans/2026-04-27-f150-product-layering-release-readiness-design.md)

## Goal

Prepare and exercise a Homebrew formula path without publishing a tap. The formula is a rehearsal artifact for the selected stable release surface.

## Beads

- sdplab-p4hj (F150-08: prepare Homebrew formula dry run)

## Scope Files

- formula file or draft under the agreed repo path
- `.goreleaser.yml`
- `.github/workflows/release.yml`
- `scripts/check-release-surface.sh`
- `README.md`
- release-surface docs

## Acceptance Criteria

- [ ] Formula installs the selected stable binary surface locally.
- [ ] Formula test verifies at least `sdp --help` and one read-only command or version check.
- [ ] Formula does not expose lab-only binaries as product promises.
- [ ] Dry-run evidence is recorded.
- [ ] Publishing to a tap remains out of scope until explicit approval.

## Out of Scope

- Publishing a Homebrew tap.
- Tagging a release.
- Installing every lab binary.
