# 00-117-05: Real-Corpus UX Acceptance Harness

Feature: F117 (StratAudit — claim-centric trace explorer and tabbed analyst report)

## Goal

Защитить `F117` от отката в synthetic-demo UX: зафиксировать реальные
acceptance rules для tabs, correspondence, zero-trace gap waterfall и language discipline.

## Beads

- sdplab-0c3z

## Scope Files

- `internal/strataudit/ingest_e2e_test.go` — realistic corpus shape acceptance
- `internal/strataudit/pipeline_test.go` — tab/gap/correspondence invariants
- `internal/strataudit/report/json_test.go` — contract assertions for trace graph and document views
- `internal/strataudit/report/html_test.go` — UX/read-model smoke assertions
- `internal/strataudit/testdata/` — minimized reproducible fixture

## Acceptance Criteria

- [ ] regression падает, если report теряет один из обязательных tabs
- [ ] regression падает, если document correspondence исчезает или становится не explainable
- [ ] regression падает, если zero-trace run не даёт gap waterfall
- [ ] regression падает, если основной report снова стартует с compare/debug surface
- [ ] regression падает, если chrome отчёта смешивает русский и английский без данных из source corpus

## Out of Scope

- Пиксель-перфект snapshot testing
- Публикация приватного корпуса в репозиторий
- Performance benchmarking

## Implementation Notes

- `WS-05` проверяет не “красиво ли”, а “объясняет ли отчёт состояние traceability без ручной археологии”.
