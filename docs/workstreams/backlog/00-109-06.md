# 00-109-06: Report JSON v2 Contract

Feature: F109 (StratAudit v2 — evidence-backed report redesign)

## Goal

Сделать `report.v2.json` главным продуктовым контрактом StratAudit, чтобы HTML
стал потребителем стабильной модели, а не местом, где заново собирается истина.

## Beads

- sdplab-id5

## Scope Files

- `internal/strataudit/report/json.go` — JSON v2 DTO и сериализация
- `internal/strataudit/report_builder.go` — сборка полного v2 contract
- `internal/strataudit/pipeline.go` — запись JSON v2 как официального output
- `internal/strataudit/report/json_test.go` — golden/shape tests для v2 contract
- `cmd/sdp-strataudit/main.go` — CLI wiring для нового report output

## Acceptance Criteria

- [ ] `report.v2.json` имеет schema version и top-level блоки для scope, trust, corpus quality, documents, sections, entities, traces, findings, coverage
- [ ] JSON v2 можно анализировать офлайн без прямого доступа к SQLite
- [ ] provenance, trust grade и coverage breakdown не теряются при экспорте
- [ ] HTML generator может потреблять только JSON v2, без обхода в store structs
- [ ] golden tests фиксируют shape contract и ловят регрессии полей

## Out of Scope

- Публичный JSON Schema в `sdp/`
- Web API поверх JSON v2
- Cross-run compare format

## Implementation Notes

- WS-06 завершает data contract. До него нельзя считать HTML redesign продуктово завершённым.
