# 00-166-03: guarded modelgateway wrapper and audit/cost evidence

Feature: F166 (sdplab-mp83)

## Goal

Wrap the non-streaming `modelgateway.Provider` call path with `llmguard` so input
checks run before provider calls, output checks run on raw assistant responses, and
redacted audit/cost evidence is written before releasing responses.

## Beads

- sdplab-km30

## Scope Files

- `internal/llmguard/`
- `internal/modelgateway/provider.go` (read contract)
- `internal/modelgateway/contract.go` (read contract)
- `docs/plans/2026-05-03-f166-runtime-llm-guard-gateway-design.md`

## Acceptance Criteria

- [x] Gateway wrapper accepts an existing non-streaming `modelgateway.Provider` without changing provider implementations.
- [x] `internal/llmguard` may import `internal/modelgateway`; `internal/modelgateway` must not import `llmguard`, avoiding circular dependencies.
- [x] Input-block verdict prevents provider invocation and writes a redacted audit event.
- [x] Redact-then-allow policy sends provider-safe untyped placeholders when configured.
- [x] Provider failures after input pass return `provider_error_after_input_pass` and record redacted audit metadata.
- [x] Provider error text is scanned/redacted before audit and stored only as a short redacted excerpt plus coarse error class.
- [x] Output guard scans raw assistant response before response release and blocks generated secrets.
- [x] Audit sink implements `WriteGuardEvent(ctx context.Context, event GuardEvent) error`, is synchronous and fail-closed by default, and `audit_failed` returns `event_id` and `correlation_id`.
- [x] `GuardEvent` JSONL schema matches the design fields for provenance, verdict, findings, redaction summary, token usage, cost status, estimated cost, and provider error class/excerpt.
- [x] Policy is supplied as a Go struct or constructor argument; no env/config/remote policy loader is added.
- [x] Cost estimator records `unknown_pricing` when model pricing is absent and never reports missing pricing as zero cost.
- [x] Fake-provider tests cover clean, input blocked, redacted allowed, output blocked, provider error, audit failure, and cost unknown paths.
- [x] Serialized audit-event tests assert raw corpus secrets are absent.

## Out of Scope

- Streaming provider support.
- Live provider calls.
- Direct Beads writes.
- Signed/queryable audit storage.
- Global adoption by all existing call sites.
