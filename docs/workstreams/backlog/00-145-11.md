# 00-145-11: F144 confidence.Checker injection + escalation policy

Feature: F145 (Multi-Provider Dispatch Matrix & Confidence-Driven Cascade)

Design reference: [2026-04-26-f145-multi-provider-dispatch-cascade-design.md §4.3](../../plans/2026-04-26-f145-multi-provider-dispatch-cascade-design.md)

## Goal

Подключить F144 `confidence.Checker` как gate-policy в `CascadingInvoker`. Default — composer (`constraint+selfcheck`). Escalation triggers: `Status ∈ [UNSURE, FAIL]`. Per-tier override (cheap tier может использовать cheaper gate).

## Beads

- (assigned during epic creation)

## Scope Files

- `internal/dispatch/cascade/gate.go` — new. `GateFunc func(ctx, output string) (confidence.Status, error)`. Default builder: `NewCompositeGate(checker confidence.Checker[string]) GateFunc` — wraps F144 Checker.
- `internal/dispatch/cascade/cascade.go` — MODIFY. `Policy.Gate GateFunc` поле + per-tier override через `Policy.PerTierGate map[TierClass]GateFunc`. `Invoker.Invoke` теперь вызывает gate ПОСЛЕ heuristic (если heuristic не сработал) и эскалирует на `EscalateOn` set.
- `internal/dispatch/cascade/gate_test.go` — new. Tests: composite gate возвращает Status из Checker; OK не эскалирует; UNSURE/FAIL эскалируют согласно `EscalateOn`; per-tier override применяется.
- `internal/dispatch/cascade/cascade_test.go` — MODIFY. Добавить тесты с mock GateFunc: stay-on-fast при OK, escalate при UNSURE, escalate при FAIL.

## Acceptance Criteria

- [ ] `Policy.Gate` с composer-checker эскалирует UNSURE/FAIL.
- [ ] `Policy.PerTierGate` override применяется (e.g. fast tier использует constraint-only, strong tier использует full composer).
- [ ] Heuristic short-circuit имеет приоритет над gate (gate не вызывается если heuristic сработал) — проверяется тестом.
- [ ] `EscalateOn` configurable: тест с `[FAIL]` only не эскалирует UNSURE.
- [ ] Cost telemetry: `Result.GateCalls` count корректный.
- [ ] go build, go test ./internal/dispatch/cascade/..., go vet clean.
- [ ] Test coverage ≥85%.

## Out of Scope

- Replay-mode — WS 12.
- New confidence strategies (всё из F144).
