# 00-120-02: Identity, Scale, and Activity Detectors

Feature: F120 (Toolkit Scout — instant repo card for unknown codebases)

## Goal

Implement the three-phase scout pipeline so SDP can determine what a repo is, how big it is, and whether it is active without paying the cost of full architecture analysis.

## Beads

- sdplab-uekb

## Scope Files

- `internal/scout/scout.go`
- `internal/scout/identity.go`
- `internal/scout/scale.go`
- `internal/scout/activity.go`
- `internal/scout/health.go`
- `internal/scout/scout_test.go`

## Acceptance Criteria

- [ ] identity phase detects primary languages, build system, README summary, and likely entry points
- [ ] scale phase counts files and LOC with shared exclusions and skips generated/binary noise
- [ ] activity phase derives recent commit, author, branch, tag, and staleness signals from git
- [ ] the pipeline works on temp test repos without LLM calls
- [ ] integration test against `sdp_lab` produces a reasonable project card

## Out of Scope

- persistent artifact writing
- text/card CLI formatting
- architect-style deep analysis

## Implementation Notes

- Design source: `docs/plans/2026-04-13-sdp-scout-design.md`
- Plan source: `docs/plans/2026-04-13-sdp-scout-implementation-plan.md`
- Keep the phases independently testable. This is a UX speed feature, not a smart-agent feature.
