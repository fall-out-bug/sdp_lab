# 00-123-01: Deterministic Contract Extraction

Feature: F123 (Toolkit Spec Recovery — recover implicit contracts from code)

## Goal

Recover API contracts and business rules from code without LLM dependency so spec recovery is useful on day one and safe on sensitive repositories.

## Beads

- sdplab-gbk4

## Scope Files

- `internal/spec/spec.go`
- `internal/spec/api_extract.go`
- `internal/spec/rules_extract.go`
- `internal/spec/go_routes.go`
- `internal/spec/sql_parse.go`
- `internal/spec/types.go`
- `cmd/sdp/cmd_spec.go`

## Acceptance Criteria

- [ ] deterministic extraction recovers API contracts and business rules from supported sources
- [ ] route extraction covers the Go web frameworks named in the design
- [ ] extraction runs without network or LLM calls by default
- [ ] `.sdp/specs/` output is useful even when enrichment is disabled
- [ ] integration tests on fixture repos prove the recovered contracts are real, not inferred guesses

## Out of Scope

- invariant extraction
- SLA signals
- LLM enrichment and drift diff

- Design source: `docs/plans/2026-04-13-sdp-spec-design.md`
- Plan source: `docs/plans/2026-04-13-sdp-spec-implementation-plan.md`
- Default mode must stay deterministic. Enrichment is optional, not the baseline.
