# 00-162-03: Prompt bundle doctor gates and isolation lint

Feature: F162 (sdplab-wuaa)
Parent bead: sdplab-wuaa.3

## Goal

Make prompt routing failures visible before runtime.

## Beads

- sdplab-wuaa.3

## Scope Files

- `cmd/sdp/cmd_doctor.go`
- `internal/adapters/drift.go`
- `internal/manifest/`
- `docs/reference/sdp-cli.md`

## Acceptance Criteria

- [ ] `sdp doctor` checks that every prompt bundle resolves deterministically.
- [ ] Doctor fails when a generated entrypoint has a stale or missing bundle hash.
- [ ] Doctor flags harness-specific rules in universal files and cross-harness imports in harness files.
- [ ] Doctor flags model-specific rules outside model-specific prompt sections.
- [ ] Tests cover missing section, duplicate match, stale generated output, and invalid overlay cases.

## Out of Scope

- Rewriting prompt content flagged by lint.
- Launching external harnesses.
