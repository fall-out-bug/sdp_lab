# 00-153-03: Trademark and domain check on key working names

Feature: F153 (sdplab-mbhg)
Parent bead: sdplab-mbhg.3

## Goal

Check each working name for trademark collision and domain availability before external communication or legal instrument references the name.

## Beads

- sdplab-mbhg.3

## Names to Check

1. `ChangePassport`
2. `arch-snap`
3. `doc-tracer`
4. `sdp-pr-gate`
5. `Enterprise Delivery Governance` (EDG)

## Scope Files

- `docs/strategy/naming/<name>.md` — one document per name with check results

## Acceptance Criteria

- [ ] Each document covers:
  - USPTO / EUIPO basic check (class 42, SaaS/software)
  - Domain availability (.com, .ai, .io, .dev)
  - GitHub org/repo namespace availability
  - npm / Go module path collision check (if applicable)
  - Verdict: safe to use externally / rename recommended / blocked
- [ ] Synthesis table in `docs/strategy/naming/summary.md`
- [ ] If any name is blocked, a recommended alternative is proposed

## Out of Scope

- Filing trademarks
- Registering domains
- Full legal opinion (use basic web search + USPTO TESS)

- SDP product layering memo v3 §Naming policy and rename criteria
