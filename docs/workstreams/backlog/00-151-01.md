# 00-151-01: Passport Schema v1 (JSON Schema)

Feature: F151 (sdplab-hfk0)
Parent bead: sdplab-hfk0.1

## Goal

Author Passport Schema v1 as a JSON Schema document covering intent, scope, actors, evidence, findings, risk, and decision. Stable contract; manual annotations cannot overwrite observed facts.

## Beads

- sdplab-hfk0.1

## Scope Files

- `docs/design/sdp-pr-gate/passport-schema-v1.md` — design rationale
- `schema/sdp-pr-gate/passport.schema.json` — JSON Schema artifact
- `schema/sdp-pr-gate/examples/` — example passports (valid + edge cases)

## Acceptance Criteria

- [ ] JSON Schema covers all 7 passport sections: intent, scope, actors, evidence, findings, risk, decision
- [ ] Schema enforces: manual annotations cannot overwrite observed facts
- [ ] Schema includes `$schema`, `$id`, `$defs` for reusable subschemas
- [ ] Decision enum: merge | hold | rework | escalate | override
- [ ] Evidence section references Evidence Provider API event structure
- [ ] At least 3 example passport documents (happy path, override, degraded evidence)
- [ ] Schema validates via `jsonschema.Validate` or equivalent
- [ ] Design doc explains field-by-field rationale and versioning strategy

- Decision Record schema (00-151-03)
- Implementation code
- Rendering templates (Markdown/JSON output formats)
