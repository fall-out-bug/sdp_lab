# 00-109-05: Findings and Coverage Regrouping

Feature: F109 (StratAudit v2 — evidence-backed report redesign)

## Goal

Убрать шум модели "одна сущность = один alert" и собрать findings в
аналитические кластеры, а coverage считать не только по уровню, но и по
документам и разделам.

## Beads

- sdplab-3z8

## Scope Files

- `internal/strataudit/model/finding.go` — grouped finding shape и типы cluster-level проблем
- `internal/strataudit/analyze.go` — regrouping logic и separation strategy gaps vs corpus-quality failures
- `internal/strataudit/store.go` — хранение grouped findings и coverage breakdowns
- `internal/strataudit/report_builder.go` — export grouped findings и multi-level coverage
- `internal/strataudit/analyze_test.go` — tests на grouping и top-blocker detection

## Acceptance Criteria

- [x] analyzer выдаёт grouped findings вместо плоского спама по entity
- [x] corpus-quality failures отделены от strategy gaps отдельным типом/кластером
- [x] coverage доступен минимум в трёх срезах: `level`, `document`, `section`
- [x] top blocking documents/sections можно получить без HTML-слоя
- [x] tests подтверждают, что repeated entity-level alerts схлопываются в устойчивые кластеры

## Out of Scope

- Финальная сортировка и визуальная приоритизация в HTML
- Ручная triage workflow
- Коррекция ontology levels
