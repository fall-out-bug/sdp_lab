# WS-004-02: Extract quality pipeline into internal/quality/

Feature: FR-004 (sdp_dev-d1l) + FR-007 (sdp_dev-e4k)
Priority: P1
Effort: 1d
Dependencies: WS-004-01

## Goal

Extract reusable quality steps from executor.go into a shared package that adapter-controller can use.

## Extract

From `internal/pipeline/executor.go`:
- `RunTests(workDir string) (bool, error)` — go test ./...
- `CollectEvidence(cfg EvidenceConfig) (*Evidence, error)` — evidence collection
- `SignProvenance(cfg ProvenanceConfig) (*SignedEnvelope, error)` — provenance signing
- `RunPRGate(issueID, workDir string) error` — pr-gate --prepublish
- `TransitionFSM(issueID, targetState, workDir string) error` — beads-fsm
- `CommitAndPublish(cfg PublishConfig) (string, error)` — git + pr-publish

Into `internal/quality/pipeline.go`.

## Acceptance Criteria

- [x] `internal/quality/` package exists
- [x] Each function has unit test
- [x] adapter post-reconcile uses quality pipeline
- [x] executor.go calls quality pipeline (if kept for test-only)
- [x] No evidence schema duplication between adapter and quality (quality uses agent.EvidenceCollector; adapter uses EvidenceProjector + evidence.ValidateStrictFile)
