# 00-138-03: Canonical skill consolidation

Feature: F138 (Skill Catalog Normalization)

## Goal

Reduce the active skill surface to the canonical catalog while handling legacy names with explicit deprecation behavior.

## Beads

- sdplab-yocw.3

## Scope Files

- `.agents/skills/*.md` — consolidate active skills and retire legacy duplicates
- `.agents/skills/README.md` — update active catalog overview if required

## Acceptance Criteria

- [ ] The active skill set matches the canonical merge map
- [ ] Legacy skill names are deprecated explicitly rather than left as ambiguous duplicates
- [ ] Consolidation does not reopen or redefine the shipped `F125` intent model
- [ ] The resulting surface is small enough to describe coherently in docs and MCP parity work

## Out of Scope

- Bootstrap generation from the catalog
- New intent design
- MCP implementation
