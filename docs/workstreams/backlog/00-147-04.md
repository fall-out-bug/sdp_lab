# 00-147-04: `BdSeverityMicro` — embedding-based bd severity classifier

Feature: F147 (MicroFirst Inference Tier)

Design reference: [2026-04-27-f147-microfirst-tier-design.md §3 F147-04](../../plans/2026-04-27-f147-microfirst-tier-design.md)

## Goal

Embedding-based k-NN classifier для bd issue severity (`P0/P1/P2/P3`). Корпус — `.beads/issues.jsonl` (closed issues only). Реализует `Confider`. Используется в `bd suggest` CLI (00-147-08) и потенциально в `@issue` skill.

## Beads

- sdplab-itzf (historical F147 anchor; leaf Beads were not preserved)

## Scope Files

- `internal/inference/microfirst/bdseverity/classifier.go` — new. `BdSeverityMicro` Stage[BdInput, BdSeverityResult].
- `internal/inference/microfirst/bdseverity/corpus.go` — new. Loader из `.beads/issues.jsonl`, фильтр closed+priority, train/test split (last-30 hold-out).
- `internal/inference/microfirst/bdseverity/result.go` — new. `BdSeverityResult{Priority, Confidence, Status, Neighbors}` implements `Confider`.
- `internal/inference/microfirst/bdseverity/classifier_test.go` — new. Eval on hold-out 30, accuracy assertion.
- `internal/inference/microfirst/bdseverity/testdata/sample_issues.jsonl` — new. Fixture corpus (synthetic, не привязан к live `.beads/`).

## Acceptance Criteria

- [ ] Loader парсит `.beads/issues.jsonl`, выкидывает: not-closed, no-priority, type=epic.
- [ ] Train/test split: last-30 closed (by closed_at) — eval; rest — train.
- [ ] Embedding key: `title + "\n" + description`.
- [ ] Threshold: top-1 cosine ≥ 0.85 AND top-3 unanimous → `Status=OK`; else `Status=Unsure`.
- [ ] Eval accuracy on `Status=OK` subset ≥ 80% on synthetic fixture corpus (live corpus eval — в 00-147-09 bench).
- [ ] Fallback rate (Status=Unsure) ≤ 50%.
- [ ] Latency p95 < 100ms (Ollama call + cosine over ~100 vectors).
- [ ] Neighbors (top-5) included в result для explainability.
- [ ] Coverage ≥ 85%.
- [ ] `go build ./...` and `go vet ./...` clean.

## Out of Scope

- BdType classifier (→ 00-147-05) — отдельный classifier.
- CLI wrapper `bd suggest` (→ 00-147-08).
- Live corpus regression test in CI (опасно — coupling к `.beads/` content; eval gates на synthetic fixture).
- Online re-training — re-embed corpus вручную при необходимости.
