# 00-011-01: kubeopencode UP-001 Retry Budget PR

Feature: F011 (sdplab-9eu)

## Goal

Contribute retry budget functionality upstream to kubeopencode. Tasks that fail should respect a retry budget instead of retrying infinitely.

## Beads

- sdplab-9eu

## Scope Files

- External: kubeopencode repo
- `docs/drafts/` — design notes for upstream contribution

## Acceptance Criteria

- [ ] PR submitted to kubeopencode with retry budget feature
- [ ] Task CRD gets `spec.retryBudget` field (max retries, backoff)
- [ ] Task controller respects budget: stops retrying after N attempts
- [ ] Tests included in the PR
- [ ] PR is in review or merged
