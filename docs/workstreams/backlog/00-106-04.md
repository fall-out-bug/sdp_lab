# 00-106-04: Crash reconciliation — defer Stop при падении агента

Feature: F106 (agentloop Integration)

## Goal

Добавить `defer h.Stop()` в `runWithHarness()` чтобы при crash/panic/context cancellation Harness записывал terminal PhaseRecord в SQLite. Это предотвращает dirty state в Beads при восстановлении.

## Beads

- sdplab-igb

## Scope Files

- `internal/executor/bridge_serve.go` — добавить defer (в функцию из 00-106-03)
- `internal/executor/bridge_serve_test.go` — добавить тест crash scenario

## Acceptance Criteria

- [ ] `runWithHarness()` содержит defer который вызывает `h.Stop(context.Background(), "")` при crash/cancel, но НЕ при успешном завершении
- [ ] `harness.go` экспортирует `var ErrHarnessTerminated = errors.New("harness: session was terminated")`
- [ ] При ctx cancel во время `RunPhase` → defer вызывает `h.Stop` → последующий `RestoreHarness` с тем же cardID возвращает `agentloop.ErrHarnessTerminated` (проверять через `errors.Is`, не строку)
- [ ] При panic в `RunPhase` → recover + `h.Stop` → паника не теряется (re-panic после Stop)
- [ ] При успешном `RunPhase` → `h.Stop` НЕ вызывается (сессия остаётся живой для следующего phase turn)
- [ ] `go test ./internal/executor/ -run TestServeBridgeCrash -race` PASS
- [ ] Все существующие тесты PASS

## Out of Scope

- Beads state reconciliation (Beads update при crash) — отдельная задача
- Background reconciliation loop — не нужен при наличии этого defer

## Implementation Notes

```go
func (b *ServeBridge) runWithHarness(...) (*control.ExecutorResultPacket, error) {
    // ... store, harness creation ...
    
    var succeeded bool
    defer func() {
        if r := recover(); r != nil {
            _ = h.Stop(context.Background(), "")
            panic(r) // re-panic после записи terminal record
        }
        if !succeeded {
            _ = h.Stop(context.Background(), "")
        }
    }()
    
    if err := h.RunPhase(ctx, prompt, ""); err != nil {
        // error → не успешно → defer вызовет Stop
        return &control.ExecutorResultPacket{Status: "failed", Error: err.Error()}, nil
    }
    
    succeeded = true // предотвращает Stop при нормальном завершении
    return &control.ExecutorResultPacket{Status: "completed", CardID: card.ID}, nil
}
```

**Важно:** `h.Stop()` в `harness.go` пишет `PhaseRecord{NextPhase: ""}` в SQLite — это terminal marker. `RestoreHarness` проверяет это состояние и возвращает `agentloop.ErrHarnessTerminated` (sentinel variable) — **не строку**:

```go
// internal/agentloop/harness.go
var ErrHarnessTerminated = errors.New("harness: session was terminated")
```

Код в `bridge_serve.go` использует `errors.Is(err, agentloop.ErrHarnessTerminated)`, НЕ `strings.Contains`.

**Тест crash**: создать ctx с cancel, вызвать `runWithHarness`, отменить ctx во время RunPhase, проверить что последующий `RestoreHarness` возвращает "was terminated" error.
