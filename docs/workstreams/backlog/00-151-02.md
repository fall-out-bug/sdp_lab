# 00-151-02: Evidence Provider API v1

Feature: F151 (sdplab-hfk0)
Parent bead: sdplab-hfk0.2

## Goal

Define Evidence Provider API v1 contract with schema_version, source, external_ref, repository, pull_request, commit_sha, observed_at, collected_at, actor, event_type, status, summary, artifact_uri, artifact_hash, error_state. Idempotent ingestion. Provider states: accepted/rejected/degraded.

## Acceptance Criteria

- [ ] API contract defines all 14 required fields from manifesto §"Evidence Provider API v1"
- [ ] Idempotent ingestion semantics documented (dedup key, replay handling)
- [ ] Provider states defined: accepted, rejected, degraded (with transition rules)
- [ ] Error state handling: missing evidence must not be silently converted into a pass
- [ ] Evidence event JSON Schema created and self-validating
- [ ] At least 3 example events: CI run, scanner finding, review comment
- [ ] API doc covers: authentication model, rate limits, versioning, backwards compatibility
- [ ] Design doc explains how degraded evidence propagates to passport
