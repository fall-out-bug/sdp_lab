# WS-011-03: pr-publish cross-project routing

Feature: FR-011
Priority: P0
Effort: 1d
Dependencies: WS-011-02

## Goal

Extend pr-publish to create PRs in the correct repo/branch based on project registry config.

## Acceptance Criteria

- [x] pr-publish accepts --repo and --base flags
- [x] Reads project config from registry if not specified
- [x] Creates PR in correct remote
- [x] Fork repos: PR targets upstream with correct base branch
- [x] Beads issue updated with prUrl pointing to correct repo
