# 00-097-02: Activation Loop CLI (sdp assess + sdp try)

Feature: F097 (Product Truth and Activation Loop)

## Goal
Implement `sdp assess` (read-only repo scan, stdout only, writes nothing) and `sdp try "task"` (bounded execution on temp branch, zero residue on discard). These provide zero-commitment first experience.

## Scope Files
- `sdp/sdp-plugin/cmd/sdp/` — new subcommands assess, try
- `sdp/sdp-plugin/internal/assess/` — new package
- `sdp/sdp-plugin/internal/trial/` — new package

## Acceptance Criteria
- [ ] `sdp assess` on a Python project outputs recommendations without creating any files
- [ ] `sdp try "description"` creates temp branch, executes one bounded task, shows results
- [ ] After discard: repository identical to pre-try state (verified by git diff)
- [ ] `sdp adopt` creates .sdp/ structure equivalent to sdp init
