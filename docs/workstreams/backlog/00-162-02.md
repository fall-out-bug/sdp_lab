# 00-162-02: Harness-native system entrypoint generation

Feature: F162 (sdplab-wuaa)
Parent bead: sdplab-wuaa.2

## Goal

Extend adapter generation so Claude Code, Codex, OpenCode, Cursor, Pi, and Kilo
start from harness-appropriate prompt bundles instead of loading all prompt
sources.

## Beads

- sdplab-wuaa.2

## Scope Files

- `internal/adapters/generate.go`
- `internal/adapters/templates/`
- `internal/adapters/generate_test.go`
- `.claude/`
- `.codex/`
- `.opencode/`
- `.cursor/`
- `.kilo/`

## Acceptance Criteria

- [ ] Generated Claude Code entrypoints reference the resolved Claude bundle for top-level and role-agent use.
- [ ] Generated Codex entrypoints reference the resolved Codex bundle while keeping universal `AGENTS.md` small and harness-neutral.
- [ ] Generated OpenCode agents reference resolved bundle files in `.opencode/opencode.json` or generated agent config.
- [ ] Generated Cursor rules reference resolved Cursor bundles.
- [ ] Generated Pi adapter follows the Pi capability profile from `00-162-06`.
- [ ] Generated Kilo config/modes/agents reference resolved Kilo bundles.
- [ ] User-owned files are preserved through generated markers, overlays, or explicit non-overwrite behavior.
- [ ] Golden tests prove deterministic output for every green harness profile.

## Out of Scope

- Runtime dispatch.
- Doctor enforcement.
