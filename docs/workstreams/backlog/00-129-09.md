# 00-129-09: CLI snapshot tests

Feature: F129 (Autonomous Operations & Regression Hardening)

## Goal

Snapshot-test `sdp-orchestrate`, `sdp-harness`, `sdp-doc-sync` CLI outputs for `--help`, common flags, and error paths. Golden-file pattern.

## Beads

- sdplab-8k5.9

## Scope Files

- `tests/cli-snapshots/` — new dir with golden files
- `tests/cli-snapshots/runner_test.go` — snapshot test runner
- `scripts/update_snapshots.sh` — regenerate golden files after intentional changes

## Acceptance Criteria

- [ ] Golden files for: `sdp-orchestrate --help`, `--next-action`, `--advance`; `sdp-harness --help`; `sdp-doc-sync --mode check/fix/changelog`
- [ ] Runner compares actual output to golden; fails on diff
- [ ] Update script regenerates via `UPDATE_SNAPSHOTS=1 go test ./tests/cli-snapshots/`
- [ ] CI runs snapshot tests

## Out of Scope

- Snapshotting LLM outputs (non-deterministic)
- Stateful commands

## Implementation Notes

Normalize timestamps/paths in output before compare. Use `github.com/bradleyjkemp/cupaloy` or a plain `testdata/golden` pattern — pick whichever matches existing conventions in this repo.
