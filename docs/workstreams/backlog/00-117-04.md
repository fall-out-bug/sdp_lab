# 00-117-04: Tabbed Analyst Report IA

Feature: F117 (StratAudit — claim-centric trace explorer and tabbed analyst report)

## Goal

Пересобрать HTML-отчёт в пять явных табов, чтобы summary, document analysis,
trace paths, gaps и diagnostics перестали конкурировать на одной странице.

## Beads

- sdplab-egqt

## Scope Files

- `internal/strataudit/report/html.go` — tab shell, navigation, view separation
- `internal/strataudit/report/json.go` — report mode and tab read model fields
- `internal/strataudit/report_builder.go` — default analyst mode data
- `internal/strataudit/report/html_test.go` — tab/render smoke tests

## Acceptance Criteria

- [x] отчёт имеет табы `Сводка`, `Документы`, `Трассировка`, `Разрывы`, `Диагностика`
- [x] default report открывается в analyst mode, а не в compare/debug mode
- [x] compare surface не отображается в основном flow
- [x] основные UI labels и заголовки русскоязычные
- [x] diagnostics не загрязняют summary/documents view
- [x] tests подтверждают наличие табов и корректное скрытие compare-first flow

## Out of Scope

- Отдельный SPA/frontend
- Реализация multi-run compare
- Исправление extraction/link quality
