# 00-109-07: HTML Report Reformatting

Feature: F109 (StratAudit v2 — evidence-backed report redesign)

## Goal

Пересобрать HTML-отчёт как честный аналитический интерфейс поверх JSON v2:
executive overview, analyst drill-down и evidence pack без потери provenance и
trust disclaimer.

## Beads

- sdplab-dfd

## Scope Files

- `internal/strataudit/report/html.go` — новая IA и drill-down navigation
- `internal/strataudit/report/json.go` — read model для HTML поверх JSON v2
- `internal/strataudit/report/html_test.go` — smoke/golden tests по ключевым секциям отчёта
- `cmd/sdp-strataudit/main.go` — генерация HTML из JSON v2 pipeline

## Acceptance Criteria

- [ ] HTML имеет три слоя: executive overview, analyst explorer, evidence pack
- [ ] из finding/traces можно дойти до документа и quote evidence не более чем за 3 клика
- [ ] coverage раскрывается по level, document и section, а не только одной цифрой
- [ ] локальные ссылки на документы и evidence cards работают на основе provenance из JSON v2
- [ ] отчёт явно показывает trust disclaimer и corpus-quality blockers

## Out of Scope

- Отдельный SPA/frontend
- Редактирование или triage прямо в HTML
- Multi-run dashboard

## Implementation Notes

- Если HTML снова полезет в store/SQLite напрямую, workstream считается не выполненным.
