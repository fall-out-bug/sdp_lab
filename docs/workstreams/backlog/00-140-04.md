# 00-140-04: Telemetry reducer — M1/M7 first, then M2–M6 (TEL-06)

Feature: F140 (AI SDLC Telemetry v1 — MVP)

Design reference: [2026-04-22-ai-sdlc-telemetry-design.md §2.1 (M1–M7), §10.9 (hypothesis)](../../plans/2026-04-22-ai-sdlc-telemetry-design.md)

## Goal

Go binary that reads `.sdp/traces/**/spans.jsonl[.zst]`, joins with beads state (closed epics, merge commits), and emits SDP-specific metrics M1–M7 plus the `ux-metrics.schema.json` output. M1 (review pass rate) and M7 (post-merge rework rate within 14 d) are the minimum shippable set — they answer falsifiable hypothesis H1.

## Beads

- sdplab-2q30 (F140-04: Telemetry reducer)

## Scope Files

- `cmd/sdp-telemetry-reducer/main.go` — new binary. Flags: `--since 7d`, `--trace-dir .sdp/traces`, `--out .sdp/metrics`, `--metrics m1,m7` (default: all).
- `internal/telemetry/reducer/` — new package.
  - `scanner.go` — reads `.jsonl` + `.jsonl.zst` day files.
  - `joiner.go` — groups spans by `trace_id` and `sdp.epic.bead_id`; "unattributed" bucket for orphan spans without bead_id.
  - `m1.go` — review pass rate: `COUNT(span where sdp.review.verdict=APPROVED AND sdp.phase.cycle_number=1) / COUNT(all review spans)`.
  - `m7.go` — post-merge rework: `git log --since=14d --name-only <merge_sha>..HEAD` vs files touched in merged PR; ratio.
  - `m2.go` .. `m6.go` — subsequent iterations (stubbed with tests but not all required for green).
  - `m6_cost.go` — reads `configs/model_pricing.json`, joins `gen_ai.usage.*` × pricing by model.
- `internal/telemetry/beads/` — new. `bd list --closed --since=...` reader; git-log wrapper for M7.
- Output files:
  - `.sdp/metrics/YYYY-MM-DD.sdp.json` — M1–M7 + per-feature breakdown.
  - `.sdp/metrics/YYYY-MM-DD.ux.json` — `ux-metrics.schema.json`-compliant aggregate.
- Tests: `internal/telemetry/reducer/*_test.go` with canonical fixture (synthetic JSONL from TEL-03 format) asserting M1 and M7 computed correctly.

## Acceptance Criteria

- [ ] Reducer reads both `.jsonl` and `.jsonl.zst` day files correctly.
- [ ] M1 computed correctly on fixture covering APPROVED/CHANGES_REQUESTED/BLOCKED verdicts.
- [ ] M7 correctly joins merged PR commits (from bead notes or `git log --grep="Merges:"`) with subsequent 14-day file touches.
- [ ] "Unattributed" bucket captured for orphan spans (missing `sdp.epic.bead_id`) — reported as separate line in output, not silently dropped.
- [ ] Output conforms to extended `ux-metrics.schema.json` (TEL-01) — validated via `jsonschema` CLI in test.
- [ ] M6 cost computation uses `configs/model_pricing.json`; fails if a model name has no pricing row.
- [ ] Runtime <10 s for 30-day trace window at typical load (10 k spans/day).
- [ ] `scripts/run_go_quality_gates.sh` covers reducer tests (no new container deps).
