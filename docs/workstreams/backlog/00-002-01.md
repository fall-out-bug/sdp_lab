## Goal

AgentRunReconciler watches AgentRun CRDs and creates kubeopencode Task CRDs for worker roles (analyst + coder in parallel).

## Reconcile Logic

```
func (r *AgentRunReconciler) Reconcile(ctx, req):
  run := get AgentRun
  
  switch run.Status.Phase:
    case "":
      // Validate spec
      intent := IntentTranslator.Translate(beads.Issue{ID: run.Spec.IssueID}, run.Name)
      gate := PolicyGate.PreDispatchModelAllowlist(run.Spec.Model)
      if !gate.Passed: set Failed + reason
      // Create analyst + coder Tasks
      analystTask := createTask(run, "analyst", intent)
      coderTask := createTask(run, "coder", intent)
      set Phase = Running, workerTask = analystTask.Name + "," + coderTask.Name
      
    case Running:
      // Check child Task statuses
      if all worker Tasks terminal:
        if any Failed: set Phase = Failed
        else: proceed to reviewer
      
    case ReviewerPending:
      // Collect worker outputs into ConfigMap
      // Create reviewer Task
      set reviewerTask = reviewerTask.Name
      
    case ReviewerRunning:
      if reviewer Task terminal:
        if Succeeded: set Phase = Succeeded, collect prUrl
        else: set Phase = Failed
```
