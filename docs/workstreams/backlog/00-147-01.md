# 00-147-01: Core composer — `decompose.WithEscalation` + `Confider` interface

Feature: F147 (MicroFirst Inference Tier)

Design reference: [2026-04-27-f147-microfirst-tier-design.md §3 F147-01](../../plans/2026-04-27-f147-microfirst-tier-design.md)

## Goal

Ship the generic Stage-композитор `WithEscalation[In, Out](micro, llm Stage[In, Out], cfg EscalationConfig) Stage[In, Out]` plus the `Confider` interface (Confidence/Status accessors). Foundation для всех F147 classifier'ов.

## Acceptance Criteria

- [ ] `EscalationConfig{ConfidenceThreshold, EscalateOnError, RecordSkippedTrace}` defined.
- [ ] `Confider` interface: `Confidence() float64`, `Status() decompose.Status`.
- [ ] `WithEscalation` returns `Stage[In, Out]` opaque to existing Pipeline.
- [ ] If micro Out implements Confider AND Status==OK AND Confidence>=threshold → no LLM call (escalated=false), trace.Attempts=1.
- [ ] If micro Out is Unsure / not Confider / Confidence<threshold → llm called, trace.Attempts=2, trace.LatencyMs = micro+llm sum, trace.TokensIn/Out from llm.
- [ ] If micro returns error and `EscalateOnError=true` → llm called.
- [ ] If micro returns error and `EscalateOnError=false` → composed stage returns error (no llm call).
- [ ] `RecordSkippedTrace=true` populates StageTrace.Attempts=1 with TokensIn/Out=0 (proves "saved" math).
- [ ] Coverage `go test -cover ./internal/inference/decompose/...` keeps ≥85%.
- [ ] `go build ./...` and `go vet ./...` clean.

## Out of Scope

- Specific micro classifiers (→ 00-147-02..06).
- Multi-tier escalation chain (micro → small-llm → big-llm) — single escalation step in v1.
- Telemetry export to external metrics — trace lives inside StageTrace only.
