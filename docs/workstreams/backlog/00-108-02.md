# 00-108-02: Миграция discovery/architect/strataudit на `llmclient`

Feature: F108

## Goal

Заменить три независимых LLM HTTP-клиента (`discovery.LLMClient`, `architect.ArchitectLLMClient`, `strataudit.LLMClient`) на тонкие обёртки поверх `internal/llmclient`. HTTP-код остаётся только в `internal/llmclient`.

## Beads

- sdplab-uiq

## Scope Files

- `internal/discovery/llm.go` — заменить HTTP-код на делегирование к `llmclient`; type aliases для backward compat
- `internal/architect/llm_client.go` — заменить HTTP-код; сохранить retry wrapper
- `internal/strataudit/llmclient.go` — заменить HTTP-код; сохранить cache + rate limiter

## Acceptance Criteria

- [ ] `internal/discovery/llm.go` использует `llmclient.New()` под капотом
- [ ] `discovery.Message`, `discovery.ChatRequest`, `discovery.ChatResponse` — type aliases из `llmclient` (без изменений в callers внутри пакета)
- [ ] `internal/architect/llm_client.go` делегирует HTTP в `llmclient.New()`; retry wrapper сохранён
- [ ] `internal/strataudit/llmclient.go` делегирует HTTP в `llmclient.New()`; cache (SHA256) и rate limiter сохранены
- [ ] `grep -rn "openrouter.ai\|chat/completions" internal/ | grep -v internal/llmclient/` → пусто
- [ ] `go build ./...` успешен
- [ ] `go test ./internal/discovery/... ./internal/architect/... ./internal/strataudit/... -race` PASS

## Out of Scope

- Изменение поведения retry, cache, rate limiter
- Изменение публичного API пакетов discovery/architect/strataudit

## Implementation Notes

Подробные шаги — в `docs/plans/2026-04-11-f108-architecture-normalization-plan.md`, раздел WS-02.

Паттерн для discovery: type alias (`type Message = llmclient.Message`) — callers внутри пакета не меняются.

Для architect: `ArchitectLLMClient.Chat()` теперь вызывает `c.inner.Chat()`, где `inner *llmclient.Client`.

Для strataudit: cache hit/miss логика не меняется; только фактический HTTP вызов заменяется.
