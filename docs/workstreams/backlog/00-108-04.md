# 00-108-04: `ErrHarnessTerminated` — sentinel-ошибка

Feature: F108

## Goal

Заменить строково-форматированную ошибку в `RestoreHarness` на экспортированную sentinel-переменную `ErrHarnessTerminated`. Все callers используют `errors.Is()`, строковое сравнение запрещено.

## Beads

- sdplab-bqi

## Scope Files

- `internal/agentloop/harness.go` — добавить `var ErrHarnessTerminated`; заменить `fmt.Errorf("session %s was terminated...")` на `fmt.Errorf("session %s: %w", sessionID, ErrHarnessTerminated)`
- `internal/agentloop/harness_test.go` — добавить тест `TestErrHarnessTerminated_isSentinel`
- Любые callers за пределами `agentloop/` что делают string-comparison на "terminated"

## Acceptance Criteria

- [ ] `var ErrHarnessTerminated = errors.New("harness: session was terminated")` — экспортировано, на уровне пакета
- [ ] `RestoreHarness` оборачивает через `%w`: `fmt.Errorf("session %s: %w", sessionID, ErrHarnessTerminated)`
- [ ] `errors.Is(err, agentloop.ErrHarnessTerminated)` возвращает `true` для обёрнутой ошибки
- [ ] `grep -rn "terminated.*by Stop\|was terminated" internal/ cmd/ | grep -v "_test.go"` → пусто (кроме README/комментариев)
- [ ] `go test ./internal/agentloop/... -run TestErrHarnessTerminated -v` PASS
- [ ] `go build ./...` без ошибок

## Out of Scope

- Изменение других ошибок в harness.go
- Изменение поведения Stop() или RestoreHarness (только error type)
