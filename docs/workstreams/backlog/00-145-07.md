# 00-145-07: Harness plumbing fix — cursor.go + opencode.go --model

Feature: F145 (Multi-Provider Dispatch Matrix & Confidence-Driven Cascade)

Design reference: [2026-04-26-f145-multi-provider-dispatch-cascade-design.md §1.1](../../plans/2026-04-26-f145-multi-provider-dispatch-cascade-design.md)

## Goal

Закрыть silent-bug: `CursorHarness.Spawn` и `OpenCodeHarness.Spawn` не передают `opts.Model` в CLI. Router-решения не реализуются. Регрессионные тесты на cmd-line invocation.

## Beads

- (assigned during epic creation)

## Scope Files

- `internal/dispatch/harness/cursor.go` — MODIFY. В `Spawn`: если `opts.Model != ""`, добавить `--model <opts.Model>` в args **перед** `prompt`. Сохранить порядок аргументов: `agent --model X -p [...] prompt`.
- `internal/dispatch/harness/cursor_test.go` — new (или MODIFY если есть). Tests: `Spawn` с `opts.Model="composer-2-fast"` запускает `cursor agent --model composer-2-fast ...` (через mock `exec.CommandContext`).
- `internal/dispatch/harness/opencode.go` — MODIFY. В `Spawn`: если `opts.Model != ""`, добавить `-m <provider/model>` в args. Формат: opencode требует `provider/model` пары — если caller передал просто `"qwen2.5-coder:7b"` без provider, дефолтим `ollama/<model>`. Документировать в doc-comment.
- `internal/dispatch/harness/opencode_test.go` — new (или MODIFY). Tests: `Spawn` с `opts.Model="ollama/qwen2.5-coder:7b"` запускает `opencode run --agent X -m ollama/qwen2.5-coder:7b`. Также тест на autonatic prefix dollama/.
- `internal/dispatch/harness/harness_test.go` — MODIFY если нужно для shared mock helpers.

## Acceptance Criteria

- [ ] `cursor agent --model <X>` передаётся когда `opts.Model != ""`.
- [ ] `opencode run -m <provider/model>` передаётся когда `opts.Model != ""`.
- [ ] Если `opts.Model == ""`, поведение идентично текущему (не ломаем default flow).
- [ ] Regression test проверяет точный список args через `exec.Cmd.Args` (mock).
- [ ] go build, go test, go vet clean.
- [ ] Test coverage ≥90% для cursor.go и opencode.go.

## Out of Scope

- Изменения в claude.go или codex.go — там `--model` уже работает.
- Provider/model resolution logic — это уровень Router (WS 08).
