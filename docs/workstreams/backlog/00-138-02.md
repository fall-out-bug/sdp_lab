# 00-138-02: Catalog artifact generation

Feature: F138 (Skill Catalog Normalization)

## Goal

Generate a machine-readable skill catalog so active skill truth stops living only in markdown prose.

## Beads

- sdplab-yocw.2

## Scope Files

- `.agents/skills/index.json` — canonical machine-readable catalog
- `internal/docsync/` — validation hooks for catalog parity if implementation lands there

## Acceptance Criteria

- [ ] `skills/index.json` exists as the canonical catalog artifact
- [ ] Entries include name, path, description, tags, and status
- [ ] Deprecated skills are represented explicitly instead of disappearing silently
- [ ] The catalog is usable as input for docs and MCP parity work

## Out of Scope

- Consolidating skill bodies
- Rewriting harness docs
