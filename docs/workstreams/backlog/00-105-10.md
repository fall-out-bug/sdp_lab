# 00-105-10: C4 Model Generation

Feature: F105 (AI Architect)

## Goal

Implement the C4 model generation engine that produces L1/L2/L3 diagrams from extractor outputs, with relationship inference, Mermaid rendering, and confidence scoring for each generated element.

## Beads

- sdplab-tx1h: historical shipped feature anchor for F105 (PR #86)

## Scope Files

- `internal/architect/c4/generator.go` — C4Generator main implementation
- `internal/architect/c4/generator_test.go`
- `internal/architect/c4/level1.go` — L1 System Context generation from infra signals
- `internal/architect/c4/level2.go` — L2 Container generation from deploy units
- `internal/architect/c4/level3.go` — L3 Component generation from import graph clusters
- `internal/architect/c4/relationship.go` — relationship inference between C4 elements
- `internal/architect/c4/mermaid.go` — Mermaid diagram rendering with layout hints
- `internal/architect/c4/mermaid_test.go`
- `internal/architect/c4/confidence.go` — confidence scoring for auto-generated elements
- `internal/architect/c4/export.go` — graph data export for Excalidraw/draw.io

## Acceptance Criteria

- [ ] L1 System Context generated from InfraExtractor signals with high confidence
- [ ] L2 Container diagram generated from deploy units (docker-compose services, k8s deployments, workspace members)
- [ ] L3 Component diagram generated from import graph clusters across all 5 language extractors
- [ ] Relationship inference connects containers/components via: imports, API calls, shared databases, message queues
- [ ] Mermaid output generated with explicit layout direction and grouping per C4 level
- [ ] Output files placed at `{target-repo}/.sdp/architecture/c4/level-{1,2,3}*.mmd`
- [ ] Confidence scoring marks low-confidence components with `[AUTO]` prefix and null human_description
- [ ] For >15 nodes, graph data file also emitted for manual layout in Excalidraw/draw.io
- [ ] Performance SLA: small repo (<1K files) <30s total, medium (<10K) <2min, large (<50K) <6min

## Out of Scope

- L4 Code-level diagram generation (on-demand only, deferred)
- Excalidraw/draw.io direct rendering (only graph data export)
- Interactive diagram editing
- Diagram diffing between versions

## Implementation Notes

- From section 2.1: C4 levels map to data sources — L1 from InfraExtractor, L2 from deploy units, L3 from import graph clusters + naming heuristics
- L3 honesty principle: generate technical component diagrams, explicitly mark components needing human enrichment with `[AUTO]` label
- From section 2.3: Mermaid output with layout hints, stored in `.sdp/architecture/c4/`
- Known limitation: auto-layout produces suboptimal results for >15 nodes — output graph data file alongside Mermaid
- From section 2.2: Performance SLAs for different repo sizes — extraction + LLM interpretation totals
- From section 3.3: Every discovered contract = labeled edge in C4 diagrams
- From section 2.1: Runtime reality over source structure — containers are deploy units, not directories
- Each generated element needs confidence score; low-confidence items marked for human review
- Monorepo support: distributed `.sdp/architecture/` per bounded context (section 4.2)
