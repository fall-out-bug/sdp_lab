# 00-121-12: Fix TagInfo.Date Collection

Feature: F121 (Toolkit Metrics — git-derived process health)

## Goal

Fix P0 blocker found by QA and SRE in round-5 review: `TagInfo.Date` is never populated because `collectTags` uses `git tag --sort=creatordate` which outputs tag names only. All release quality and stabilization metrics are silently incorrect — every fix commit gets attributed to every release tag.
