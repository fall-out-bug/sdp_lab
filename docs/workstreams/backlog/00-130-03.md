# 00-130-03: OBSERVED-ONLY Rules Generator

Feature: F130 (sdplab-9nb)

## Goal

Create `internal/rules/` package that generates rules ONLY from observed evidence (test failures, protocol-check findings, evidence chain discrepancies). Never speculative.

## Beads

- sdplab-czt

## Scope Files

- `internal/rules/rules.go` — new: core rules types and generator
- `internal/rules/rules_test.go` — new: tests
- `internal/rules/evidence.go` — new: evidence source reader

## Acceptance Criteria

- [ ] `internal/rules/` package with `Rule` struct: {ID, Title, Source, EvidenceRef, Severity}
- [ ] Source tag is always `observed-failure:<ref>` or `human-annotated:<bd-id>` — never `speculative`
- [ ] Generator reads from `.sdp/evidence/` and test failure history
- [ ] Diff mode: `rules diff` shows added/removed/modified with evidence citation
- [ ] Deterministic: re-run on unchanged evidence produces identical output

## Out of Scope

- Scout-based speculative rules (expressly forbidden)
- Harness adapter rendering (F130-04)

## Implementation Notes

- Evidence sources: evidence.json files, test output logs, protocol-check findings
- Rule format: YAML or JSON, compatible with downstream adapters
- Each rule MUST have `source` field — generator refuses to emit without it
