# 00-161-05: pi-review diff packet skip-filter bugfix

Feature: F161 (sdplab-tffu)
Parent bead: sdplab-p1qw

## Goal

Fix Kimi reviewer quorum degradation caused by oversized `pi-review` context
packets. The reviewed file list already skips generated/noisy paths such as
`.beads/`, but the unified diff still included those paths. That let
`.beads/issues.jsonl` reorder noise enter the prompt and caused Kimi to time out
on otherwise small code/spec reviews.

## Acceptance Criteria

- [x] Working-tree review diffs are path-filtered to the same reviewed files
