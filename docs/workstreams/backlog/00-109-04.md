# 00-109-04: Trace Evidence Contract

Feature: F109 (StratAudit v2 — evidence-backed report redesign)

## Goal

Разделить discovery и proof в traceability: similarity и LLM могут генерировать
кандидатов, но пользовательский trace должен существовать только вместе с
evidence bundle.

## Beads

- sdplab-zbu

## Scope Files

- `internal/strataudit/model/trace.go` — `trace_candidates`, verified trace fields, verification mode
- `internal/strataudit/link.go` — разделение candidate generation и verified trace admission
- `internal/strataudit/store.go` — хранение evidence refs, similarity score, trust grade
- `internal/strataudit/report_builder.go` — экспорт trace diagnostics и verified traces раздельно
- `internal/strataudit/link_test.go` — tests на candidate vs verified semantics

## Acceptance Criteria

- [ ] similarity-only link остаётся candidate/diagnostic и не попадает в verified trace set
- [ ] verified trace требует source/target evidence refs и явный `verification_mode`
- [ ] trace хранит `trust_grade`, similarity score и justification раздельно
- [ ] store/report API различают candidates и verified traces без ad hoc фильтрации в UI
- [ ] tests покрывают downgrade similarity-only links и success path для evidence-backed trace

## Out of Scope

- Новый graph UI
- Ручное подтверждение trace человеком
- Cross-run diff trace quality

## Implementation Notes

- WS-04 закрывает главный продуктовый обман текущего StratAudit: similarity не должен выглядеть как доказательство.
