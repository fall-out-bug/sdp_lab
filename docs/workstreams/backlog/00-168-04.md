# 00-168-04: Model review planes over pi-review

Feature: F168 (sdplab-o8gk)
Design reference: [F168 design](../../plans/2026-05-13-f168-onboarding-quality-taxonomy-design.md)

## Goal

Define independent model-review planes for requirements-vs-implementation,
CleanCode, CleanArchitecture, Security, DX, UX, and documentation completeness.

## Scope Files

- `docs/reference/pi-review-spec.md`
- `cmd/sdp-pi-review/`
- `internal/pireview/`
- `schema/review-verdict.schema.json`

## Beads

- primary: sdplab-f16804

## Acceptance Criteria

- [ ] Reviewer planes are separate and cannot collapse into one generic verdict.
- [ ] Empty or unparsable model output degrades quorum and cannot produce `APPROVED`.
- [ ] Empty effective scope fails or falls back to branch diff; it does not review only ignored telemetry.
- [ ] Context egress excludes `.sdp/config.yml` contents and redacts/block secrets before provider calls.
- [ ] Raw telemetry stays local and untracked by default; compact verdict remains the durable artifact.

## Out of Scope

- Giving model reviewers write access.
- Replacing deterministic security scanners.
- Merging or publishing based on model output.
