# 00-145-02: OpenAIProvider — codex lineup + headers parsing

Feature: F145 (Multi-Provider Dispatch Matrix & Confidence-Driven Cascade)

Design reference: [2026-04-26-f145-multi-provider-dispatch-cascade-design.md §4.1, §4.5](../../plans/2026-04-26-f145-multi-provider-dispatch-cascade-design.md)

## Goal

Реализовать `OpenAIProvider` с каталогом моделей, доступных через codex CLI, и парсингом `x-ratelimit-*` headers для не-stub `CheckLimits()`. Provider — metadata-only: не хранит API key, не делает HTTP.

## Beads

- (assigned during epic creation)

## Scope Files

- `internal/dispatch/harness/providers/openai.go` — new. `OpenAIProvider struct{}`, `Name() = "openai"`, `Models()` возвращает каталог: `["gpt-5", "gpt-5-codex", "o1", "o1-pro", "o3", "o3-mini", "gpt-4o", "gpt-4o-mini"]`. `CheckLimits` возвращает текущий cached state из `LimitsCache` (передаётся через DI), `UpdateFromHeaders(http.Header)` парсит `x-ratelimit-remaining-requests`, `x-ratelimit-remaining-tokens`, `x-ratelimit-reset-*`.
- `internal/dispatch/harness/providers/openai_test.go` — new. Tests: `Models()` non-empty, `UpdateFromHeaders` корректно парсит mock headers, `CheckLimits` без headers возвращает stub с `Source: "uninitialized"`.

## Acceptance Criteria

- [ ] `Models()` содержит ≥ 8 моделей из текущего OpenAI lineup.
- [ ] `UpdateFromHeaders` корректно парсит valid `x-ratelimit-*` formats; ignore'ит невалидные.
- [ ] `CheckLimits` thread-safe (concurrent UpdateFromHeaders + Get).
- [ ] go build, go test, go vet clean.
- [ ] Test coverage ≥85%.

## Out of Scope

- HTTP-call к OpenAI API. Provider — metadata-only.
- Rate-limit retry logic — это уровень `LimitsCache` (WS 13).
- Profile entries для этих моделей — WS 09 (seed).
