# 00-110-01: Strict Work Atomicity Contracts in Validator, Harness, and Canonical Docs

Feature: F110 (Work Atomicity Normalization — strict leaf execution contract)

## Goal

Implement the first strict execution slice for work atomicity normalization so SDP stops treating every workstream as directly executable. This slice must make the new workstream schema machine-readable, compile a committed lock artifact, bind the mini-harness to executable leaf workstreams only, and remove ambiguous workstream wording from canonical skill and agent surfaces.
