# 00-110-01: Claim-Centric Trace Graph Contract

Feature: F110 (StratAudit — claim-centric trace explorer and tabbed analyst report)

## Goal

Сделать claim/entity минимальной explainable единицей трассировки и расширить
`report.v2.json` так, чтобы trace explorer можно было построить офлайн без
обращения к SQLite/store.

## Beads

- sdplab-qmm5

## Scope Files

- `internal/strataudit/model/trace.go` — trace node/edge status semantics
- `internal/strataudit/report/json.go` — additive contract blocks `trace_graph.*`
- `internal/strataudit/report_builder.go` — materialization of nodes/edges/paths
- `internal/strataudit/report/json_test.go` — contract/golden tests for trace graph

## Acceptance Criteria

- [ ] `report.v2.json` содержит `trace_graph.nodes`, `trace_graph.edges`, `trace_graph.paths`
- [ ] каждый node ссылается на entity, document, section, level и source quote
- [ ] каждый edge несёт `status`, `verification_mode`, `confidence`, `similarity`, `reason`
- [ ] contract остаётся additive поверх `report.v2.json`, без тихого слома текущих потребителей
- [ ] HTML/read-model можно построить без прямого чтения SQLite

## Out of Scope

- Gap taxonomy
- Document correspondence aggregation
- HTML tabs and navigation

## Implementation Notes

- Это фундамент `F110`. Если тут останется document-centric модель, весь feature снова уедет в красивую, но слабую витрину.
