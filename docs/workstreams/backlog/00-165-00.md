# 00-165-00: Indirect Prompt Injection Through SDP Task Data

Feature: F165 (sdplab-28xb)
Phase: Pilot Evidence & Spec Quality
Status: Backlog

## Goal

Deliver a safe SDP-native Day-12 indirect prompt-injection demo pack. The feature
adapts the challenge from email/document/web to Beads issue data, workstream
Markdown, and evidence/finding artifacts while preserving the trust-boundary
spirit. It proves the behavior through sanitized fixtures, deterministic unsafe
and defended outcomes, and residual-risk reporting.
