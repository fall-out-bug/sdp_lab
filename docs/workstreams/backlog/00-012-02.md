# WS-012-02: Per-role model selector with 3-tier fallback chains

Feature: FR-012 (sdp_dev-3ro)
Priority: P1
Effort: 1.5d
Dependencies: WS-012-01

## Goal

Refactor model_selector.go and model_chain.go to use per-role 3-tier config (primary → fallback → economy) from ConfigMap. Support 20 agent roles.

## Roles (20)

Core: analyst, coder, reviewer, reviewer-security, reviewer-dx, builder, verifier
Orchestration: orchestrator, autonomy-worker, brain-gateway
Analysis: retro-agent, self-improve-agent, evaluator, intake-analyzer
New agents: telemetry-analyzer, feature-orchestrator, cicd-agent
Alternative: openclaw-agent

## 3-Tier Fallback Logic

```
1. Try primary model
2. If primary fails/unavailable → try fallback
3. If fallback fails/unavailable → try economy
4. If budget > auto_downgrade_at_pct → skip to economy (except exempt roles)
5. If all fail → escalate
```
