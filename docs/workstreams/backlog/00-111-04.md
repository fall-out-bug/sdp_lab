# 00-111-04: Explicit StratAudit Skill Contract — Evidence, Runtime, Modes

Feature: F111 (StratAudit portability — engine-adapter-skill split)

## Goal

Довести portable skill surface StratAudit до честного продуктового контракта:
явная evidence policy, явная runtime policy, mode-based output contract и
fail-closed refusal rules для любого harness.

## Acceptance Criteria

- [x] local StratAudit skill is concise and trigger-driven, not pipeline-descriptive
- [x] evidence policy is documented separately from the top-level skill and clearly distinguishes `verified` vs `inferred`
- [x] runtime policy is documented separately and frames host-native models as first-class, with OpenRouter as enhancer/fallback
- [x] skill contract defines explicit audit modes and expected artifacts for each mode
- [x] skill contract defines fail-closed refusal rules when corpus, provenance, or runtime quality is insufficient
- [x] local `sdp_lab` surface and public `sdp` surface say the same thing about trust, runtime order, and output modes
