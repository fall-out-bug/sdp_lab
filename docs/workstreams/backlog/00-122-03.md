# 00-122-03: Manifest and Enrichment Pipeline

Feature: F122 (Toolkit Index — persistent codebase memory)

## Goal

Generate the always-in-context manifest and enrich index metadata from the rest of the toolkit without making those integrations mandatory.

## Beads

- sdplab-sstz

## Scope Files

- `internal/index/manifest.go`
- `internal/index/enricher.go`
- `internal/index/manifest_test.go`
- `internal/index/enricher_test.go`
- `cmd/sdp/cmd_index.go`

## Acceptance Criteria

- [ ] `sdp index manifest` generates `.sdp/manifest.md` from index data
- [ ] manifest stays concise enough for always-on agent context
- [ ] enrichment can ingest scout, metrics, architect, and spec artifacts when present
- [ ] missing upstream artifacts degrade gracefully without blocking index usage
- [ ] tests cover manifest generation and partial-enrichment scenarios

## Out of Scope

- background watching
- public protocol schema publication
