## Acceptance Criteria

- [ ] `BashTool(workdir string) Tool` — executes shell command, 60s default timeout, returns combined stdout+stderr
- [ ] **BashTool security**: команда проходит через `validateBashCommand(cmd string) error` перед выполнением. Deny-list паттернов: `rm -rf /`, `rm -rf ~`, `chmod 777 /`, `dd if=/dev/zero`, `:(){ :|: & };:` (fork bomb), `mkfs`, `>/dev/sda`. Метод возвращает `error` при match — команда не выполняется
- [ ] `cmd.Dir = workdir` выставляется, но **не является** единственной защитой. Явный тест: команда `cd / && pwd` должна выполниться (workdir irrelevant), команда `rm -rf /` должна вернуть ошибку

## Implementation Notes

**Bash tool security** (обязательно):
```go
var bashDenyPatterns = []string{
    "rm -rf /",
    "rm -rf ~",
    "chmod 777 /",
    "dd if=/dev/zero",
    ":(){ :|:",
    "mkfs",
    ">/dev/sda",
}

func validateBashCommand(cmd string) error {
    for _, pattern := range bashDenyPatterns {
        if strings.Contains(cmd, pattern) {
            return fmt.Errorf("command denied: matches unsafe pattern %q", pattern)
        }
    }
    return nil
}
```

Для file tools — path escape check:
```go
func validatePath(root, userPath string) error {
    abs := filepath.Join(root, filepath.Clean(userPath))
    if !strings.HasPrefix(abs, filepath.Clean(root)+string(os.PathSeparator)) {
        return fmt.Errorf("path escape: %s", userPath)
    }
    return nil
}
```

Bash args schema:
```json
{"type":"object","properties":{"command":{"type":"string"},"timeout":{"type":"integer","default":60}},"required":["command"]}
```

Bash implementation: `exec.CommandContext(ctx, "bash", "-c", command)`, `cmd.Dir = workdir`, `cmd.Stdout = &buf`, `cmd.Stderr = &buf`.

`OnToolResult` в `evidence.go` проверяет:
- `strings.Contains(output, "PASS")` или `strings.Contains(output, "\nok ")` → test pass
- `strings.Contains(output, "FAIL")` → test fail
- `strings.HasPrefix(output, "edited: ")` → file_modified
- `strings.HasPrefix(output, "card_created:")` → card_created
