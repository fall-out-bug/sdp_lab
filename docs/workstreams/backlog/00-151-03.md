# 00-151-03: Decision Record v1

Feature: F151 (sdplab-hfk0)
Parent bead: sdplab-hfk0.3

## Goal

Decision Record schema: decision (merge|hold|rework|escalate|override), owner, reason, timestamp, linked evidence snapshot, append-only audit reference.

## Beads

- sdplab-hfk0.3

## Scope Files

- `docs/design/sdp-pr-gate/decision-record-v1.md` — design doc
- `schema/sdp-pr-gate/decision-record.schema.json` — JSON Schema

## Acceptance Criteria

- [ ] Decision enum: merge | hold | rework | escalate | override
- [ ] Required fields: decision, owner, reason, timestamp, evidence_snapshot_ref, audit_ref
- [ ] Override requires: owner, reason, timestamp, linked evidence snapshot, visible marker, append-only audit entry
- [ ] Audit trail is append-only by design (no mutation, no deletion)
- [ ] Decision signing semantics documented (who signed, what was signed)
- [ ] Evidence snapshot linkage: how decisions reference a specific evidence state
- [ ] Design doc covers: decision lifecycle, state transitions, conflict resolution
- [ ] At least 2 examples: standard merge decision, override with reason
