# 00-134-05: Disclosure audit trail — public/private/confidential labels + audit log

Feature: F134 (sdplab-i01)

## Beads

- sdplab-i6u

## Goal

Delta artifacts and evidence carry public / private / confidential labels; audit log written to beads. EU AI Act transparency requirement.

## Scope Files

- `internal/delta/delta.go` — extend Block with Disclosure field
- `internal/delta/disclosure.go` — NEW: disclosure filter logic
- `internal/delta/disclosure_test.go` — tests

## Design

Extend F134-02 Delta struct: each Added/Modified/Removed block carries Disclosure field:
- `public` — visible in PR description, safe for open-source
- `private` — visible to team, redacted from external view
- `confidential` — visible to approvers only (compliance, security)

`sdp trace` (existing) extended to filter by disclosure level.
Audit log: every gate resolution + delta emission written as beads memory.

## Acceptance Criteria

- [ ] Block struct extended with Disclosure field (public|private|confidential)
- [ ] `FilterByDisclosure(level string) []Block` filters delta blocks
- [ ] Unit tests: filter public only, filter private, empty result for confidential with no blocks
- [ ] `go vet` clean

## Out of Scope

- UI rendering of disclosure levels
- Full audit log implementation (relies on beads integration)
