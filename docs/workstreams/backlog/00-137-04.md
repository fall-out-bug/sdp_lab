# 00-137-04: Shim wrappers + deprecation warnings

Feature: F137 (CLI Surface Normalization)

## Goal

Keep legacy standalone binaries callable during migration while making the deprecation path explicit at runtime and in docs.

## Beads

- sdplab-pg7o.4

## Scope Files

- `cmd/sdp-*/main.go` — thin forwarders for retained legacy binaries in scope
- `scripts/gen_shims.sh` — optional shim generation helper
- `docs/reference/deprecations.md` — deprecation dates, replacements, and grace policy

## Acceptance Criteria

- [ ] Legacy binaries in scope forward to `sdp <subcommand>`
- [ ] Each shim emits an explicit deprecation warning on stderr
- [ ] The grace-period policy is documented in one reference doc
- [ ] Commands classified as `retire` are not silently kept alive

## Out of Scope

- Long-term removal of deprecated binaries
- CLI behavior changes unrelated to forwarding
