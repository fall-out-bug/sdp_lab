# 00-059-01: Pre-tool-call guard hook

Feature: F059 (Ecosystem Synergies)

## Goal

Implement a guard hook that fires before any edit/write/bash tool call in OhMyOpenCode. The hook checks scope boundaries via GUPP (Gas Town Universal Propulsion Principle): "If work on hook, must execute."
