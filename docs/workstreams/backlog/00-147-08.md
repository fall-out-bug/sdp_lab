# 00-147-08: `bd suggest` CLI — read-only suggester

Feature: F147 (MicroFirst Inference Tier)

Design reference: [2026-04-27-f147-microfirst-tier-design.md §3 F147-08](../../plans/2026-04-27-f147-microfirst-tier-design.md)

## Goal

CLI command `bd suggest` (implemented как `cmd/sdp-bd-suggest`) — read-only suggester для `--type` и `--priority` при создании bd issue. Использует BdTypeMicro (00-147-05) и BdSeverityMicro (00-147-04). Ничего не пишет в `.beads/`.

## Acceptance Criteria

- [ ] `sdp-bd-suggest --title="..." --description="..."` возвращает JSON по умолчанию.
- [ ] `--format=human` печатает: type with confidence, priority with confidence, top-3 neighbors.
- [ ] `--escalate` flag: при `Status=Unsure` вызывается LLM (через существующий `internal/llmclient/`); без флага — Unsure остаётся Unsure (escalated=false в output).
- [ ] Никаких записей в `.beads/issues.jsonl` (read-only).
- [ ] `--format=json` schema стабильна (golden test).
- [ ] Coverage ≥ 80%.
- [ ] `go build ./...` and `go vet ./...` clean.

## Out of Scope

- Auto-create issue (`bd suggest --create`) — потенциальный follow-up, не в F147.
- Severity rationale generation (только value+confidence в v1).
