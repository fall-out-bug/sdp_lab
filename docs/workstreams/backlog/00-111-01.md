Feature: F111 (StratAudit portability — engine-adapter-skill split)

## Goal

Убрать из StratAudit жёсткую привязку к concrete `*LLMClient` и hardcoded
OpenRouter CLI path, чтобы engine можно было вызывать из любого harness с
инжектированным model runtime.
