# 00-137-02: Registry core + discovery contract

Feature: F137 (CLI Surface Normalization)

## Goal

Create the canonical CLI registry and the discovery contract that downstream automation can trust.

## Beads

- sdplab-pg7o.2

## Scope Files

- `internal/sdpcli/registry.go` — new command registry types and lookup surface
- `cmd/sdp/main.go` — registry-backed command discovery entrypoint
- `cmd/sdp/cmd_help.go` — help and `--json` discovery output
- `cmd/sdp/cmd_version.go` — version metadata with `registry_hash` and compatibility fields

## Acceptance Criteria

- [ ] A registry exists as the source of truth for commands in scope
- [ ] `sdp help --json` returns machine-readable command discovery output
- [ ] `sdp version` exposes compatibility metadata needed by downstream automation
- [ ] Commands absent from the registry are clearly treated as out of scope or legacy
- [ ] Tests cover registry listing, lookup, and discovery output

## Out of Scope

- Migrating every command onto the registry
- Shim generation
- MCP exposure
