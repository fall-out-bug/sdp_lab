# 00-124-01: Bootstrap Planner and Dry-Run

Feature: F124 (Toolkit Bootstrap — brownfield-safe agent setup)

## Goal

Build the non-destructive planning surface for bootstrap so users can see what SDP will generate before any file is created or changed.

## Beads

- sdplab-25nr

## Scope Files

- `internal/bootstrap/bootstrap.go`
- `internal/bootstrap/collector.go`
- `internal/bootstrap/commands.go`
- `internal/bootstrap/types.go`
- `internal/bootstrap/bootstrap_test.go`
- `cmd/sdp/cmd_bootstrap.go`

## Acceptance Criteria

- [ ] bootstrap can discover available `.sdp/` inputs and repo conventions before mutating files
- [ ] `sdp bootstrap --dry-run` shows what will be generated or merged
- [ ] `sdp bootstrap status` explains current bootstrap state and missing inputs
- [ ] collector degrades gracefully when metrics, index, spec, or architect artifacts are absent
- [ ] no file mutation happens before the plan or dry-run result is available

## Out of Scope

- CLAUDE.md or AGENTS.md merge behavior
- hooks and policies
- verification gates

## Implementation Notes

- Design source: `docs/plans/2026-04-13-sdp-bootstrap-design.md`
- Plan source: `docs/plans/2026-04-13-sdp-bootstrap-implementation-plan.md`
- Brownfield safety starts here. If the dry-run is weak, the whole feature is unsafe.
