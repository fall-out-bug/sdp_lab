# 00-164-06: MCP and write-tool policy checks

Feature: F164 (sdplab-9wxx)

## Goal

Ensure untrusted content cannot induce unauthorized write-capable MCP or tool calls in SDP-controlled mappings.

## Beads

- sdplab-9wxx.6

## Scope Files

- `internal/mcp/tools.go`
- `internal/mcp/tools_test.go`
- `internal/mcp/contract/mapping.go`
- `internal/mcp/contract/mapping_test.go`
- `docs/reference/sdp-mcp.md`
- `.pi/extensions/sdp.ts`
- `schema/contracts/cli-mcp-mapping.json`

## Dependencies

- 00-164-01
- 00-164-02

## Acceptance Criteria

- [ ] SDP-controlled MCP/write tools are classified as read or write capable.
- [ ] Duplicate or ambiguous tool names fail validation.
- [ ] Untrusted MCP resource or tool-description text cannot authorize a write call.
- [ ] Read-then-write chains require trusted authorization for the write step.
- [ ] Tests use mock/sandbox traces and do not depend on arbitrary third-party MCP server behavior.
- [ ] `go test ./internal/mcp/...` passes.

## Out of Scope

- Securing arbitrary third-party MCP servers.
- Broad filesystem sandbox implementation.
- Changing user-authored third-party `.pi` extensions.
