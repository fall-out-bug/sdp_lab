# 00-134-07: Phase-first skills + gate.md paired skill (SDP compliance path)

Feature: F134 (sdplab-i01)

## Beads

- sdplab-sm6

## Goal

Create phase-first skills for SDP Flow 2 compliance path + shared gate paired skill.

## Scope Files

- `.agents/skills/plan-phase.md` — NEW
- `.agents/skills/review-phase.md` — NEW
- `.agents/skills/eval-phase.md` — NEW
- `.agents/skills/gate.md` — NEW: shared boundary skill

## Design

Each phase skill: direct 1:1 mapping to phase command. Structure: MUST DO, MUST NOT DO, Response Format.
- `plan-phase.md` — invokes sdp plan, artifact: plan.delta.md, gate: human approval
- `review-phase.md` — invokes sdp review, NOT code-review
- `eval-phase.md` — invokes sdp eval, quality gate aggregation + attestation

`gate.md` — paired skill invoked by ANY phase skill at boundary:
1. How to emit delta artifact
2. How to open gate (bd human or SDP gate command)
3. How to wait for resolution
4. How to read gate verdict and continue or stop

Naming: `-phase` suffix disambiguates from F125 intent skills.

## Acceptance Criteria

- [ ] 4 new skill files, each <= 100 lines
- [ ] Frontmatter: `compatibility: [claude-code, opencode, cursor, codex]`
- [ ] `sdp-protocol-check --lint-skills` green (if available)
- [ ] gate.md defines boundary protocol shared by all phase skills

## Out of Scope

- Updates to F125 intent skills (F134-06)
