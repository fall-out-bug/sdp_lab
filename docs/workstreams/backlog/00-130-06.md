# 00-130-06: Greenfield Mode — Spec Kit-inspired Interactive Bootstrap

Feature: F130 (sdplab-9nb)

## Goal

Interactive bootstrap for new projects. Spec Kit constitution pattern: ask questions, generate PRINCIPLES.md + AGENTS.md from answers.

## Beads

- sdplab-gi2

## Scope Files

- `internal/bootstrap/greenfield.go` — new: interactive question flow
- `internal/bootstrap/greenfield_test.go` — new: tests
- `internal/bootstrap/questions.go` — new: question definitions

## Acceptance Criteria

- [ ] Interactive flow asks: project type, primary language, test strategy, CI preference, deployment target
- [ ] Generates DRAFT-PRINCIPLES.md and DRAFT-AGENTS.md (F130-09 contract)
- [ ] Non-interactive mode: `--preset go-web-service` skips questions with defaults
- [ ] Answers are stored in `.sdp/bootstrap-answers.json` for reproducibility
- [ ] Unit tests: each preset produces deterministic output

## Out of Scope

- Brownfield mode (F130-07)
- Auto-commit (forbidden by F130-09)

## Implementation Notes

- Use `survey` or simple bufio.Scanner for interactive input
- Presets map to `GreenfieldConfig` struct
- Output files are prefixed with DRAFT- per F130-09 contract
