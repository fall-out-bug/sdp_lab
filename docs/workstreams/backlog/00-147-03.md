# 00-147-03: Ollama embedding client + k-NN library

Feature: F147 (MicroFirst Inference Tier)

Design reference: [2026-04-27-f147-microfirst-tier-design.md §3 F147-03](../../plans/2026-04-27-f147-microfirst-tier-design.md)

## Goal

Shared infrastructure for embedding-based micro-classifiers: Ollama embeddings client (POST /api/embeddings) + k-NN library (cosine similarity, top-k retrieval over labeled corpus). Reused by 00-147-04 (BdSeverity), 00-147-05 (BdType), 00-147-06 (RoutingColdStart).

## Scope Files

- `internal/inference/microfirst/embed/ollama.go` — new. `OllamaEmbedder{baseURL, model, httpClient}` with `Embed(ctx, text) ([]float64, error)`.
- `internal/inference/microfirst/embed/cache.go` — new. In-memory LRU cache for corpus embeddings (avoid re-embedding on every classify call).
- `internal/inference/microfirst/knn/knn.go` — new. Generic `Index[Label]` with `Add(vec, label)`, `Query(vec, k) []Match[Label]`. Cosine distance.
- `internal/inference/microfirst/knn/classify.go` — new. `MajorityVote[Label](matches []Match[Label], minTop1 float64) (Label, confidence, status)` helper.
- `internal/inference/microfirst/embed/ollama_test.go` — new. HTTP server mock for /api/embeddings.
- `internal/inference/microfirst/knn/knn_test.go` — new. Property tests on cosine, top-k correctness, majority voting.

## Acceptance Criteria

- [ ] `OllamaEmbedder.Embed` returns float64 vector for input string; configurable model (default `bge-small-en-v1.5`).
- [ ] HTTP errors / 4xx / 5xx surfaced with wrapped error.
- [ ] Embedding cache: same text → same vector without HTTP call (cache hit metric available).
- [ ] `knn.Index` Add/Query: O(n) cosine over corpus, top-k correct on synthetic vectors.
- [ ] `MajorityVote`: top-1 score >= minTop1 AND top-3 unanimous → `Status=OK`; else `Status=Unsure`.
- [ ] Coverage ≥ 85%.
- [ ] `go build ./...` and `go vet ./...` clean.
- [ ] No new external dependencies beyond stdlib (HTTP/json).

## Out of Scope

- Persistent embedding storage (in-memory only in v1).
- ANN / HNSW / faiss — exact O(n) cosine is enough at corpus sizes ≤ 10k.
- Embedding model fine-tuning / training.
- Specific classifiers (→ 00-147-04..06).
