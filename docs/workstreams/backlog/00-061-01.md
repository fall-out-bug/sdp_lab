# 00-061-01: SQL dependency query

Feature: F061 (Beads Graph Integration)

## Goal

Implement SQL-based dependency query for Beads issues. `SELECT ready FROM issues WHERE no blockers` translates to `sdp ready` command output.

- [ ] Return ready WS IDs sorted by priority
