# 00-130-04: Harness Adapter Layer — Rules to Harness Config

Feature: F130 (sdplab-9nb)

## Goal

Create `internal/harnessadapter/` package that transforms rules + scout.Report into harness-specific config files. One source, N outputs.

## Beads

- sdplab-dk1

## Scope Files

- `internal/harnessadapter/adapter.go` — new: Adapter interface + implementations
- `internal/harnessadapter/adapter_test.go` — new: tests
- `internal/harnessadapter/claude.go` — new: CLAUDE.md renderer
- `internal/harnessadapter/cursor.go` — new: .cursorrules renderer
- `internal/harnessadapter/agents.go` — new: AGENTS.md renderer

## Acceptance Criteria

- [ ] `Adapter` interface with `Render(report scout.ProjectCard, rules []rules.Rule) ([]byte, error)`
- [ ] Implementations for Claude Code (CLAUDE.md section), Cursor (.cursorrules), AGENTS.md
- [ ] Preserves existing content (append/update, never overwrite)
- [ ] Uses `internal/harnesscfg/manifest.go` for file paths
- [ ] Unit tests: given fixed report+rules, output is deterministic

## Out of Scope

- OpenCode adapter (defer)
- Codex adapter (defer)
- Bootstrap wiring (F130-05)

## Implementation Notes

- Reuse `harnesscfg.Manifest` for path resolution
- Each adapter emits a section/snippet, not a full file
- Use `internal/harnesscfg/manifest.go` (101 LOC) as path source
