# 00-117-03: Document Correspondence Read Model

Feature: F117 (StratAudit — claim-centric trace explorer and tabbed analyst report)

## Goal

Сделать документный анализ понятным: показать, какие документы чему
соответствуют, через какие claims и где correspondence подтверждён или сломан.

## Beads

- sdplab-oqsf

## Scope Files

- `internal/strataudit/model/document.go` — document-level analysis fields where needed
- `internal/strataudit/report/json.go` — `document_views` contract
- `internal/strataudit/report_builder.go` — document correspondence aggregation
- `internal/strataudit/report/html.go` — consume document view without UI heuristics
- `internal/strataudit/analyze_test.go` — correspondence aggregation cases
- `internal/strataudit/report/json_test.go` — shape tests for document view

## Acceptance Criteria

- [x] у каждого документа есть explainable list upstream/downstream corresponding docs
- [x] correspondence выводится из claims, edges и gaps, а не из ручных summary strings
- [x] document view показывает extracted claims, verified links, broken links и blockers
- [x] report отвечает на вопрос "что чему соответствует" без перехода в debug JSON
- [x] tests фиксируют устойчивую correspondence модель на mixed-level corpus

## Out of Scope

- Cross-run compare
- HTML tab shell
- Link-stage diagnostics taxonomy

## Implementation Notes

- Документ — это entry surface, но не trace unit. `WS-03` должен оставаться агрегатом над claim graph, а не подменять его.
