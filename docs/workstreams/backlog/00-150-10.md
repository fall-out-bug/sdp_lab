# 00-150-10: Debt ledger and release readiness report

Feature: F150 (Product Layering And Release Readiness)

Design reference: [2026-04-27-f150-product-layering-release-readiness-design.md](../../plans/2026-04-27-f150-product-layering-release-readiness-design.md)

## Goal

Close F150 with an explicit readiness report: what changed, what is release-ready, what remains lab-only, what was deferred, and which Beads own remaining work.

## Beads

- sdplab-3uep (F150-10: produce debt ledger and release readiness report)

## Scope Files

- `docs/reviews/` or `docs/reference/` readiness report path selected during execution
- Beads queue
- `docs/workstreams/INDEX.md`
- `docs/roadmap/ROADMAP.md`

## Acceptance Criteria

- [ ] Readiness report lists shipped changes with evidence.
- [ ] Remaining debt is linked to Beads IDs.
- [ ] Lab-only surfaces are explicitly named.
- [ ] Release blockers are separated from non-blocking debt.
- [ ] F150 completion criteria are evaluated honestly.

## Out of Scope

- Closing deferred Beads prematurely.
- Tagging a release.
- Publishing a Homebrew tap.
