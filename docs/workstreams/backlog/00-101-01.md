# 00-101-01: Write Plan Emission and Confirmation

Feature: F101 (Write Boundaries)

## Goal

Add write plan emission to all stateful skills: before execution, show list of files to CREATE/MODIFY/DELETE and ask for confirmation. Support --dry-run (plan only), --yes (skip confirmation for CI). Log write plan to .sdp/log/events.jsonl.
