# 00-161-03: Pi model review and synthesis

Feature: F161 (sdplab-tffu)
Parent bead: sdplab-tffu.3

## Goal

Invoke local `pi` as the model runtime for the review panel, normalize GLM and Kimi outputs, use OpenRouter fallback when needed, and synthesize SDP-prioritized findings.

## Beads

- sdplab-tffu.3

## Scope Files

- internal package for `pi` process invocation
- model panel config resolution
- model output normalization
- synthesis prompt and parser
- `.sdp/runs/pi-review/<run_id>/models/*.json`
- `.sdp/runs/pi-review/<run_id>/synthesis.json`

## Acceptance Criteria

- [ ] MVP panel runs GLM and Kimi reviewer slots through `pi`.
- [ ] Provider keys and subscriptions are read only by `pi`, not SDP.
- [ ] OpenRouter fallback is attempted only when a required reviewer fails or times out.
- [ ] Raw model output is persisted with provider, model, slot, status, latency, and usage when available.
- [ ] Synthesizer maps findings to SDP priorities `P0` through `P3`.
- [ ] `P0` and `P1` findings block clean verdict.
- [ ] Conflicting `P0` or `P1` model conclusions escalate instead of being silently averaged.

## Out of Scope

- Direct provider SDKs inside SDP.
- Model-written code fixes.
- Non-review agent behavior in `pi`.
