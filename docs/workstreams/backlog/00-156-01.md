# 00-156-01: Land arch-snap promotion gate

Feature: F156 (sdplab-jhef)
Parent bead: sdplab-jhef.1

## Goal

Satisfy the four-condition promotion gate that unlocks active IIP development for arch-snap. Until all four are met, no code work is permitted for arch-snap.

## Beads

- sdplab-jhef.1

## Promotion Gate — all four required

1. **Named IIP lead** — individual (not team) who owns delivery, commercial validation, and extraction readiness
2. **`commercial_hypothesis.md`** — exists in the arch-snap module root with: target ICPs (named), pricing-model hypothesis, top 3 competitors, expected WTP range, kill criteria
3. **≥3 discovery interviews** — documented in `docs/strategy/commercial-discovery/arch-snap-<date>-<org>.md`
4. **F158 import-path decision applied** — the chosen option (A/B/C) is applied to arch-snap module structure before first line of production code

## Scope Files

- `arch-snap/commercial_hypothesis.md` — IIP commercial hypothesis (gate condition 2)
- `docs/strategy/commercial-discovery/arch-snap-*.md` — interview records (gate condition 3)
- `arch-snap/BRAND.md` — brand transfer plan (created at promotion)

## Acceptance Criteria

- [ ] Named lead documented (person, not team) in arch-snap module README or beads update
- [ ] `commercial_hypothesis.md` exists and covers all required fields
