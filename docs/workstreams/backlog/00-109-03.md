# 00-109-03: Provenance Layer — Documents, Sections, Quote Spans

Feature: F109 (StratAudit v2 — evidence-backed report redesign)

## Goal

Добавить в StratAudit first-class provenance между документом, разделом,
цитатой и сущностью, чтобы любой вывод можно было раскрыть до реального места в
исходном корпусе.

## Beads

- sdplab-s33

## Scope Files

- `internal/strataudit/model/document.go` — расширение document metadata
- `internal/strataudit/model/section.go` — новый тип section/chunk provenance
- `internal/strataudit/model/entity.go` — binding к section и quote span
- `internal/strataudit/ingest.go` — фиксация section metadata при ingest/chunking
- `internal/strataudit/store.go` — таблицы/запросы для documents, sections, quote spans
- `internal/strataudit/report_builder.go` — подъем provenance в report model
- `internal/strataudit/ingest_test.go` — section/chunk persistence tests
- `internal/strataudit/store_test.go` — round-trip tests для section/span references

## Acceptance Criteria

- [ ] section/chunk представлен как отдельная модель с `document_id`, `ordinal`, offsets и preview
- [ ] verified entity ссылается минимум на `document_id`, `section_id` и quote/span reference
- [ ] store умеет загрузить sections и quote spans без обращения к исходному SQLite вручную
- [ ] document link можно восстановить до реального пути исходного файла
- [ ] tests подтверждают, что provenance переживает полный ingest/store/load цикл

## Out of Scope

- Визуальный trace explorer
- Cross-document canonical section IDs
- OCR и восстановление сканов

## Implementation Notes

- Без WS-03 нельзя честно показывать coverage по разделам и документам.
- Если section parser не уверен, это отдельный `quality_flag`, а не повод молча терять provenance.
