# 00-134-02: Delta artifact emitter — OpenSpec-style ADDED/MODIFIED/REMOVED per phase

Feature: F134 (sdplab-i01)
Beads: sdplab-tk7

## Goal

Each phase produces `phase-<name>.delta.md` with OpenSpec-style ADDED / MODIFIED / REMOVED blocks for human review at boundary.

## Scope Files

- `internal/delta/` — NEW package
- `internal/delta/delta.go` — Delta struct + renderer
- `internal/delta/delta_test.go` — tests

## Design

Delta struct:
```go
type Delta struct {
    Phase     string
    Timestamp time.Time
    Added     []Block
    Modified  []Block
    Removed   []Block
    Rationale string
}
type Block struct {
    Title       string
    Description string
    Files       []string
}
```

Renderer to markdown with frontmatter: phase, feature_id, ws_id, run_id.
Written to `.sdp/phases/<run_id>/<phase>.delta.md`.

## Acceptance Criteria

- [ ] `internal/delta/` package with Delta struct and Markdown renderer
- [ ] Output markdown has YAML frontmatter (phase, feature_id, ws_id, run_id)
- [ ] Unit tests: render empty delta, render with blocks, round-trip parse
- [ ] `go vet` clean

## Out of Scope

- Disclosure labels on blocks (F134-05)
- CLI command integration (F134-01)
