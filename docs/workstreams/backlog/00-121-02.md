# 00-121-02: Delivery Hygiene Analyzers

Feature: F121 (Toolkit Metrics — git-derived process health)

## Goal

Implement the first four metrics categories so SDP can report whether a repo has disciplined delivery behavior before any agent starts making changes.

## Beads

- sdplab-aiyg

## Scope Files

- `internal/metrics/hygiene.go`
- `internal/metrics/waste.go`
- `internal/metrics/gitflow.go`
- `internal/metrics/release.go`
- `internal/metrics/hygiene_test.go`
- `internal/metrics/waste_test.go`
- `internal/metrics/gitflow_test.go`
- `internal/metrics/release_test.go`

## Acceptance Criteria

- [x] commit hygiene metrics report commit size, commit quality, and batchiness signals
- [x] wasted-work metrics quantify churn, reverts, and abandoned changes
- [x] git-flow detection distinguishes likely branch models from actual history
- [x] release-quality metrics describe release cadence and instability from tags/merges
- [x] tests use synthetic git histories to prove the analyzers match expected patterns

## Out of Scope

- knowledge-risk and code-decay categories
- CLI markdown rendering
- intent-layer synthesis
