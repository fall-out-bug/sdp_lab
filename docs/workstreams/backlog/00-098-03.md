# 00-098-03: Risk-Aware @review

Feature: F098 (Simplified Progressive Disclosure)

## Goal
Add risk-based review depth allocation alongside LOC tiers while keeping all 7 reviewers always present. File path patterns force specific reviewers into deep review: auth/crypto → security + qa, CI/deployment → devops + sre, DB/migrations → sre + security. Configurable reviewer depth rules live in `.sdp/config.yml`.

## Beads

- sdplab-ns9k: historical shipped feature anchor for F098 (PR #89)

## Scope Files
- `sdp/prompts/skills/review/SKILL.md` — add risk-based logic
- `sdp/.sdp/config.yml` — risk pattern configuration

## Acceptance Criteria
- [x] `@review` always emits all 7 reviewer roles in the verdict contract
- [x] `<50 LOC` non-risk change keeps all 7 reviewers present, with deep review defaulting to `qa` + `techlead`
- [x] auth/crypto paths force `security` + `qa` into deep review regardless of LOC tier
- [x] CI/deployment paths force `devops` + `sre` into deep review regardless of LOC tier
- [x] LOC tiers, risk patterns, and `--full` / `--quick` depth overrides are configurable in `.sdp/config.yml`

## Out of Scope
- Changes to reviewer agent definitions
- Automatic risk classification beyond path patterns
