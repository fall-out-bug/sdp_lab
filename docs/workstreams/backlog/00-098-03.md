# 00-098-03: Risk-Aware @review

Feature: F098 (Simplified Progressive Disclosure)

## Goal
Add risk-based reviewer selection alongside LOC tiers. File path patterns trigger additional reviewers: auth/crypto → +security, CI/deployment → +devops, DB migrations → +sre. Configurable risk patterns in .sdp/config.yml.

## Scope Files
- `sdp/prompts/skills/review/SKILL.md` — add risk-based logic
- `sdp/.sdp/config.yml` — risk pattern configuration

## Acceptance Criteria
- [ ] @review on <50 LOC non-risk change → 2 reviewers
- [ ] @review on <50 LOC auth change → 3 reviewers (2 + security)
- [ ] @review --full → all 7 regardless
- [ ] @review --quick → 2 regardless
- [ ] Risk patterns configurable in .sdp/config.yml

## Out of Scope
- Changes to reviewer agent definitions
- Automatic risk classification beyond path patterns
