## Implementation Notes

### Session Store

The `SessionStore` manages ephemeral work items:

```go
store, _ := workstream.NewSessionStore(workstream.SessionStoreConfig{
    BasePath: ".sdp/session",
    TTL:      24 * time.Hour,
})

// Create a wisp
w, _ := store.CreateWisp(workstream.Wisp{
    Title:       "Quick fix needed",
    Description: "Found a typo in docs",
    Type:        "task",
    Labels:      []string{"docs", "urgent"},
})

// List active wisps
wisps, _ := store.ListWisps()

// Expire old wisps
expired, _ := store.ExpireWisps()

// Clear session
store.ClearSession()
```

### Wisp Properties

- `ID`: Auto-generated unique ID
- `Title`, `Description`: Wisp content
- `Type`: task, bug, feature (default: task)
- `Priority`: 1-3 (default: 2)
- `Status`: open, done, blocked (default: open)
- `ExpiresAt`: Auto-set to CreatedAt + TTL
- `Labels`: For categorization
