# 00-110-02: Live Beads Dispatch and Claim Revalidation for Bound Leaf Sessions

Feature: F110 (Work Atomicity Normalization — strict leaf execution contract)

## Goal

Implement the runtime Beads contract for normalized leaf dispatch so the mini-harness stops treating static lock validation as sufficient execution authority. This slice must query bound issues live, resolve the active issue at runtime, claim it, revalidate immediately, persist the claimed issue in the session store, and expose an explicit release path.

## Acceptance Criteria

- [ ] Runtime Beads adapter can query the full bound issue set and fails closed on incomplete or invalid payloads.
- [ ] Active issue resolution follows `blocking finding > primary > non-blocking finding`.
- [ ] `sdp-harness new` acquires a live claim for the resolved issue, revalidates it, and persists `claimed_issue_id` into the session.
- [ ] `sdp-harness run` refuses to execute when the claim is stale, missing, displaced by another bound issue, or the leaf is no longer executable.
- [ ] `sdp-harness release` explicitly releases the live claim and clears it from session persistence.

## Out of Scope

- Full observability counters and structured log emission for every dispatch failure code.
- Leaf-scoped advisory locking across multiple local processes or hosts.
- Automatic reacquire semantics for an already-created released session.
