# 00-150-07: Telemetry consent and OTEL export contract

Feature: F150 (Product Layering And Release Readiness)

Design reference: [2026-04-27-f150-product-layering-release-readiness-design.md](../../plans/2026-04-27-f150-product-layering-release-readiness-design.md)

## Goal

Make external telemetry export explicit, consent-based, and OTEL-compatible. Local trace storage may exist by default; outbound export must not.

## Beads

- sdplab-crct (F150-07: define telemetry consent and OTEL export)

## Scope Files

- `cmd/sdp/cmd_telemetry.go`
- `internal/trace/`
- `schema/telemetry/sdp-trace-events.schema.json`
- `docs/reference/telemetry-schema.md`
- telemetry-related configs or scripts

## Acceptance Criteria

- [ ] Export requires explicit consent.
- [ ] Export requires an explicit OTEL collector endpoint.
- [ ] Default behavior does not contact external collectors.
- [ ] Consent levels gate content export.
- [ ] Docs include enable, inspect, and disable paths.

## Out of Scope

- Building a dashboard.
- Sending telemetry to a hosted service by default.
- Broad F140 telemetry redesign.
