# 00-162-01: Prompt bundle manifest schema and resolver contract

Feature: F162 (sdplab-wuaa)
Parent bead: sdplab-wuaa.1

## Goal

Define the prompt bundle contract before implementation so harness/model/role
routing is deterministic and auditable.

## Beads

- sdplab-wuaa.1

## Scope Files

- `sdp.manifest.yaml`
- `internal/manifest/schema.json`
- `internal/manifest/manifest.go`
- `docs/plans/2026-04-29-f162-system-level-prompt-bundle-packaging-design.md`

## Acceptance Criteria

- [ ] `sdp.manifest.yaml` supports a `prompt_bundles` section with explicit harness, model/profile, role, task_class, ordered sections, and output path fields.
- [ ] `internal/manifest/schema.json` validates the new bundle fields and rejects empty selectors.
- [ ] Go manifest types represent prompt bundles without breaking existing manifest parsing.
- [ ] Resolver behavior is specified for no match, multiple matches, missing sections, and project overlays.
- [ ] Bundle output includes id, hash, source paths, and diagnostics.

## Out of Scope

- Generating harness files.
- Launching agents.
- Rewriting existing prompt content.
