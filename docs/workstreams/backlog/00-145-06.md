# 00-145-06: OllamaProvider — replaces LocalConfig (clean migration)

Feature: F145 (Multi-Provider Dispatch Matrix & Confidence-Driven Cascade)

Design reference: [2026-04-26-f145-multi-provider-dispatch-cascade-design.md §4.6](../../plans/2026-04-26-f145-multi-provider-dispatch-cascade-design.md)

## Goal

Формализовать Ollama как Provider, удалить хардкод-каркас `LocalConfig` из [internal/dispatch/local.go](../../../internal/dispatch/local.go) и [internal/dispatch/route.go](../../../internal/dispatch/route.go) special-case. Один PR, чистый break, никаких deprecation aliases.

## Scope Files

- `internal/dispatch/harness/providers/ollama.go` — new. `OllamaProvider struct{ host string }`, `Name() = "ollama"`. `Models()` через `ollama list` subprocess (cached TTL=5min). `CheckLimits` всегда возвращает unlimited (`Total: 999999, Used: 0, Source: "local"`) — local model, no rate cap.
- `internal/dispatch/harness/providers/ollama_test.go` — new. Tests: `Models()` парсит `ollama list` output на fixture; CheckLimits возвращает unlimited.
- `internal/dispatch/harness/providers/testdata/ollama_list.txt` — new. Fixture: `qwen2.5-coder:7b`, `llama3.2:3b`, etc.
- `internal/dispatch/local.go` — DELETE. Logic переносится в OllamaProvider.
- `internal/dispatch/local_ollama.go` — DELETE. Logic переносится в OllamaProvider + harness.OpenCodeHarness.
- `internal/dispatch/local_test.go` — DELETE.
- `internal/dispatch/local_ollama_test.go` — DELETE.
- `internal/dispatch/route.go` — MODIFY. Удалить `LocalConfig` field, special-case инжекцию (`if r.LocalConfig != nil ...`). Local-tier теперь обычный профиль.
- `internal/dispatch/route_test.go` — MODIFY. Тесты на инжекцию local profile удалить, заменить на тесты с обычными профилями `tier_class=local`.
- Все callsites `LocalConfig` в коде (через `rg LocalConfig internal/`) — MODIFY. Замена на профиль через `Router.Profiles`.
