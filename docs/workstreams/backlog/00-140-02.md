# 00-140-02: `sdp trace` CLI + session-lifetime daemon (TEL-02)

Feature: F140 (AI SDLC Telemetry v1 — MVP)

Design reference: [2026-04-22-ai-sdlc-telemetry-design.md §10.2 / §10.3 / §10.5](../../plans/2026-04-22-ai-sdlc-telemetry-design.md)

## Goal

Cross-harness `sdp trace` Go CLI that is the sole emitter interface, plus a session-lifetime daemon backing it over a Unix domain socket. Resolves Critic P0 (allowlist emit-site enforcement) + Engineer P0 (concurrent-safe span registry).

## Beads

- sdplab-0wi3 (F140-02: sdp trace CLI + session-lifetime daemon)

## Scope Files

- `cmd/sdp/trace/` — new subcommand package: `init`, `span-start`, `span-end`, `event`, `shutdown`, `daemon`.
- `internal/trace/daemon/` — new. Session daemon listening on `~/.sdp/sockets/trace-<session_id>.sock` (0600). Holds in-memory `HashMap<(trace_id, tool_call_id), SpanHandle>`. Sole writer to `.sdp/traces/YYYY-MM-DD/spans.jsonl` with `O_APPEND`.
- `internal/trace/client/` — new. Unix-socket RPC client, length-prefixed JSON; <5 ms round-trip budget.
- `internal/trace/semconv_mapping.go` — new. Single-file abstraction mapping SDP verbs (`--phase build --cycle 2 --verdict APPROVED`) to OTel GenAI semconv v1.36 attribute names. All semconv drift is absorbed here.
- `internal/trace/consent/` — new. Reads `SDP_TRACE_CONSENT` env (`metadata|findings|content`). Emit-site allowlist gate per `schema/sdp-trace-events.schema.json` (TEL-01).
- `internal/trace/bead/` — new. Resolves `sdp.epic.bead_id` canonically from `.sdp/state/current-feature`; fails loud (exit 2) if missing.
- `internal/trace/rotate.go` — new. Rotation helper: on SessionEnd or day boundary, compress previous day's `.jsonl` with `zstd -3 --rm`. Never touches live-write file.
- `scripts/install-sdp-trace.sh` — optional; documents SessionStart hook to autostart daemon.
- Tests: `internal/trace/*_test.go` including concurrency stress test (100 parallel PreToolUse/PostToolUse pairs, no dropped/mis-correlated spans).

## Acceptance Criteria

- [ ] `sdp trace init --feature <bead_id>` writes root span, generates TRACEPARENT, persists session metadata to `.sdp/traces/current.env`.
- [ ] `sdp trace span-start --kind tool --name Bash --tool-call-id <id>` + matching `span-end --tool-call-id <id>` correlate correctly under 100-way concurrency.
- [ ] Daemon round-trip latency p99 <5 ms on benchmark fixture (1000 span-starts).
- [ ] Emit-site allowlist: attempting to emit an attribute absent from `schema/sdp-trace-events.schema.json` exits non-zero with message naming the offending attribute.
- [ ] `SDP_TRACE_CONSENT=metadata` drops `gen_ai.prompt`, `gen_ai.completion`, `tool.input.*`, `tool.output.*`, snippet bodies. Replaced with `sha1(value)[:8]` hash where applicable.
- [ ] Missing `.sdp/state/current-feature` causes `sdp trace init` to exit 2 with remediation message.
- [ ] `sdp.epic.bead_id` attached as **span attribute** per span (not resource attribute).
- [ ] Live-write file is plain `.jsonl`; rotation produces `.jsonl.zst` for prior days only; live file never compressed.
- [ ] SessionEnd hook / `sdp trace shutdown --flush` closes socket, flushes file, optionally rotates.
- [ ] `verify_trace_attrs.sh` (TEL-01) passes against real `sdp trace` fixtures.
- [ ] Concurrency stress test in Go test suite; no dropped spans, no mis-correlation.
