# 00-108-03: `LiveGateway` в `internal/agentloop/livegw`

Feature: F108

## Goal

Создать `internal/agentloop/livegw.LiveGateway` — production-реализацию `agentloop.ModelGateway` через `llmclient.Stream()`. Полный цикл конвертации: `[]agentloop.Message` → SSE → `<-chan agentloop.Event`.

## Beads

- sdplab-uog5

## Scope Files

- `internal/agentloop/livegw/livegw.go` — создать
- `internal/agentloop/livegw/livegw_test.go` — создать

## Acceptance Criteria

- [ ] `livegw.New(apiKey, baseURL string) (*LiveGateway, error)` — возвращает ошибку при пустом `apiKey`
- [ ] `LiveGateway` implements `agentloop.ModelGateway` (compile-time check: `var _ agentloop.ModelGateway = (*LiveGateway)(nil)`)
- [ ] `IsAvailable(model string) bool` — не делает сетевых вызовов; возвращает `true` если ключ установлен
- [ ] `Call()` маппинг: `text_delta` → `agentloop.Event{Type:"text_delta"}`, `tool_call` → `agentloop.Event{Type:"tool_call", ToolCalls:[...]}`, `finish` → `turn_end` + `done`, `error` → `agentloop.Event{Type:"error"}`
- [ ] `cfg.Tools` передаются в `llmclient.ChatRequest.Tools`
- [ ] `go test ./internal/agentloop/livegw/... -race` PASS с `httptest.Server`
- [ ] `go build ./...` без ошибок

## Out of Scope

- Tool execution (LiveGateway только эмитирует tool_call события, не выполняет инструменты)
- Retry (это задача Harness)
- Multi-tool-call в одном ответе (поддерживается через аккумулятор из llmclient)
