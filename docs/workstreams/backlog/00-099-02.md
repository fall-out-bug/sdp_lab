# 00-099-02: Disabled Gates on Adoption

Feature: F099 (Brownfield Safe Overlay)

## Goal

When `sdp adopt` (from F097) creates .sdp/config.yml, set adoption_mode: true which disables quality gates (file size, coverage, TDD). Evidence logging stays enabled (lightweight, non-blocking). `sdp adopt --full` enables all gates when ready.

## Beads

- sdplab-20

## Scope Files

- `sdp/sdp-plugin/internal/gate/` — read adoption_mode, skip gates when true
- `sdp/sdp-plugin/cmd/sdp/` — adopt subcommand --full flag

## Acceptance Criteria

- [ ] At adoption_mode: true, @build executes without quality gate failures on legacy code
- [ ] Evidence events still logged to .sdp/log/events.jsonl
- [ ] sdp adopt --full sets adoption_mode: false, enables all gates
- [ ] sdp doctor shows current adoption mode

## Out of Scope

- Graduation levels 0-3 (F103)
- Language-specific gate commands (F103)
