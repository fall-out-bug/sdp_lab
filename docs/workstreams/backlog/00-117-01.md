# 00-117-01: Claim-Centric Trace Graph Contract

Feature: F117 (StratAudit — claim-centric trace explorer and tabbed analyst report)

## Goal

Сделать claim/entity минимальной explainable единицей трассировки и расширить
`report.v2.json` так, чтобы trace explorer можно было построить офлайн без
обращения к SQLite/store.

## Beads

- sdplab-qmm5

## Scope Files

- `internal/strataudit/model/trace.go` — trace node/edge status semantics
- `internal/strataudit/report/json.go` — additive contract blocks `trace_graph.*`
- `internal/strataudit/report_builder.go` — materialization of nodes/edges/paths
- `internal/strataudit/report/json_test.go` — contract/golden tests for trace graph
- `internal/strataudit/report/testdata/report_v2.golden.json` — frozen additive JSON contract

## Acceptance Criteria

- [x] `report.v2.json` содержит `trace_graph.nodes`, `trace_graph.edges`, `trace_graph.paths`
- [x] каждый node ссылается на entity, document, section, level и source quote
- [x] каждый edge несёт `status`, `verification_mode`, `confidence`, `similarity`, `reason`
- [x] contract остаётся additive поверх `report.v2.json`, без тихого слома текущих потребителей
- [x] HTML/read-model можно построить без прямого чтения SQLite

## Out of Scope

- Gap taxonomy
- Document correspondence aggregation
- HTML tabs and navigation

## Implementation Notes

- Это фундамент `F117`. Если тут останется document-centric модель, весь feature снова уедет в красивую, но слабую витрину.
- Источник: `docs/plans/2026-04-13-strataudit-trace-explorer-design.md`, AD-1..AD-3.
- Выполнено на ветке `codex/F117-strataudit-trace-explorer`: `trace_graph` стал first-class read model с nodes/edges/paths, edge-level evidence refs и contract coverage через builder + golden tests.
