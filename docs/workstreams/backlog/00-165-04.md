# 00-165-04: F165 Report CLI And Safe Output Contract

Feature: F165 (sdplab-28xb)
Phase: Pilot Evidence & Spec Quality
Status: Backlog

## Goal

Add an operator-facing and automation-safe report surface for F165. Typed fields
may be consumed downstream; free-form narrative is explicitly non-authoritative.
The report verdict is a demo/eval verdict only and must not be interpreted as
delivery `ci:pass`, `qa:pass`, `review:pass`, or merge readiness.

## Scope Files

- `cmd/sdp-eval/`
- `internal/evals/`
- `schema/`
- `docs/security/`
- `docs/reference/`

## Beads

- primary: sdplab-f16504

## Dependencies

- 00-165-03

## Acceptance Criteria

- [ ] Report emits typed fields: `case_id`, `verdict`, `blocked_reason`, `trusted_evidence_ref`, and `residual_risk_category`.
- [ ] Report narrative is marked non-authoritative and cannot authorize Beads, Git, PR, CI, or filesystem mutation.
- [ ] Report schema or validation states that F165 verdicts are advisory demo verdicts, not delivery gate verdicts.
- [ ] Report shows naive result, defended result, defense trigger, evidence reference, and residual risk for every case.
- [ ] Report includes a concise operator-facing summary that avoids exploit-style language.
- [ ] Output validation rejects unknown `blocked_reason` and residual-risk category values.
- [ ] Targeted CLI/report tests pass without live providers or network.
