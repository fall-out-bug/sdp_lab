# 00-121-01: Git Ingestion Pipeline and Metrics Contract

Feature: F121 (Toolkit Metrics — git-derived process health)

## Goal

Build the single-pass git ingestion layer and stable `MetricsReport` contract so all later analyzers operate on one deterministic history snapshot.

## Beads

- sdplab-sg5a

## Scope Files

- `internal/metrics/collector.go`
- `internal/metrics/parse.go`
- `internal/metrics/filter.go`
- `internal/metrics/types.go`
- `internal/metrics/collector_test.go`
- `cmd/sdp/cmd_metrics.go`

## Acceptance Criteria

- [x] one collector pass captures the raw commit/change data needed by all seven categories
- [x] generated, bot, and formatting-only noise can be filtered consistently
- [x] `MetricsReport` contract is stable enough for JSON and markdown rendering
- [x] collector tests cover empty repos, single-author repos, and repos without tags
- [x] metrics respect shared exclusion rules where filesystem views matter

## Out of Scope

- category-specific scoring
- `@understand` routing
- index enrichment
