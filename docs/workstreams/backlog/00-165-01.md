# 00-165-01: F165 Fixture Schema And Corpus

Feature: F165 (sdplab-28xb)
Phase: Pilot Evidence & Spec Quality
Status: Backlog

## Goal

Define the sanitized fixture schema and initial corpus for SDP-native indirect
prompt-injection demos. Fixtures must represent Beads issue poisoning,
workstream Markdown poisoning, evidence/finding poisoning, one non-obvious prose
case, and one unsupported/residual-risk case without executable exploit payloads.

## Acceptance Criteria

- [ ] Fixture schema captures case id, vector, trusted operator request, trusted-state snapshot, untrusted artifact, expected unsafe result, expected defended result, evidence expectation, and residual-risk category.
- [ ] Corpus includes Beads issue poisoning, workstream Markdown poisoning, and evidence/finding poisoning cases.
- [ ] Corpus includes at least one non-obvious prose fixture that does not rely on visible `[SANITIZED_*]` markers.
- [ ] Corpus includes at least one `unsupported_surface`, `partial_coverage`, or `not_tested` residual-risk case.
- [ ] Fixtures contain no real external URLs, secrets, live account actions, destructive commands, or reusable offensive instructions.
- [ ] Targeted schema/corpus validation tests pass.
