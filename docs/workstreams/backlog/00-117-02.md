# 00-117-02: Gap Taxonomy and Link Diagnostics

Feature: F117 (StratAudit — claim-centric trace explorer and tabbed analyst report)

## Goal

Превратить молчаливый zero-trace state в явную модель разрыва: где, между какими
уровнями и по какой причине трасса оборвалась.

## Beads

- sdplab-6ztx

## Scope Files

- `internal/strataudit/link.go` — persist candidate/rejection/gap reasons
- `internal/strataudit/analyze.go` — stage-aware gap computation
- `internal/strataudit/store.go` — storage/query support for gap diagnostics
- `internal/strataudit/report_builder.go` — `trace_gaps` export
- `internal/strataudit/link_test.go` — rejection and gap semantics tests
- `internal/strataudit/analyze_test.go` — waterfall and boundary coverage tests

## Acceptance Criteria

- [x] для каждого admitted claim на boundary level существует либо edge, либо `trace_gap`
- [x] `trace_gap` фиксирует `stage`, `gap_type`, `reason`, `expected_to_level`, `candidate_count`
- [x] similarity/candidate rejection reasons не теряются в HTML-only логике
- [x] zero-trace run можно объяснить через gap waterfall без ручного чтения debug logs
- [x] tests покрывают минимум `no_candidates`, `all_candidates_rejected`, `missing_upstream_entities`, `quote_evidence_missing`

## Out of Scope

- Документный correspondence view
- HTML tabs
- Recall fixes на strategy deck'ах
