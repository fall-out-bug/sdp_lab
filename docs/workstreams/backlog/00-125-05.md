# 00-125-05: `@review --mode readiness` verify-before-completion

Feature: F125 (Intent skills)

## Goal

Add `--mode readiness` to existing `@review` intent skill — verify-before-completion semantics. Checks: all tests pass, coverage not below base, docs updated (CHANGELOG/INDEX/ROADMAP matched against git diff), no orphan workstreams, no `TODO`/`FIXME` added.

## Beads

- sdplab-as0

## Scope Files

- `.agents/skills/review.md` — extend with `--mode readiness` section
- `cmd/sdp-review-readiness/main.go` — new CLI backing the intent (or extend existing `sdp-review`)
- `internal/review/readiness.go` — checks library

## Acceptance Criteria

- [ ] Skill frontmatter passes `sdp-protocol-check --lint-skills` (no warnings)
- [ ] `sdp-review --mode readiness` returns JSON report with pass/fail per check
- [ ] Checks: `tests-pass`, `coverage-delta`, `docs-updated`, `no-orphans`, `no-new-todos`
- [ ] Exit code 0 if all pass, 2 if any fail
- [ ] Skill body stays within 100-line limit

## Out of Scope

- Auto-fix for failed checks (readiness is verification-only)
- PR-level vs commit-level scope distinction (single mode initially)
- Integration with F126 MCP (deferred)

## Implementation Notes

readiness check spec:

```
readiness_checks:
  - tests_pass: run test suite; must be green
  - coverage_delta: compare against base; warn if drop >1pp, fail if >2pp
  - docs_updated: if changed files include *.go without matching CHANGELOG entry → fail
  - no_orphans: bd orphans → empty
  - no_new_todos: grep "TODO\|FIXME" in diff → 0
```
