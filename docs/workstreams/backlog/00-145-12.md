# 00-145-12: cascade-replay mode in F144 replay corpus + tier_used metrics

Feature: F145 (Multi-Provider Dispatch Matrix & Confidence-Driven Cascade)

Design reference: [2026-04-26-f145-multi-provider-dispatch-cascade-design.md §6](../../plans/2026-04-26-f145-multi-provider-dispatch-cascade-design.md)

## Goal

Расширить F144 replay corpus и harness `internal/inference/confidence/replay/` так, чтобы можно было прогонять cascade-flow и собирать tier-use метрики (% stayed-on-cheap, % escalated, average tokens). Day-8 acceptance demo живёт здесь.

## Beads

- sdplab-uamt (historical leaf issue)

## Scope Files

- `internal/inference/confidence/replay/cascade.go` — new. `CascadeReplay struct`, `Run(prompts []Prompt, invoker cascade.Invoker) CascadeReport`.
- `internal/inference/confidence/replay/cascade_report.go` — new. `CascadeReport struct{ TotalPrompts, StayedCheap, Escalated, FailedAll int; AvgTokens, AvgLatency float64; PerPrompt []PromptResult }`. CSV export.
- `internal/inference/confidence/replay/testdata/cascade_corpus.yaml` — new. 20+ prompts: simple-coding-easy (10), complex-coding-hard (5), refusal-bait (3), nonsense (2). Поля: `id`, `prompt`, `expected_tier`, `notes`.
- `internal/inference/confidence/replay/cascade_test.go` — new. Mocks cascade.Invoker, проверяет CSV генерацию, group-by-tier counts.
- `cmd/sdp-cascade-replay/main.go` — new. CLI: `sdp-cascade-replay -corpus <yaml> -out <csv>`. Использует реальный CascadingInvoker с замоканными harness'ами для deterministic replay (или real harness через `--live` flag для smoke-режима).
- `docs/reference/cascade-replay.md` — new. Документация: format corpus YAML, CSV columns, как интерпретировать report.

## Acceptance Criteria

- [ ] `cascade_corpus.yaml` содержит ≥20 prompts с распределением по типам.
- [ ] `CascadeReplay.Run` корректно агрегирует `StayedCheap/Escalated/FailedAll` counts.
- [ ] CSV export содержит per-prompt rows + summary row.
- [ ] Mock-mode test (deterministic): для known-easy prompts → ≥40% stayed-cheap; для known-hard → ≥80% escalated.
- [ ] CLI tool работает: `sdp-cascade-replay -corpus testdata/cascade_corpus.yaml -out /tmp/r.csv` производит valid CSV.
- [ ] go build ./cmd/..., go test ./internal/inference/..., go vet clean.

## Out of Scope

- Live-mode integration с реальными harness'ами (требует API keys) — это smoke job в WS 14.
- Dashboard / визуализация report — CSV достаточен.
