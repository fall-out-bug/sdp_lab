# 00-140-05: `sdp usage report` CLI (TEL-07)

Feature: F140 (AI SDLC Telemetry v1 — MVP)

Design reference: [2026-04-22-ai-sdlc-telemetry-design.md §2.2, §10.8 (CLI is default operator path)](../../plans/2026-04-22-ai-sdlc-telemetry-design.md)

## Goal

Operator-facing CLI that prints M1–M7 tables from reducer output. This is the **default surface** — no dashboard, no Grafana in v1. Must be enough for the operator to evaluate hypothesis H1 (does SDP's review loop lower M7 vs baseline?).

## Beads

- sdplab-fh67 (F140-05: sdp usage report CLI)

## Scope Files

- `cmd/sdp/usage/` — new subcommand package.
  - `report.go` — `sdp usage report [--since 7d|30d] [--feature FXXX] [--by-phase] [--json]`.
  - `format.go` — ASCII table rendering + JSON output mode.
- `internal/telemetry/report/` — new. Reads `.sdp/metrics/*.sdp.json`, filters/aggregates per flags.
- `docs/reference/sdp-usage-report.md` — operator-facing reference: flag table, example output, how to read each metric in relation to H1/H2.
- Tests: `cmd/sdp/usage/*_test.go` — table rendering golden files, JSON output schema, `--feature` filter correctness.

## Acceptance Criteria

- [ ] Default invocation (`sdp usage report`) prints last-7-days M1 through M7 as an ASCII table.
- [ ] `--feature FXXX` narrows to a single epic bead.
- [ ] `--by-phase` shows per-phase duration breakdown (M5) with top-5 longest subagent invocations.
- [ ] `--json` emits machine-readable output conforming to a new `schema/sdp-usage-report.schema.json`.
- [ ] Output explicitly labels H1 status: M7 trend direction + confidence note (e.g. "M7 trending down, <8 weeks data — inconclusive").
- [ ] Missing `.sdp/metrics/` directory → friendly error ("run `sdp-telemetry-reducer` first; see TEL-06") instead of stack trace.
- [ ] Exit code 0 on success, 2 on missing data, 3 on malformed metrics file.
- [ ] Golden-file tests pin the ASCII table format for regression stability.

## Out of Scope

- Dashboard integration (DuckDB, Grafana, Langfuse) — v2 parking lot.
- Real-time / streaming views — v2.
- Cross-repo aggregation — v2.
- Per-user leaderboards — anti-goal (§5).
