# 00-129-07: Coverage enforcement gate

Feature: F129 (Autonomous Operations & Regression Hardening)

## Goal

CI gate blocks merge if `go test` coverage drops >2pp from the base branch. Metrics stored in `.sdp/metrics/coverage.txt`.

## Beads

- sdplab-8k5.7

## Scope Files

- `.github/workflows/ci.yml` — new `coverage-gate` job
- `scripts/check_coverage_delta.sh` — threshold checker
- `.sdp/metrics/coverage.txt` — committed baseline

## Acceptance Criteria

- [ ] `coverage-gate` job runs `go test -coverprofile`, extracts total %, compares with base
- [ ] Fails if drop >2pp; warns on 1–2pp drop
- [ ] Writes `.sdp/metrics/coverage.txt` (committed alongside code changes)
- [ ] Initial baseline = current total coverage at implementation time

## Out of Scope

- Per-package thresholds
- Test quality metrics
- Mutation score

## Implementation Notes

`go tool cover -func=cov.out | grep total | awk '{print $3}'`. Use `python3` for the float comparison (`bc` portability is unreliable in CI runners).
