# 00-105-08: TypeScript/JS Extractor (tree-sitter)

Feature: F105 (AI Architect)

## Goal

Implement the TypeScript/JavaScript ecosystem extractor using tree-sitter queries for import resolution, tsconfig.json path mapping, and React/Next.js/NestJS/Express pattern detection.

## Acceptance Criteria

- [ ] tree-sitter queries extract ES module imports with 65-75% accuracy
- [ ] Import types handled: `import X from 'Y'`, `import { X } from 'Y'`, `require('Y')`, dynamic `import('Y')`
- [ ] tsconfig.json resolution: baseUrl, paths aliases, project references
- [ ] React detection: JSX/TSX files, component patterns (function components, class components)
- [ ] Next.js detection: next.config.*, pages/ or app/ directory, getServerSideProps/getStaticProps
- [ ] NestJS detection: @Module, @Controller, @Injectable decorators, module graph
- [ ] Express detection: app.get/post/put/delete route registration, middleware chain
- [ ] Workspace dependencies resolved for npm workspaces, yarn workspaces, pnpm workspaces
- [ ] Known blind spots documented: path aliases (@/), barrel re-exports, dynamic import(), CommonJS require with variables, Webpack module federation

## Out of Scope

- Webpack module federation resolution
- Dynamic import() with variable arguments
- CommonJS require() with computed paths
- Barrel re-export chain resolution (index.ts re-exports)

## Implementation Notes

- From section 1.5: TS/JS uses tree-sitter + tsconfig.json/package.json resolution with 65-75% import accuracy
- Strengths: ES module imports, React/Next.js/NestJS/Express patterns, workspace dependencies
- Blind spots: path aliases, barrel re-exports, dynamic import, CommonJS require with variables, Webpack module federation
- From section 1.5 JS/TS Framework Detection table: each framework has specific detection signals and architectural extraction
- React/Next.js: page routes as API surface, SSR/SSG classification from getServerSideProps/getStaticProps
- NestJS: module graph from @Module imports array, controller routes from @Controller decorators
- Express/Fastify: route table extraction from app.METHOD calls, middleware chain from app.use
- Vue/Nuxt: page routes from pages/ directory, composables as components
- Angular: module dependency graph from @NgModule, service injection
- tsconfig.json parsing: handle extends, compilerOptions.paths (e.g., "@/*": ["src/*"])
