# 00-090-03: Verdict artifacts and findings-aware rerun control

Feature: F090 (Canonical SDP Workflow and Orchestrator Alignment)

## Goal

Turn review and QA verdicts into first-class SDP artifacts and make blocking findings influence rerun control more directly.

## Beads

- sdplab-pglm: F090-03 verdict-artifacts-rerun-control

## Scope Files

- `internal/orchestrate/findings.go`

## Acceptance Criteria

- [x] `.sdp/review_verdict.json` is written on review success and review failure
- [x] `.sdp/qa_verdict.json` is written on `qa:pass` and `qa:fail`
- [x] Verdict artifacts carry `finding_ids` and `blocking_ids` when findings are created
- [x] Blocking findings are used as explicit rerun control, not only surfaced in logs
