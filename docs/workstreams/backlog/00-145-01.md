# 00-145-01: Provider sub-package scaffold + register pattern

Feature: F145 (Multi-Provider Dispatch Matrix & Confidence-Driven Cascade)

Design reference: [2026-04-26-f145-multi-provider-dispatch-cascade-design.md §4.1](../../plans/2026-04-26-f145-multi-provider-dispatch-cascade-design.md)

## Goal

Создать sub-pkg `internal/dispatch/harness/providers/` с пустым `ProviderRegistry`, register/get pattern, и каркасом для последующих Provider impls. Никакой реализации провайдеров в этой WS — только структура.

## Beads

- sdplab-0261 (historical leaf issue)

## Scope Files

- `internal/dispatch/harness/providers/providers.go` — new. `ProviderRegistry struct{}`, `Register(p harness.Provider)`, `Get(name string) harness.Provider`, `All() []string`. Singleton-friendly через package-level default registry + injection-friendly через explicit `NewRegistry()`.
- `internal/dispatch/harness/providers/providers_test.go` — new. Unit tests на register/get/all/duplicate-name.
- `internal/dispatch/harness/providers/doc.go` — new. Пакетная документация: что такое Provider в SDP, contract'ы, относительно `harness.Provider` interface в [harness.go](../../../internal/dispatch/harness/harness.go).

## Acceptance Criteria

- [ ] `providers.ProviderRegistry` имплементирует registry pattern идентичный `harness.Registry` (для consistency).
- [ ] `Register(provider)` overwrite на duplicate name (mirror `Registry.Register`).
- [ ] Default package-level registry доступен через `providers.Default()` для bootstrap из `cmd/sdp-harness/main.go`.
- [ ] `go build ./internal/dispatch/...` passes.
- [ ] `go test ./internal/dispatch/harness/providers/...` passes, coverage ≥85%.
- [ ] go vet clean.

## Out of Scope

- Конкретные Provider impls (OpenAI/Anthropic/Cursor/Kimi/Ollama) — отдельные WS 02..06.
- LimitsCache — WS 13.
- Bootstrap-wiring в `cmd/sdp-harness/main.go` — отдельная маленькая правка в WS 14 (smoke).
