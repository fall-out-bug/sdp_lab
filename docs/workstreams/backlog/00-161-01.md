# 00-161-01: Pi-review contracts and schemas

Feature: F161 (sdplab-tffu)
Parent bead: sdplab-tffu.1

## Goal

Define the stable `sdp pi-review` contract before implementation so the model runtime, verdict file, telemetry, and beads integration do not drift into incompatible shapes.

## Beads

- sdplab-tffu.1

## Scope Files

- `docs/reference/pi-review-spec.md`
- `schema/pi-review-run.schema.json`
- `schema/review-verdict.schema.json`
- `schema/index.json`

## Acceptance Criteria

- [ ] `docs/reference/pi-review-spec.md` describes command behavior, scope selection, model policy, telemetry, beads integration, and delivery-loop rules.
- [ ] `schema/pi-review-run.schema.json` validates the per-run telemetry manifest.
- [ ] `schema/review-verdict.schema.json` remains compatible with existing seven-role `@review` verdicts and adds optional pi-review metadata.
- [ ] `schema/index.json` registers `pi-review-run`.
- [ ] The spec explicitly states that `pi` owns provider subscriptions and keys.
- [ ] JSON schemas parse and compile in the existing schema validation path.

## Out of Scope

- Implementing the runner.
- Adding providers to `pi`.
- Changing `@review` seven-role behavior.
