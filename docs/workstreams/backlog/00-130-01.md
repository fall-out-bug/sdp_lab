# 00-130-01: Config provisioning spec — harness config manifest schema

Feature: F130 (AI Harness Config Auto-Provisioning)

## Beads

- sdplab-6zo

## Goal

Define what "complete harness config" means for a repo. Produce a JSON schema for the config manifest that describes: which files to generate (CLAUDE.md sections, .cursorrules, AGENTS.md language section, codex.yaml), which harnesses to target (Claude Code, Cursor, Codex CLI, OpenCode), which lifecycle stage (greenfield / brownfield-new / brownfield-mature).

## Scope Files

- `schema/harness-config-manifest.schema.json` (new)
- `docs/reference/harness-config-spec.md` (new reference doc)
- `docs/reference/harness-integration.md` (update with provisioning notes)

## Acceptance Criteria

- [ ] JSON schema for config manifest exists and validates
- [ ] Lifecycle stages (greenfield/brownfield-new/brownfield-mature) documented with decision rules
- [ ] Supported harnesses listed with their config file paths
- [ ] Schema includes version field for drift detection
