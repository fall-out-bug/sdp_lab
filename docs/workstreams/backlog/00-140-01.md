# 00-140-01: Trace schema + consent + footprint + pricing (TEL-01)

Feature: F140 (AI SDLC Telemetry v1 — MVP)

Design reference: [2026-04-22-ai-sdlc-telemetry-design.md §10.1 / §10.4 / §6.4](../../plans/2026-04-22-ai-sdlc-telemetry-design.md)

## Goal

Ship the canonical data contract before any emitter or reducer lands: allowlist-based trace event schema, three-tier consent model, disk-footprint envelope with sampling defaults, and checked-in model-pricing table with freshness CI.

## Beads

- F140-01 child bead (linked from epic on creation)

## Scope Files

- `schema/sdp-trace-events.schema.json` — new. Allowlist schema per span kind (`execute_tool`, `invoke_agent`, `delivery_loop.phase_*`, `sdp.bead.event`). Enumerates every allowed attribute and their type.
- `schema/ux-metrics.schema.json` — extend with M1–M7 output fields.
- `docs/reference/telemetry-schema.md` — new. Human-readable reference: consent levels, sampling policy, disk-footprint envelope (light/typical/heavy), what each span kind emits.
- `configs/model_pricing.json` — new. ≥3 Claude models (sonnet, haiku, opus) with `input`/`output`/`unit`/`effective` fields per §6.4.
- `scripts/verify_pricing_freshness.sh` — new. Fails CI if any `effective` date in `model_pricing.json` is older than 60 days. Wired into `run_go_quality_gates.sh`.
- `scripts/verify_trace_attrs.sh` — new. Parses `sdp-trace-events.schema.json`, runs `sdp trace` fixture emitters (stubbed at this WS; TEL-02 fills them), diffs emitted attrs vs schema; fails on any attribute not declared. Wired into `run_go_quality_gates.sh`.

## Acceptance Criteria

- [ ] `sdp-trace-events.schema.json` is an allowlist: every span kind declares its exhaustive attribute list; unknown attributes MUST be rejected by consumers.
- [ ] Three consent levels documented: `metadata` (default), `findings`, `content`.
- [ ] Disk-footprint envelope in `telemetry-schema.md` covers light/typical/heavy loads and zstd compression ratio.
- [ ] Sampling defaults documented: head-based 100 %, tail-based drop for fast-successful Read/Glob/Grep, hash-based for >100 k-span sessions.
- [ ] `model_pricing.json` contains claude-sonnet-4-5, claude-haiku-4-5, claude-opus-4-1 with correct schema.
- [ ] `verify_pricing_freshness.sh` exits 0 for ≤60-day-old entries, exits 1 otherwise; covered by a fixture test.
- [ ] `verify_trace_attrs.sh` passes against fixture emitters; new anchors added to `scripts/verify_skill_anchors.sh` if schema paths are cross-referenced in skills.
- [ ] Both new CI scripts invoked from `scripts/run_go_quality_gates.sh`.

## Out of Scope

- Any `sdp trace` CLI implementation (→ 00-140-02).
- Daemon process or socket protocol (→ 00-140-02).
- Reducer, report CLI (→ 00-140-04 / 00-140-05).
- Dashboard or Collector service (→ v2 parking lot).
