# 00-109-08: Regression Harness on Real Corpus

Feature: F109 (StratAudit v2 — evidence-backed report redesign)

## Goal

Зафиксировать регрессионный контур StratAudit на реалистичном русскоязычном
корпусе или воспроизводимом audit fixture, чтобы trust-проблемы больше не
прятались за "успешный demo run".

## Beads

- sdplab-7r1

## Scope Files

- `internal/strataudit/ingest_e2e_test.go` — realistic corpus ingest regression
- `internal/strataudit/pipeline_test.go` — end-to-end audit invariants for JSON v2
- `internal/strataudit/report/json_test.go` — invariants for provenance/trust fields
- `internal/strataudit/testdata/` — reproducible corpus fixture or minimized golden dataset

## Acceptance Criteria

- [ ] regression падает, если prompt/system strings снова попадают в сущности
- [ ] regression падает, если verified traces теряют evidence bundle
- [ ] regression падает, если JSON/HTML больше не содержат document/section provenance
- [ ] fixture воспроизводим локально без доступа к пользовательскому приватному корпусу
- [ ] test output явно указывает, какая trust-гарантия нарушена

## Out of Scope

- Полная публикация пользовательских документов в репозитории
- Performance benchmarking на всех форматах
- Golden snapshots для каждого HTML-пикселя

## Implementation Notes

- WS-08 защищает реальный продукт от возврата к toy-demo поведению.
- Фикстура должна быть анонимизированной или синтетической, но достаточно грязной, чтобы ловить language drift и provenance regressions.
