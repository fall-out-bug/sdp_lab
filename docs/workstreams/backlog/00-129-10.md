# 00-129-10: Flaky detection + mutation advisory

Feature: F129 (Autonomous Operations & Regression Hardening)

## Goal

Non-blocking advisory: detect flaky tests (retry on fail + compare); mutation testing summary on changed code. Both as CI comments, NOT blocking.

## Beads

- sdplab-8k5.10

## Scope Files

- `.github/workflows/ci.yml` — new `flaky-advisory` and `mutation-advisory` jobs
- `scripts/detect_flaky.sh` — retry-and-compare
- `scripts/mutation_summary.sh` — `go-mutesting` wrapper

## Acceptance Criteria

- [ ] `flaky-advisory` runs failing tests twice; comments on PR if pass rate is not 100% or 0%
- [ ] `mutation-advisory` runs `go-mutesting` on files changed in the PR; comments a summary
- [ ] Neither blocks merge (`continue-on-error: true`)
- [ ] Opt-out flag in commit message: `[skip flaky]`, `[skip mutation]`

## Out of Scope

- Quarantine of flaky tests
- Auto-fix for mutations
- Full-repo mutation (changed files only)

## Implementation Notes

Priority P2 — defer to Phase 3. Don't invest in custom tooling; use existing (`go-mutesting`, standard retry patterns).
