# 00-120-01: Project Card Contract + Shared Exclusions

Feature: F120 (Toolkit Scout — instant repo card for unknown codebases)

## Goal

Define the stable `ProjectCard` contract for `sdp scout` and create one shared exclusion implementation so scout, metrics, and index count the same repository surface.

## Beads

- sdplab-of55

## Scope Files

- `internal/scout/types.go`
- `internal/scout/languages.go`
- `internal/common/exclude.go`
- `cmd/sdp/cmd_scout.go`

## Acceptance Criteria

- [ ] `ProjectCard` covers identity, scale, activity, health, entry points, and build/test/CI hints
- [ ] shared exclusion rules live in one package reused by scout, metrics, and index
- [ ] unknown fields are explicit `unknown` or omitted, not guessed
- [ ] JSON shape for `.sdp/scout.json` is locked by a golden fixture
- [ ] no LLM or network dependency is introduced

## Out of Scope

- repo-specific health scoring policy
- `@understand` routing
- architect integration beyond contract compatibility
