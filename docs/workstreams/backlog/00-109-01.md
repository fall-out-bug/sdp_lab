# 00-109-01: Extraction Trust Gate

Feature: F109 (StratAudit v2 — evidence-backed report redesign)

## Goal

Ввести admission gate для сущностей StratAudit: `source_quote` должен
подтверждаться реальным текстом чанка/документа, а prompt leak и служебный
boilerplate не должны попадать в trusted слой данных.

## Beads

- sdplab-q10

## Scope Files

- `internal/strataudit/extract_llm.go` — валидация `source_quote` и фильтрация leakage
- `internal/strataudit/model/entity.go` — trust-grade и quality flags на уровне entity
- `internal/strataudit/store.go` — хранение trust-статуса и причин downgrade/reject
- `internal/strataudit/pipeline.go` — протаскивание gate verdict через pipeline
- `internal/strataudit/extract_llm_test.go` — негативные кейсы для quote mismatch и prompt leak
- `internal/strataudit/pipeline_test.go` — интеграционный проход через verified/suspect/rejected

## Acceptance Criteria

- [ ] verified entity не создаётся, если `source_quote` не найден в исходном тексте
- [ ] prompt/system strings и повторяющийся boilerplate помечаются как `suspect` или `rejected`
- [ ] entity получает явные `trust_grade` и `quality_flags`
- [ ] pipeline сохраняет counters минимум для `verified`, `suspect`, `rejected`
- [ ] unit/integration tests ловят prompt leak и quote mismatch на реальных фрагментах

## Out of Scope

- UI-отображение trust grades
- Мультиязычная нормализация полей display
- Trace verification
