# 00-161-02: Working-tree context packet and test evidence

Feature: F161 (sdplab-tffu)
Parent bead: sdplab-tffu.2

## Goal

Build the deterministic context packet that `sdp pi-review` sends to `pi`: touched files, diff, project rules, bead context, file hashes, omitted-file metadata, and SDP-captured test evidence.

## Beads

- sdplab-tffu.2

## Scope Files

- `cmd/sdp` or equivalent command surface for `sdp pi-review`
- internal package for context packet collection
- `.sdp/runs/pi-review/<run_id>/context.json`
- `.sdp/runs/pi-review/<run_id>/context.diff`
- `.sdp/runs/pi-review/<run_id>/test-evidence.json`

## Acceptance Criteria

- [ ] `--scope auto` reviews working-tree changes, including untracked files, before falling back to branch diff.
- [ ] `--scope working-tree` includes staged, unstaged, and untracked files.
- [ ] `--scope branch --base <ref>` reviews `<base>...HEAD`.
- [ ] Context packet includes git status, reviewed file list, unified diff, file hashes, and project rules.
- [ ] Oversized packets degrade explicitly and record omitted files.
- [ ] SDP runs test evidence once before model calls and records command, exit code, duration, status, and artifact path.
- [ ] No provider secrets are included in context or telemetry.

## Out of Scope

- Model invocation.
- Beads finding creation.
- Fixing test failures found by the evidence command.
