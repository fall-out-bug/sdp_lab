# 00-145-04: CursorProvider — ~30 моделей через --list-models

Feature: F145 (Multi-Provider Dispatch Matrix & Confidence-Driven Cascade)

Design reference: [2026-04-26-f145-multi-provider-dispatch-cascade-design.md §4.1](../../plans/2026-04-26-f145-multi-provider-dispatch-cascade-design.md)

## Goal

Реализовать `CursorProvider` с каталогом, дёргаемым через `cursor agent --list-models`. Cache на N секунд чтобы не запускать subprocess каждый раз. CheckLimits — stub (Cursor CLI не экспонирует rate-limit endpoint), но Source != "unavailable".

## Beads

- sdplab-bg69 (historical leaf issue)

## Scope Files

- `internal/dispatch/harness/providers/cursor.go` — new. `CursorProvider struct{ cache atomic.Pointer[modelList] }`, `Name() = "cursor"`. `Models()` парсит вывод `cursor agent --list-models` (skip header line "Available models", пустые, парсит `<id> - <description>` пары). Cache TTL=10min. `CheckLimits` возвращает `&Limits{Source: "cursor-cli", CheckedAt: now}` с пустым Total (rate-limit не экспонируется).
- `internal/dispatch/harness/providers/cursor_test.go` — new. Tests: парсер `--list-models` output на fixture (sample real output из design проверки), cache TTL поведение, fallback при отсутствии CLI.
- `internal/dispatch/harness/providers/testdata/cursor_list_models.txt` — new. Fixture с реальным выводом `cursor-agent --list-models` (~30 моделей).

## Acceptance Criteria

- [ ] `Models()` парсит ≥ 25 моделей из fixture (composer-1.5/2/2-fast + gpt-5.x lineup + sonnet-4 + gpt-5).
- [ ] Cache работает: повторный вызов внутри TTL не запускает subprocess.
- [ ] При отсутствии cursor binary — `Models()` возвращает пустой slice + slog.Warn (не panic).
- [ ] go build, go test, go vet clean.
- [ ] Test coverage ≥80% (subprocess execution mocked).
