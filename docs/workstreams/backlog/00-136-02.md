# 00-136-02: Repo-scoped memory core

Feature: F136 (Peer Memory Foundation)

## Goal

Implement `internal/memory/` as the minimal durable core: shared repo-local storage across worktrees, append-only event log, filter/query helpers, and high-confidence secret blocking.

## Beads

- sdplab-lq4h

## Scope Files

- `internal/memory/types.go`
- `internal/memory/store.go`
- `internal/memory/query.go`
- `internal/memory/secrets.go`
- `internal/memory/*_test.go`

## Acceptance Criteria

- [ ] Store root resolves via git common-dir so all worktrees share one memory store
- [ ] Append is concurrent-safe and preserves JSONL integrity
- [ ] Query supports author, type, role, session, and time filters
- [ ] Secret scanner blocks high-confidence credentials but allows benign phrases
- [ ] Unit tests cover append, filters, secrets, and worktree-safe root resolution

## Out of Scope

- CLI wiring
- agentloop integration
- MCP resources

Keep FTS5/index initialization behind the package boundary. H1 needs a boring store, not a framework.
