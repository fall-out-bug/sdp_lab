# 00-093-01: Reality-Pro external docs and ADR ingestion

Feature: F093 (Reality-Pro External Evidence Ingestion)

## Goal

Make `reality-pro` materially multi-source by ingesting optional docs, ADRs, and runbooks into persistent repo memory and wiring that evidence into review/report outputs.

## Beads

- sdplab-wdu: F093-01 Reality-pro external evidence ingestion

## Scope Files

- `internal/realitypro/memory.go`
- `internal/realitypro/review.go`
- `internal/realitypro/report.go`
- `cmd/sdp-reality-pro-ingest/main.go`
- `schema/reality/repo-memory.schema.json`
- `docs/specs/reality/PRO-SPEC.md`

## Acceptance Criteria

- [x] `sdp-reality-pro-ingest` supports a docs-enabled mode aligned with `PRO-SPEC` (`--with-docs` plus explicit doc roots)
- [x] `repo-memory.json` stores normalized evidence sources for ingested docs/ADRs/runbooks
- [x] `reality-pro-review` and `reality-pro-report` cite ingested evidence sources when they are present
- [x] `docs/reality/multi-repo-map.md` exposes evidence coverage so operators can see whether consulting inputs are thin or rich
