# 00-145-10: cascade pkg + CascadingInvoker

Feature: F145 (Multi-Provider Dispatch Matrix & Confidence-Driven Cascade)

Design reference: [2026-04-26-f145-multi-provider-dispatch-cascade-design.md §4.3](../../plans/2026-04-26-f145-multi-provider-dispatch-cascade-design.md)

## Goal

Создать pkg `internal/dispatch/cascade/` с `CascadingInvoker`, `Policy`, `Result` types. В этой WS — **скелет + heuristic short-circuit + MaxDepth/Budget**. Инжекция confidence.Checker — следующая WS 11.

## Beads

- (assigned during epic creation)

## Scope Files

- `internal/dispatch/cascade/cascade.go` — new. `Invoker struct`, `Policy struct`, `Result struct`, `ShortCircuitConfig struct`. `Invoke(ctx, dir, agent, prompt) (Result, error)` — алгоритм per design §4.3 без confidence-call (placeholder gate возвращает OK всегда).
- `internal/dispatch/cascade/policy.go` — new. Default policy builder: `DefaultPolicy() Policy` с MaxDepth=2, MaxBudget=30s, Tiers=[Fast, Strong].
- `internal/dispatch/cascade/heuristics.go` — new. `ShortCircuit(out string, cfg ShortCircuitConfig) (escalate bool, reason string)`. Checks: empty/whitespace, length < MinLengthChars, regex match RefusalPatterns.
- `internal/dispatch/cascade/cascade_test.go` — new. Tests на алгоритм с mock invokers: stay-on-tier-1, escalate-to-tier-2 после heuristic trigger, exhaust-all-tiers, MaxBudget cutoff.
- `internal/dispatch/cascade/heuristics_test.go` — new. Tests: empty triggers, length triggers, refusal regex triggers, multi-language refusal patterns.
- `internal/dispatch/cascade/policy_test.go` — new. Tests on DefaultPolicy values.

## Acceptance Criteria

- [ ] `Invoker.Invoke` корректно итерирует tier'ы согласно `Policy.Tiers`.
- [ ] `ShortCircuit` возвращает `(true, "empty")` для пустого output, `(true, "too_short")` для < MinLengthChars, `(true, "refusal:<pattern>")` для match.
- [ ] `Policy.MaxBudget` обрезает cascade если превышено время.
- [ ] `Result.TierUsed` корректно отражает финальный tier; `EscalationCount` = количество переходов.
- [ ] Cascade без подходящих профилей → возвращает error "no profiles for tier <X>".
- [ ] go build, go test ./internal/dispatch/cascade/..., go vet clean.
- [ ] Test coverage ≥85%.
