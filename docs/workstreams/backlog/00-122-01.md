# 00-122-01: Index Store, Chunking, and Cold Build

Feature: F122 (Toolkit Index — persistent codebase memory)

## Goal

Create the persistent index store and cold-build path so SDP can turn a repo into queryable local memory instead of repeated ad hoc scans.

## Beads

- sdplab-hxiu

## Scope Files

- `internal/index/builder.go`
- `internal/index/parser.go`
- `internal/index/store.go`
- `internal/index/types.go`
- `internal/index/languages.go`
- `cmd/sdp/cmd_index.go`

## Acceptance Criteria

- [ ] cold build creates `.sdp/index.db` with chunks, edges, file metadata, and repo metadata
- [ ] chunking is tree-sitter-based and language-aware for supported languages
- [ ] secret and binary file exclusions are explicit and tested
- [ ] build works without any always-on external service
- [ ] builder and store tests cover cold-build correctness on temp repos

## Out of Scope

- advanced query ranking
- manifest generation
- incremental refresh
