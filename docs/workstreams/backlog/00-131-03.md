# 00-131-03: Bootstrap integration — wire skill augmenter into sdp bootstrap

Feature: F131 (sdplab-ait)

## Goal

Integrate the skill augmenter from 00-131-02 into `sdp bootstrap`. After harness config generation, automatically detect the repo's stack and augment skills. Add `sdp skills update` as a standalone re-augment command.

## Beads

- sdplab-qo1 (F131-03)

## Scope Files

- `cmd/sdp/bootstrap.go` — modify. Add skill augmentation step after harness config.
- `cmd/sdp/skills_update.go` — new. `sdp skills update` subcommand (re-augment).
- `internal/skills/detect.go` — new. Auto-detect stack from repo contents (go.mod, package.json, requirements.txt, pyproject.toml).

## Acceptance Criteria

- [ ] `sdp bootstrap` runs skill augmentation after config generation
- [ ] `sdp skills update` re-augments skills without full bootstrap
- [ ] Stack detection: recognizes Go (go.mod), Python (requirements.txt/pyproject.toml), TypeScript (package.json with tsconfig)
- [ ] Post-augmentation validation: `sdp-protocol-check --lint-skills` passes
- [ ] Unit tests for stack detection and bootstrap integration

## Out of Scope

- New harness types (only existing harness configs)
- Scout/report integration
- Multi-stack repos (pick primary stack, document limitation)
