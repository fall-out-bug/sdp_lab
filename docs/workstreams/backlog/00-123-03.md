# 00-123-03: Optional LLM Enrichment and Drift Diff

Feature: F123 (Toolkit Spec Recovery — recover implicit contracts from code)

## Goal

Add the optional second phase that enriches deterministic specs and detects drift between recovered contract snapshots without making LLM use mandatory.

## Beads

- sdplab-5e10

## Scope Files

- `internal/spec/spec.go`
- `internal/spec/diff.go`
- `internal/spec/diff_test.go`
- `internal/spec/spec_test.go`
- `cmd/sdp/cmd_spec.go`

## Acceptance Criteria

- [ ] enrichment is explicit opt-in and never the default path
- [ ] spec diff or drift detection compares recovered contracts between snapshots
- [ ] enrichment and diff outputs explain confidence and limits instead of hiding uncertainty
- [ ] tests cover false-positive guardrails and stable diff semantics
- [ ] spec recovery remains usable when no LLM runtime is configured

## Out of Scope

- automatic backlog creation from drift
- MCP wrapping
- bootstrap generation
