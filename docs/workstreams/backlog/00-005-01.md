# WS-005-01: adapter-controller subscribes to NATS ready events and creates Tasks

Feature: FR-005 (sdp_dev-wk8)
Priority: P1
Effort: 1d
Dependencies: WS-001-02 (TaskReconciler works)

## Goal

Connect adapter-controller to NATS so intake flow (intake-gateway → NATS → bridge → Beads ready) triggers Task CRD creation automatically.

## Design

1. adapter-controller subscribes to `sdp.beads.*.ready`
2. On ready event: parse issues list, for each unprocessed issue:
   - IntentTranslator → TaskIntent
   - PolicyGate → pre-dispatch check
   - RunLockManager → acquire
   - Create Task CRD in kubeopencode-system
3. On terminal reconcile: publish `sdp.status.<project>.<issue>` to NATS

## Acceptance Criteria

- [x] adapter-controller connects to NATS_URL
- [x] Ready event → Task CRD created
- [x] Terminal → NATS status event published
- [x] Duplicate events don't create duplicate Tasks (RunLockManager)
- [x] Integration test with embedded NATS
