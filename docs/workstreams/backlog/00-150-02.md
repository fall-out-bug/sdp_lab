# 00-150-02: Release surface inventory and stable build contract

Feature: F150 (Product Layering And Release Readiness)

Design reference: [2026-04-27-f150-product-layering-release-readiness-design.md](../../plans/2026-04-27-f150-product-layering-release-readiness-design.md)

## Goal

Create the authoritative release inventory before code cleanup. Classify commands, packages, docs, and publish artifacts as stable product, operator tooling, lab-only, experimental, retired, or future product candidate.

## Beads

- sdplab-8rk7 (F150-02: inventory release surface and stable build contract)

## Scope Files

- `cmd/`
- `internal/`
- `.goreleaser.yml`
- `.github/workflows/release.yml`
- `scripts/check-release-surface.sh`
- `docs/reference/product-surface.md`
- `docs/reference/maturity-matrix.md`
- new or updated release inventory doc

## Acceptance Criteria

- [ ] Every `cmd/sdp*` binary is classified.
- [ ] `cmd/sdp` subcommands are classified for formula visibility.
- [ ] Each internal package used by the stable release surface has an owner and maturity label.
- [ ] Formula default install surface is explicitly selected.
- [ ] Lab-only and experimental surfaces have an exclusion mechanism named.

## Out of Scope

- Implementing build-tag isolation.
- Module path migration.
- Removing dependencies.
