# 00-136-03: sdp memory CLI

Feature: F136 (Peer Memory Foundation)

## Goal

Expose the H1 memory surface through `sdp memory` with ergonomic human writes and scriptable reads.

## Beads

- sdplab-olvg

## Scope Files

- `cmd/sdp/cmd_memory.go`
- CLI integration tests / golden files

## Acceptance Criteria

- [ ] `sdp memory log|query|recent|show|compact` work end-to-end
- [ ] `--json` exists for read commands
- [ ] `--role` and `--type` validate against frozen enums
- [ ] Help text documents the intended H1 use, not H2/H3 aspirations
- [ ] Roundtrip integration test passes: log → query → show

## Out of Scope

- Hook automation
- MCP exposure

## Implementation Notes

Optimize for low-friction human usage first. If the CLI is annoying, the memory system dies before dogfood finishes.
