# 00-134-04: AI-vs-human attribution — provenance in git trailers

Feature: F134 (sdplab-i01)

## Beads

- sdplab-zf6

## Goal

Every commit gets provenance marker distinguishing agent / human / hybrid authorship. NIST AI RMF GenAI Profile + Colorado AI Act (Jun 2026) requirement.

## Scope Files

- `internal/provenance/` — NEW package
- `internal/provenance/provenance.go` — Provenance struct + trailer emitter
- `internal/provenance/provenance_test.go` — tests

## Design

```go
type Provenance struct {
    GeneratedBy string    // agent|human|hybrid
    Harness     string    // claude-code|codex|opencode|cursor
    Model       string    // claude-opus-4-7, etc.
    SessionID   string
    Timestamp   time.Time
}
```

Emit as git trailer: `AI-Attribution: agent/claude-opus-4-7/session-xxxx`

## Acceptance Criteria

- [ ] `internal/provenance/` package with Provenance struct
- [ ] `FormatTrailer()` emits parseable git trailer
- [ ] `ParseTrailer()` reads trailer back from git log
- [ ] Unit tests for all fields, round-trip, edge cases
- [ ] `go vet` clean
