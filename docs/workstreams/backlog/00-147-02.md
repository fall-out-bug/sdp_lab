# 00-147-02: `WsVerdictMicro` — deterministic rule-based classifier

Feature: F147 (MicroFirst Inference Tier)

Design reference: [2026-04-27-f147-microfirst-tier-design.md §3 F147-02](../../plans/2026-04-27-f147-microfirst-tier-design.md)

## Goal

Deterministic micro-classifier для ws-verdict extract stage: парсит test report + guard diff и возвращает `{PASS, FAIL, UNSURE}` без вызова LLM. Применяется как micro-side в `WithEscalation` обёртке вокруг F146-04 extract stage.

## Beads

- sdplab-itzf (historical F147 anchor; leaf Beads were not preserved)

## Scope Files

- `internal/inference/microfirst/wsverdict/classifier.go` — new. `WsVerdictMicro` struct + Stage interface impl, rules engine.
- `internal/inference/microfirst/wsverdict/result.go` — new. `WsVerdictMicroResult{Verdict, Confidence, Status, Reasons}` implements `Confider`.
- `internal/inference/microfirst/wsverdict/rules.go` — new. Rule predicates: TestsFailed, GuardOutOfScope, SkippedAboveThreshold, CoverageBelowMin.
- `internal/inference/microfirst/wsverdict/classifier_test.go` — new. ≥30 fixture cases (clean-pass, clean-fail, ambiguous, edge cases).
- `internal/inference/microfirst/wsverdict/testdata/` — new. JSON fixtures of (TestReport, GuardDiff, expected).

## Acceptance Criteria

- [ ] `NewWsVerdictMicro(rulesCfg)` constructor returns Stage[WsVerdictInput, WsVerdictMicroResult].
- [ ] Rule R1: `TestReport.Failed > 0` → `FAIL`, confidence=0.95.
- [ ] Rule R2: `Failed==0 && Errored==0 && len(GuardDiff.OutOfScope)==0` → `PASS`, confidence=0.90.
- [ ] Rule R3: `len(GuardDiff.OutOfScope) > 0` → `UNSURE`, confidence=0.40.
- [ ] Rule R4: `Skipped > threshold` → `UNSURE`, confidence=0.50.
- [ ] Rule R5: `Coverage < ws.MinCoverage` → `UNSURE`, confidence=0.45.
- [ ] Rule R6 (catch-all): `UNSURE`, confidence=0.30.
- [ ] ≥30 fixture test cases; on clear-pass/clear-fail subset accuracy = 100%.
- [ ] Latency p99 < 5ms (no I/O).
- [ ] Coverage ≥ 85%.
- [ ] `go build ./...` and `go vet ./...` clean.
