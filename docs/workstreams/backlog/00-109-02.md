# 00-109-02: Source-Preserving Multilingual Policy

Feature: F109 (StratAudit v2 — evidence-backed report redesign)

## Goal

Сделать язык источника first-class свойством entity и запретить скрытый перевод
русскоязычных названий и описаний в английский по умолчанию.

## Beads

- sdplab-2md

## Scope Files

- `internal/strataudit/extract_llm.go` — prompt и post-processing для source-preserving extraction
- `internal/strataudit/model/entity.go` — `title_original`, `description_original`, `lang`, `language_mismatch`
- `internal/strataudit/store.go` — хранение исходных и display-полей
- `internal/strataudit/report_builder.go` — экспорт original/display/lang в report DTO
- `internal/strataudit/extract_llm_test.go` — кейсы с русским source и нежелательным English rewrite

## Acceptance Criteria

- [ ] extraction prompt явно требует сохранять язык исходного фрагмента
- [ ] entity хранит original-поля отдельно от display-полей
- [ ] русский source quote не превращается по умолчанию в англоязычный title
- [ ] `language_mismatch` фиксируется отдельным quality signal
- [ ] tests покрывают минимум кейсы `ru -> ru`, `ru -> en mismatch`, `en -> en`

## Out of Scope

- Автоматический перевод для UI
- Локализация HTML chrome
- Дедупликация сущностей между языками

## Implementation Notes

- WS-02 не должен прятать проблему за "красивыми" display-полями. Сначала оригинал, потом derived view.
