# 00-069-08: Orchestrator Loop Integration

Feature: F069 (Control Tower Pack + Spec-Driven Pipeline)

## Goal

Turn the control store into a first-class orchestration surface by adding one-pass loop behavior for ingest, dispatch, and resume decisions instead of leaving execution steps as disconnected manual commands.

## Beads

- Historical execution bead is not recoverable from current mapping data
- sdplab-x43: F096-02 placeholder remediation batch for `00-069-06` ... `00-069-10`

## Acceptance Criteria

- [x] `sdp orchestrate once` performs exactly one useful action per pass: ingest a result, else dispatch work, else explain the no-op
- [x] `sdp dispatch next` can select and report the next dispatchable card from control-store state
- [x] Feedback and resume flow can move cards back toward `clarifying` or `ready` without bypassing control-store invariants
- [x] Tests cover ingest-first, dispatch, and nothing-to-do behavior
