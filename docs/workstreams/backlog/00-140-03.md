# 00-140-03: Delivery-loop phase-span emission (TEL-05)

Feature: F140 (AI SDLC Telemetry v1 — MVP)

Design reference: [2026-04-22-ai-sdlc-telemetry-design.md §10.6 (critical path), §3.3 (span attrs)](../../plans/2026-04-22-ai-sdlc-telemetry-design.md)

## Goal

Instrument the `delivery-loop` skill to emit canonical phase spans (`phase_0_bootstrap`, `phase_1_build.cycle_N`, `phase_2_pr`, `phase_3_codex.cycle_N`, `phase_4_closeout`) via `sdp trace`. This is the **primary M1/M2/M3/M4 signal source** — must land before reducer so the reducer has real fixtures.

## Beads

- F140-03 child bead (linked from epic on creation)

## Scope Files

- `.agents/skills/delivery-loop.md` — amend Phase 0/1/2/3/4 sections with explicit `sdp trace span-start/span-end` calls. Existing checkpoint writes unchanged.
- `prompts/skills/delivery-loop/SKILL.md` — mirror (if distinct from `.agents/` version).
- `scripts/sdp-checkpoint-write.sh` — extend to emit `delivery_loop.phase_*` span on every phase transition with canonical attributes.
- `scripts/sdp-dispatch.sh` — inject `TRACEPARENT` and `--tool-call-id` into dispatched subagent invocations (preserves trace continuity across fork).
- `.agents/skills/review.md` — emit `sdp.review.verdict`, `sdp.findings.count`, `sdp.findings.by_severity` as event on phase-1 span (metadata consent: severity+rule+hash only).
- Tests: shell-level fixture that runs a stubbed loop and asserts span JSONL contains expected phase/cycle/verdict attributes.

## Acceptance Criteria

- [ ] Phase 0 Bootstrap emits one span with `sdp.feature_id`, `sdp.workstream_count`.
- [ ] Phase 1 Build emits one span per cycle with `sdp.phase.cycle_number`, `sdp.review.verdict ∈ {APPROVED, CHANGES_REQUESTED, BLOCKED}`, `sdp.findings.count`, `sdp.findings.by_severity` (JSON attr).
- [ ] Phase 2 PR emits span with `sdp.pr.number`, `sdp.quality_gate.result`.
- [ ] Phase 3 Codex emits one span per cycle with `sdp.codex.consecutive_clean`, `sdp.codex.tests_passed`, `sdp.codex.findings.count`.
- [ ] Phase 4 Closeout emits span with `sdp.closeout.children_closed`, `sdp.closeout.duration_ms`.
- [ ] All attributes pass `verify_trace_attrs.sh` (TEL-01 allowlist).
- [ ] Subagent dispatched via `sdp-dispatch.sh` inherits `TRACEPARENT` — verified by integration fixture.
- [ ] Zero performance regression on delivery loop beyond TEL-02 daemon round-trip cost.
- [ ] Anchor `^## Phases \(declarative\)` still present in `delivery-loop.md`; `verify_skill_anchors.sh` green.

- Reducer / M1–M7 computation (→ 00-140-04).
- Codex `/rescue` internal instrumentation (consumes phase-3 emission, not extended here).
