# 00-099-01: Safe Install (Merge, Not Overwrite)

Feature: F099 (Brownfield Safe Overlay)

## Goal

Modify install.sh and install-project.sh to: backup existing IDE config to .sdp/backup/ before modification, merge SDP hooks into existing settings.json (append to arrays), add --preview flag to show changes before applying. Never overwrite user config by default.

## Beads

- sdplab-19

## Scope Files

- `sdp/install.sh` — add backup and preview logic
- `sdp/scripts/install-project.sh` — merge behavior, backup
- `sdp/scripts/uninstall.sh` — new file

## Acceptance Criteria

- [ ] Existing .claude/settings.json preserved after install (non-SDP keys unchanged)
- [ ] .sdp/backup/ contains pre-install copies of modified files
- [ ] --preview flag shows what will change without changing it
- [ ] sdp uninstall removes SDP artifacts, preserves user data
- [ ] sdp uninstall --purge removes everything
- [ ] sdp uninstall --dry-run shows plan without executing

## Out of Scope

- Graduation levels (F103)
