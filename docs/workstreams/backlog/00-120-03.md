# 00-120-03: CLI Surfaces, Artifacts, and Performance Harness

Feature: F120 (Toolkit Scout — instant repo card for unknown codebases)

## Goal

Ship `sdp scout` as a usable operator command with stable JSON/text/card output, optional `.sdp/scout.json` artifact writing, and explicit performance budgets.

## Beads

- sdplab-eva1

## Scope Files

- `cmd/sdp/cmd_scout.go`
- `internal/scout/scout_test.go`
- `internal/scout/identity_test.go`
- `internal/scout/scale_test.go`
- `internal/scout/activity_test.go`

## Acceptance Criteria

- [ ] `sdp scout <repo>` supports `--format json|text|card`
- [ ] `sdp scout --output .sdp/ <repo>` writes `.sdp/scout.json`
- [ ] large-repo safeguards are explicit and tested
- [ ] integration/perf tests enforce the "fast first look" budget from the design
- [ ] command failure modes explain missing git data or unreadable paths clearly
