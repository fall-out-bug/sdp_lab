# 00-129-04: sdp-doc-sync --mode fix

Feature: F129 (Autonomous Operations & Regression Hardening)

## Goal

Extend `internal/docsync` and `cmd/sdp-doc-sync` with `--mode fix` that auto-repairs simple doc issues: relative link reindex via `git log --follow`, trailing-slash normalization, code-fence language tag inference.

## Beads

- sdplab-8k5.4

## Scope Files

- `internal/docsync/fix.go` — new fix routines
- `internal/docsync/fix_test.go` — tests
- `cmd/sdp-doc-sync/main.go` — wire `--mode fix`

## Acceptance Criteria

- [ ] `--mode fix` applies safe fixes only; complex issues (broken anchor, missing target) stay in `--mode check`
- [ ] Dry-run mode (`--mode fix --dry-run`) prints intended changes
- [ ] Idempotent (second run is a no-op)
- [ ] Unit tests cover each fix category
- [ ] `go vet` + `-race` clean

## Out of Scope

- Fixing broken anchors
- Regenerating missing docs
- Cross-repo link resolution

## Implementation Notes

Reuse the `checkMarkdownLinks` infrastructure. Link rename uses `git log --follow --name-status` to trace file moves. Keep the fix pipeline small: trailing slash → fence tag → link reindex.
