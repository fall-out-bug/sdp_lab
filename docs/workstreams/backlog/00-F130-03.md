Feature: F130 (AI Harness Config Auto-Provisioning)

## Goal

Generate a language-specific patterns doc (format: docs/reference/go-patterns.md is the reference output) from `pattern-report.json`. Pull actual code snippets for examples. Validate that examples compile. Support versioning so re-generation produces a diff, not full overwrite.

## Scope Files

- `internal/rulesgen/generator.go` (new)
- `internal/rulesgen/generator_test.go`
- `cmd/sdp-rulesgen/main.go` (new binary)
- `docs/reference/go-patterns.md` (reference output format — already exists as manual example)

- [ ] `sdp-rulesgen --pattern-report=pattern-report.json` generates rules file
- [ ] Output format matches docs/reference/go-patterns.md structure
- [ ] Examples are actual code snippets from the repo (not fabricated)
