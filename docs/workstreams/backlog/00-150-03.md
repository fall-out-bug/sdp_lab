# 00-150-03: Go module path migration away from sdp_dev

Feature: F150 (Product Layering And Release Readiness)

Design reference: [2026-04-27-f150-product-layering-release-readiness-design.md](../../plans/2026-04-27-f150-product-layering-release-readiness-design.md)

## Goal

Replace active Go module naming from legacy `sdp_dev` to the chosen public module path. Default target is `github.com/fall-out-bug/sdp_lab` unless the release inventory proves a different source repo is required.

## Beads

- sdplab-kcrd (F150-03: migrate Go module path away from sdp_dev)

## Scope Files

- `go.mod`
- `cmd/**/*.go`
- `internal/**/*.go`
- non-historical docs that describe active source install or imports

## Acceptance Criteria

- [ ] `go.mod` uses the chosen public module path.
- [ ] Active first-party Go imports no longer use `sdp_dev`.
- [ ] Historical `sdp_dev` references are preserved only where explicitly historical.
- [ ] `go test ./...` or the repo quality gate passes with the selected build tags.
- [ ] Release docs no longer tell users to import or install `sdp_dev`.

## Out of Scope

- Public `sdp` repo publishing.
- Renaming Beads IDs.
- Rewriting archived historical logs.
