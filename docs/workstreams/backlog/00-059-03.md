# 00-059-03: Permission↔Guard bridge

Feature: F059 (Ecosystem Synergies)

## Goal

Bridge OhMyOpenCode's pattern-based ACL (`ask`/`allow`/`deny`) to SDP boundary gate escalation. When OMO triggers `ask`, escalate to SDP boundary gate for approval.

## Beads

- sdplab-11: F059-03 Permission-Guard bridge
## Scope Files

- `internal/guard/permission_bridge.go` (new)
- `internal/guard/boundary.go` (extend)

## Acceptance Criteria

- [ ] OMO `ask` action triggers SDP boundary gate prompt
- [ ] `allow` → auto-approve within scope
- [ ] `deny` → block and log violation
- [ ] Pattern matching supports glob and regex
- [ ] Audit log records permission decisions
