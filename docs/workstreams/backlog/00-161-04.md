# 00-161-04: Verdict, telemetry, beads, and delivery-loop integration

Feature: F161 (sdplab-tffu)
Parent bead: sdplab-tffu.4

## Goal

Connect `sdp pi-review` to SDP delivery: compact verdicts, raw telemetry, bead findings, and repeat-until-clean behavior for subagent delivery loops.

## Beads

- sdplab-tffu.4

## Scope Files

- `.sdp/review_verdict.json`
- `.sdp/runs/pi-review/<run_id>/run.json`
- beads finding emission path
- delivery-loop integration docs and prompts
- command docs for `sdp pi-review` / `sdp-pi-review`

## Acceptance Criteria

- [ ] `--write-verdict` writes `.sdp/review_verdict.json` compatible with `schema/review-verdict.schema.json`.
- [ ] `run.json` validates against `schema/pi-review-run.schema.json`.
- [ ] `--create-beads` creates or updates beads for actionable findings with stable dedupe keys.
- [ ] Open `P0` or `P1` pi-review findings prevent clean verdict.
- [ ] Delivery loop repeats fix-review rounds until verdict is `APPROVED`.
- [ ] Loop escalates when the same blocker survives two fix attempts, model quorum is insufficient, or required context was omitted.
- [ ] Telemetry captures run ID, scope, hashes, model statuses, fallback use, raw artifacts, verdict reference, and created bead IDs.

## Out of Scope

- Human UI for browsing raw review artifacts.
- Automatic PR comment posting.
- Replacing existing `@review` gates.
