# 00-146-03: Confidence (F144) and cascade (F145) integration per stage

Feature: F146 (Inference Decomposition Framework)

Design reference: [2026-04-26-f146-inference-decomposition-design.md §3 F146-03](../../plans/2026-04-26-f146-inference-decomposition-design.md)

## Goal

Wire optional per-stage F144 `confidence.Checker` and forward-compatible F145 `cascade.Invoker` into `Pipeline.Run`. Establish the call order (cascade → confidence → stitcher), trace merge into `StageTrace`, status propagation into `Result.Status`, and `SubScore` derivation. F145 dependency is local narrow-interface so this WS does not block on F145 merge.

## Beads

- sdplab-ass2 (historical leaf issue)

## Scope Files

- `internal/inference/decompose/integration.go` — new. Per-stage execution wrapper invoking optional Cascade then Confidence then Stitcher; merges traces.
- `internal/inference/decompose/cascade_iface.go` — new. Local narrow interface `cascade.Invoker` (forward-compatible with F145 sdplab-5ii8). Type alias to real `internal/dispatch/cascade.Invoker` after F145 merges.
- `internal/inference/decompose/pipeline.go` — modify. `Pipeline.Run` calls integration wrapper instead of raw `Stage.Run`.
- `internal/inference/decompose/result.go` — modify. `StageTrace` adds `ConfidenceLog *confidence.Trace` and `CascadeLog *cascade.Trace` (via narrow type for cascade).
- `internal/inference/decompose/integration_test.go` — new. Three scenarios: confidence-only, cascade-only (mock F145), both wrapped.
- `internal/inference/decompose/README.md` — extend. Section `## Composition with F144/F145` documenting call order, trace merge semantics, status escalation rules.

## Acceptance Criteria

- [ ] `Pipeline.Run` for each stage: if `StageConfig.Cascade != nil`, wraps `Stage.Run` in `cascade.Invoker.Invoke`; if `StageConfig.Confidence != nil`, then wraps cascade output (or raw stage output) in `confidence.Checker.Check`; finally Stitcher validates the resulting Out.
- [ ] Call order strictly cascade → confidence → stitcher (provider escalation first, semantic gate second, format gate last).
- [ ] `StageTrace.ConfidenceLog` populated when Confidence used; `nil` otherwise.
- [ ] `StageTrace.CascadeLog` populated when Cascade used; `nil` otherwise.
- [ ] `StageResult.SubScore` ← `confidence.Result.Score` if Confidence used; else `1.0` on success / `0.0` on failure.
- [ ] `StageResult.Status` ← `confidence.Result.Status` if Confidence used; mapped from FailurePolicy outcome otherwise.
- [ ] `Result.Status` aggregation: any stage FAIL → Result FAIL (unless Fallback succeeded); any UNSURE without FAIL → Result UNSURE; all OK → OK.
- [ ] Cascade narrow interface (`cascade.Invoker`) defined locally; mock implementation in tests; design comment marks intended swap to real F145 import once F145 merges.
- [ ] Integration tests cover (a) Confidence-only stage, (b) Cascade-only stage via mock, (c) both wrapped — each asserts call order, trace merge, status.
- [ ] Existing 00-146-01 unit tests (Pipeline, Stage, FailurePolicy) still pass — no regression.
- [ ] Coverage of integration.go ≥ 85 %.
- [ ] README documents the composition story with diagram or short worked example.
- [ ] `go build ./...` and `go vet ./...` clean.
