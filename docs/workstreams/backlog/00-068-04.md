# 00-068-04: Status and instructions contracts

Feature: F068 (Unified Integration Contracts)

## Goal

Define versioned machine-readable contracts for SDP status and instructions so guided next-step UX can be deterministic across CLI, adapters, and agents.

## Beads

- sdplab-ifez: F068-04 status-instructions-contracts

## Scope Files

- `schema/contracts/status-view.schema.json` (new)
- `schema/contracts/instructions.schema.json` (new)
- `docs/protocol/CONTRACTS.md` (update)

## Acceptance Criteria

- [ ] JSON Schema for `StatusView` includes ready items, blocked items, next action, and rationale fields
- [ ] JSON Schema for `InstructionPayload` includes action identifier, required context, optional context, and policy/evidence expectations
- [ ] Text and JSON consumers can derive the same next-step recommendation from the same contract fields
- [ ] Example payloads cover ready, blocked, and no-next-action states
