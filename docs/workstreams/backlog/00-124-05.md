# 00-124-05: Post-`bd close` auto-sync hook

Feature: F124 (Beads/workstream sync automation)

## Goal

Install a post-`bd close` git hook (or bd-native extension) that auto-syncs workstream status (`backlog/` → `done/`), updates `INDEX.md` counter, and regenerates `ROADMAP.md` references. Brownfield-safe: additive only, no deletes without `--force`.

## Beads

- sdplab-nai

## Scope Files

- `scripts/install_bd_hooks.sh` — new installer
- `scripts/bd_post_close.sh` — hook script that: (a) parses closed issue IDs from bd output; (b) greps workstream files referencing those beads; (c) moves them from `backlog/` to `done/`; (d) runs `sdp-doc-sync --mode fix` on `INDEX.md`
- `scripts/bd_post_close_test.bats` — bats-framework test (mocked bd output)

## Acceptance Criteria

- [ ] Installer adds hook without overwriting existing git hooks (merges)
- [ ] Hook correctly moves workstream files when bd bead ID found in frontmatter
- [ ] `INDEX.md` range updated (e.g. `00-106-01 ... 00-106-06` → `... 00-106-07`)
- [ ] bats test covers: normal close, close without workstream match, multiple closes
- [ ] Dry-run mode (`BD_POST_CLOSE_DRY_RUN=1`) lists intended changes without applying

## Out of Scope

- Cross-repo sync (`sdp` submodule changes handled separately)
- bd issue → workstream bidirectional sync (only close-forward direction)
- `ROADMAP.md` content generation (only reference updates)

## Implementation Notes

Extract bead IDs from `bd close` output via regex `sdplab-[a-z0-9]+`. Workstream scan: grep `## Beads\n- sdplab-<id>` in `backlog/*.md`.
