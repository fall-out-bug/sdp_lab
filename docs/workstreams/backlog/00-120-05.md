# 00-120-05: Review Remediation — Context-Aware File Walking

Feature: F120 (Toolkit Scout — instant repo card for unknown codebases)

## Goal

Fix the remaining P1 from round-2 review: `filepath.Walk` in `detectScale` and `detectIdentity` ignores context cancellation, making the scout pipeline uninterruptible on large or NFS-mounted repositories. Replace with a context-checking walker and propagate errors properly.

## Beads

- sdplab-7uke

## Scope Files

- `internal/scout/scout.go`
- `internal/scout/identity.go`
- `internal/scout/scale.go`

## Dependencies

- 00-120-04: previous remediation (context threading for git commands)

## Acceptance Criteria

- [ ] `detectIdentity` and `detectScale` accept `context.Context` and check `ctx.Err()` periodically during walk
- [ ] `scout.RunWithContext` passes context to `detectIdentity` and `detectScale`
- [ ] `filepath.Walk` errors (permission denied, broken symlink) are not silently swallowed — logged or returned
- [ ] test verifies walk is cancelled when context is cancelled mid-scan
- [ ] all existing tests still pass
- [ ] `go vet ./internal/scout/...` clean

## Out of Scope

- P2 findings: calcBusFactor improvement, IsTestFile dead code, language ordering determinism, RepoURL credential sanitization, symlink README, --output sanitization, unbounded commit log, cumulative timeout budget
- These are tracked in review_verdict.json for future remediation

## Implementation Notes

- Review finding source: `.sdp/review_verdict.json` round 2, SRE P1
- Pattern: wrap `filepath.Walk` with periodic `ctx.Err()` check (every N files or per-directory), or use a custom walker with `filepath.WalkDir` + select on context done channel
- Prefer `filepath.WalkDir` over `filepath.Walk` — fewer `os.Stat` calls, Go 1.16+ standard
- Keep changes minimal — focused on context propagation in walk phases only
