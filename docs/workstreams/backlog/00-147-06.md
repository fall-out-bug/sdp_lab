# 00-147-06: `RoutingColdStartMicro` + dispatch integration

Feature: F147 (MicroFirst Inference Tier)

Design reference: [2026-04-27-f147-microfirst-tier-design.md §3 F147-06](../../plans/2026-04-27-f147-microfirst-tier-design.md)

## Goal

Embedding-based k-NN classifier для cold-start routing в `internal/dispatch/route.go`. Заменяет neutral prior для unknown task types на capability hint от embedding-similarity к labeled corpus. Backward-compat: `Status=Unsure` → старый neutral prior.
