# 00-136-05: MCP read resources for memory

Feature: F136 (Peer Memory Foundation)

## Goal

Expose memory retrieval to all harnesses through the F126 MCP server without opening an MCP write path in H1.

## Beads

- sdplab-l0mm

## Scope Files

- MCP server resource registration
- MCP memory resource tests

## Acceptance Criteria

- [ ] `sdp://memory/recent` returns the latest entries
- [ ] `sdp://memory/query?q=...` returns filtered results
- [ ] `sdp://memory/session/{id}` returns a full session
- [ ] Resource responses match CLI JSON shape closely enough for cross-harness reuse
- [ ] Write attempts are explicitly rejected

## Out of Scope

- MCP write API
- trust tiers / moderation

## Implementation Notes

Do not invent a second contract. CLI JSON and MCP JSON should stay boringly aligned.
