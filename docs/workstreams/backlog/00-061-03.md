# 00-061-03: Formula → Workstream template

Feature: F061 (Beads Graph Integration)

## Goal

Convert Beads formulas (YAML/JSON-defined reusable workflows) into SDP workstream templates. Formulas enable declarative WS generation with variable substitution.

## Implementation Notes

### Usage

```bash
# List available formulas
sdp-beads-bridge formula list

# Show formula details
sdp-beads-bridge formula show feature

# Generate workstreams from formula
sdp-beads-bridge formula apply \
  --vars name=auth-api \
  --feature F062 \
  --output docs/workstreams/backlog \
  .beads/formulas/feature.yaml
```

### Formula Schema

Supports workflow type formulas with:
- `name`, `version`, `description`
- `variables` with defaults and types
- `steps` with dependencies, scope files, acceptance criteria

### Variable Substitution

Supports both `{{var}}` and `{{.var}}` patterns.
