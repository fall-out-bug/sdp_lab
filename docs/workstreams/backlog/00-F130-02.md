# 00-F130-02: Pattern extraction engine — extend Scout/Index for convention mining

Feature: F130 (AI Harness Config Auto-Provisioning)

## Goal

Extend `sdp scout` / `sdp index` (F120/F122) to extract structured patterns from the codebase: naming conventions (from exported identifiers), architecture patterns (from interface/struct/method relationships), good code examples (highest-coverage, most-referenced files), antipattern signals (panic usage, global vars, empty error checks). Output: `pattern-report.json`.

## Scope Files

- `internal/scout/patterns.go` (new — pattern extraction logic)
- `internal/scout/patterns_test.go`
- `cmd/sdp-scout/main.go` (add `--extract-patterns` flag)
- `schema/pattern-report.schema.json` (new)

## Acceptance Criteria

- [ ] `sdp scout --extract-patterns` produces pattern-report.json
- [ ] Naming conventions extracted (package names, type names, constructor patterns)
- [ ] Architecture patterns detected (FSM, DI via interfaces, event-driven)
- [ ] At least 3 antipattern signal types detected
- [ ] Tests use testing.Short() for integration tests
