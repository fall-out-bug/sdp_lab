# 00-151-06: Pilot Measurement Plan

Feature: F151 (sdplab-hfk0)
Parent bead: sdplab-hfk0.6

## Goal

Pilot measurement plan: install time, evidence-mismatch rate, useful-decision rate, false-block rate, reviewer time delta, post-merge incident rate. Sample size, baseline window, stop/go rules.

## Beads

- sdplab-hfk0.6

## Scope Files

- `docs/design/sdp-pr-gate/pilot-measurement-plan-v1.md` — measurement plan doc

## Acceptance Criteria

- [ ] Install time target: ≤30 min (formula, measurement method, who measures)
- [ ] Passport gen time: ≤60 sec post-checks (formula, measurement method)
- [ ] Useful-decision rate: ≥70% (formula: passports driving reviewer action without reconstruction)
- [ ] Evidence-mismatch rate: <5% (formula: passport claim vs ground-truth source)
- [ ] False-block rate: <5% (formula: blocking PRs that should ship)
- [ ] Reviewer time delta: median −20% in 4-week pilot (measurement method: before/after)
- [ ] Post-merge incident rate: not above baseline (baseline window defined)
- [ ] Each metric has: formula, baseline window, pilot window, minimum sample size, stop/go rule
- [ ] Overall pilot: duration, minimum participants, data collection method, privacy considerations
- [ ] Stop rules: when to abort the pilot, when to extend, when to declare success
- [ ] Go criteria for GA: what numbers trigger "product is real"

## Out of Scope

- Actual pilot execution
- Pricing model (separate F152 track)
- Competitive benchmarking
