# 00-162-04: Runtime dispatch selection and model profile integration

Feature: F162 (sdplab-wuaa)
Parent bead: sdplab-wuaa.4

## Goal

Make non-interactive SDP dispatch choose the exact prompt bundle before launching
Claude Code, Codex, OpenCode, Cursor, Pi, or Kilo.

## Beads

- sdplab-wuaa.4

## Scope Files

- `cmd/sdp-dispatch/`
- `cmd/sdp/`
- `internal/router/`
- `configs/policies/model-routing.rego`
- `docs/reference/harness-integration.md`

## Acceptance Criteria

- [ ] Dispatch accepts or derives harness, model/profile, role, and task_class.
- [ ] Dispatch resolves exactly one prompt bundle before launching the harness.
- [ ] Claude Code, Codex, OpenCode, Cursor, Pi, and Kilo invocations use the harness-specific launch shape documented in `docs/reference/harness-integration.md`.
- [ ] OpenCode non-interactive dispatch uses an explicit agent and does not fall back to the default Sisyphus path.
- [ ] Pi and Kilo dispatch paths stay disabled unless their capability profiles are green.
- [ ] Evidence records bundle id, bundle hash, harness, model/profile, role, and task_class.

## Out of Scope

- Provider billing.
- Model benchmarking.
