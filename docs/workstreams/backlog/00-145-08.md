# 00-145-08: tier_class label + Router scoring integration

Feature: F145 (Multi-Provider Dispatch Matrix & Confidence-Driven Cascade)

Design reference: [2026-04-26-f145-multi-provider-dispatch-cascade-design.md §4.2](../../plans/2026-04-26-f145-multi-provider-dispatch-cascade-design.md)

## Goal

Добавить опциональный `TierClass` field на `CapabilityProfile`, обеспечить back-compat десериализации старых profiles (без поля), не менять существующее поведение Router. Tier-aware фильтрация — отдельная функция `cascade.SelectTiers` (используется в WS 10).

## Beads

- sdplab-noiq (historical leaf issue)

## Scope Files

- `internal/dispatch/profile.go` — MODIFY. Добавить `TierClass string` field (optional, omitempty в JSON). Helper-validators: `TierFast/Balanced/Strong/Local` константы, `IsValidTier(s string) bool`.
- `internal/dispatch/profile_test.go` — MODIFY. Tests: deserialization старого profile без поля → `TierClass == ""` (no error); deserialization с tier_class → корректное значение; validator отвергает неизвестные tier'ы.
- `internal/dispatch/route.go` — без изменений в этой WS (Router сторона остаётся single-winner).
- `internal/dispatch/cascade_select.go` — new (но логика будет вызываться из cascade pkg в WS 10). Функция `func SelectTiers(profiles []*CapabilityProfile, order []TierClass) [][]*CapabilityProfile` — возвращает группы профилей в порядке tier'ов.
- `internal/dispatch/cascade_select_test.go` — new. Tests: правильная группировка, порядок сохранён, профили без tier_class попадают в конец как "untiered".

## Acceptance Criteria

- [ ] `CapabilityProfile.TierClass` опциональное поле, JSON `omitempty`.
- [ ] Старые profiles (без поля) десериализуются без ошибки, `TierClass == ""`.
- [ ] `IsValidTier` принимает `fast/balanced/strong/local`, отвергает остальное.
- [ ] `SelectTiers` корректно группирует и сортирует.
- [ ] go build, go test, go vet clean.
- [ ] Test coverage ≥90%.

## Out of Scope

- Использование SelectTiers в CascadingInvoker — WS 10.
- Дефолтные tier'ы для существующих профилей — WS 09.
