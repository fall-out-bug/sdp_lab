# 00-139-03: Prompt/resource parity

Feature: F139 (MCP Contract Parity)

## Goal

Align MCP prompts and resources with the shipped intent model and the post-normalization skill catalog.

## Beads

- sdplab-9jfv.3

## Scope Files

- `internal/mcp/prompts.go` — prompt registration and parity logic
- `internal/mcp/resources.go` — resource registration and parity logic
- `internal/mcp/templates/` — prompt/resource templates as needed
- `internal/mcp/prompts_test.go` — parity coverage for prompt exposure
- `internal/mcp/resources_test.go` — parity coverage for resource exposure

## Acceptance Criteria

- [ ] Prompt exposure reflects the shipped `F125` intent model rather than a legacy flat skill list
- [ ] Resource exposure follows the normalized catalog and documented parity contract
- [ ] Missing or deprecated surfaces degrade explicitly instead of drifting silently
- [ ] Tests cover partial-context and missing-surface behavior

## Out of Scope

- Auto-generated tool registration
- Reworking skill files themselves
