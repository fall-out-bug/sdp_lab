# 00-126-02: Resources and Intent Prompts

Feature: F126 (Toolkit MCP — universal agent interface)

## Goal

Expose toolkit artifacts as MCP resources and the five intents as MCP prompts so clients can read context and request routed behavior through one protocol surface.

## Beads

- sdplab-vrgy

## Scope Files

- `internal/mcp/resources.go`
- `internal/mcp/prompts.go`
- `internal/mcp/resources_test.go`
- `internal/mcp/prompts_test.go`
- `internal/mcp/templates/understand.tmpl`
- `internal/mcp/templates/build.tmpl`
- `internal/mcp/templates/fix.tmpl`
- `internal/mcp/templates/review.tmpl`
- `internal/mcp/templates/operate.tmpl`

## Acceptance Criteria

- [ ] `.sdp/` artifacts such as scout, metrics, manifest, and bootstrap report are readable as MCP resources
- [ ] the five intents are exposed as prompts with explicit parameters such as `depth` or `mode`
- [ ] prompt assembly uses available artifacts instead of duplicating tool logic
- [ ] resource and prompt tests cover missing-artifact and partial-artifact cases
- [ ] prompts reflect the intent model from `F125`, not the retired flat skill list

## Out of Scope

- harness installation
- cross-harness testing
- protocol publication to `sdp/`
