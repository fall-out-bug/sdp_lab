# 00-150-05: Dependency diet and duplicate-code audit

Feature: F150 (Product Layering And Release Readiness)

Design reference: [2026-04-27-f150-product-layering-release-readiness-design.md](../../plans/2026-04-27-f150-product-layering-release-readiness-design.md)

## Goal

Reduce code and dependency weight only where the release surface inventory proves it is safe. File remaining cleanup as Beads instead of hiding debt in prose.

## Beads

- sdplab-hjl7 (F150-05: run dependency diet and duplicate-code audit)

## Scope Files

- `go.mod`
- `go.sum`
- `cmd/`
- `internal/`
- release inventory doc from 00-150-02
- new review report if needed under `docs/reviews/`

## Acceptance Criteria

- [ ] Direct dependencies are justified by at least one stable or operator-facing owner.
- [ ] Heavy indirect dependency chains are explained or reduced.
- [ ] Duplicate helper/code patterns are listed with fix/defer decisions.
- [ ] Any removal has tests or build evidence.
- [ ] Remaining non-trivial debt is filed as Beads with links to this workstream.

## Out of Scope

- Large architectural rewrites.
- Removing lab-only experiments solely to reduce counts.
- Refactoring without release-surface evidence.
