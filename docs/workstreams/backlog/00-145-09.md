# 00-145-09: profiles_default.json — tier-mapped seed (~40 entries)

Feature: F145 (Multi-Provider Dispatch Matrix & Confidence-Driven Cascade)

Design reference: [2026-04-26-f145-multi-provider-dispatch-cascade-design.md §4.4](../../plans/2026-04-26-f145-multi-provider-dispatch-cascade-design.md)

## Goal

Создать встроенный seed `profiles_default.json` на 5 провайдеров × подмножество моделей × 4 task-type'а с осмысленными prior'ами по tier-mapping таблице. Гарантия: ни один cold-start не получает all-zero scores.

## Scope Files

- `internal/dispatch/profiles_default.json` — new. ~40 entries: claude × {sonnet, opus, haiku} × {anthropic, zai}, codex × openai × {gpt-5-codex, o3, o3-mini, gpt-4o-mini}, cursor × cursor × {composer-2-fast, composer-2, gpt-5.3-codex, gpt-5.3-codex-xhigh, sonnet-4}, opencode × {ollama/qwen2.5-coder:7b, kimi/kimi-k2, zai/glm-4.7}. Каждый с `tier_class` и `capabilities` map.
- `internal/dispatch/profiles_default.go` — new. `//go:embed profiles_default.json` + `func DefaultProfiles() []*CapabilityProfile` для bootstrap.
- `internal/dispatch/profiles_default_test.go` — new. Tests: embed parses, ≥40 entries, все имеют валидный `tier_class`, не нулевые `capabilities`.
- `internal/dispatch/profiles_tiers.md` — new. Документация tier-mapping таблицы (как в design §4.4) + rationale prior'ов.

## Acceptance Criteria

- [ ] `profiles_default.json` валидный JSON, ≥40 entries.
- [ ] Каждый entry имеет: harness, provider, model, tier_class, capabilities (минимум `coding/Go: {test_pass_rate: X}`).
- [ ] `DefaultProfiles()` возвращает non-empty slice.
- [ ] Tier-distribution: ≥10 fast, ≥10 balanced, ≥6 strong, ≥3 local.
- [ ] Все references к существующим harness'ам/providers корректны (опечатки в `harness=clude` ловятся test'ами).
- [ ] go build, go test, go vet clean.

## Out of Scope

- Bench-driven prior'ы (только tier-default mapping).
- CLI tool для regen — отдельная WS в F146.
