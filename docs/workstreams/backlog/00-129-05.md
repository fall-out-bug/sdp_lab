# 00-129-05: CHANGELOG auto-generation in CI

Feature: F129 (Autonomous Operations & Regression Hardening)

## Goal

CI job generates a `CHANGELOG.md` entry from bd closed issues + commit messages on merge to `main`. Non-destructive: append-only, dedup by issue ID.

## Beads

- sdplab-8k5.5

## Scope Files

- `.github/workflows/changelog-autogen.yml` — new workflow (on push to `main`)
- `scripts/gen_changelog_entry.sh` — generation script
- `.changelog-template.md` — template

## Acceptance Criteria

- [ ] On push to `main`: extract bd issues closed in commits since the last tag, append to the `Unreleased` section of `CHANGELOG.md`
- [ ] Commits the CHANGELOG update with a `[skip ci]` marker
- [ ] Dedup: same bd ID not added twice
- [ ] Format: `- [bd-<id>] <title> (#<PR>)` when PR number is available

## Out of Scope

- Release tagging automation
- Semver bumping
- Release notes beyond the append

## Implementation Notes

Use `bd list --status=closed --since=<last-tag-date>` + `git log --format='%s %H'`. Skip if no closed issues in the range. Keep the script idempotent — safe to run twice in a row.
