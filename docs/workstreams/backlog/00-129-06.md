# 00-129-06: Markdown link auto-fix

Feature: F129 (Autonomous Operations & Regression Hardening)

## Goal

Within `--mode fix` (F129-04), specifically implement markdown link auto-repair for files moved via `git log --follow`. Handle trailing slash and anchor normalization.

## Beads

- sdplab-8k5.6

## Scope Files

- `internal/docsync/link_fix.go` — merged into the F129-04 PR; this WS tracks the link-specific test suite
- `internal/docsync/link_fix_test.go` — tests for moved file, anchor-only path, `../` relative paths, absolute repo paths

## Acceptance Criteria

- [ ] Test corpus covers: moved file (`src/foo.go` → `pkg/foo/foo.go`), broken relative link, stale anchor
- [ ] Auto-fix correctly rewrites after `git log` trace
- [ ] Does NOT touch links to external URLs (`http`/`https`)

## Out of Scope

- Non-markdown file links (yaml anchors, json refs)

## Implementation Notes

This WS may be consolidated into F129-04 at implementation time — keeping it separate for tracking clarity. Keep test fixtures small and deterministic (no network, no live git history beyond the fixture repo).
