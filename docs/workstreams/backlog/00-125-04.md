# 00-125-04: Migration Harness and Documentation Cutover

Feature: F125 (Toolkit UX — intent-routed skills over composable tools)

## Goal

Land the intent-model migration with compatibility checks, deprecation messaging, and documentation updates so old workflows do not silently break.

## Beads

- sdplab-pnpw

## Scope Files

- `skills/`
- `docs/reference/skills.md`
- `docs/reference/agent-catalog.md`
- `docs/reference/commands.md`
- `docs/happy-paths/new-feature.md`

## Acceptance Criteria

- [ ] compatibility tests or evals cover old-to-new routing for the major skill entry points
- [ ] deprecation warnings are explicit and actionable
- [ ] canonical docs point to intents first, not the legacy flat list
- [ ] migration guidance explains what changed and why
- [ ] rollout can happen without leaving two contradictory skill models in docs

## Out of Scope

- MCP server implementation
- toolkit CLI tool code
- public schema publication

## Implementation Notes

- Design source: `docs/plans/2026-04-13-sdp-skill-architecture-design.md`
