# 00-147-09: Bench harness `sdp-microfirst-bench` + report

Feature: F147 (MicroFirst Inference Tier)

Design reference: [2026-04-27-f147-microfirst-tier-design.md §3 F147-09](../../plans/2026-04-27-f147-microfirst-tier-design.md)

## Goal

End-to-end bench harness прогоняющий все 4 micro-classifier'а (WsVerdict, BdSeverity, BdType, RoutingColdStart) на корпусах (synthetic fixtures + replay из `.beads/issues.jsonl`) в двух режимах: micro-only и WithEscalation(micro, mock-llm). Output: per-classifier JSON evidence + aggregate markdown report со всеми требуемыми челленджем метриками.

## Beads

- sdplab-itzf (historical F147 anchor; leaf Beads were not preserved)

## Scope Files

- `cmd/sdp-microfirst-bench/main.go` — new. CLI entrypoint, flags `--classifier`, `--corpus`, `--mode`, `--output`.
- `cmd/sdp-microfirst-bench/runner.go` — new. Per-classifier eval loop, latency measurement, accuracy против ground truth.
- `cmd/sdp-microfirst-bench/mock_llm.go` — new. Stub LLM с фиксированной latency 800ms + token cost (для бенча).
- `cmd/sdp-microfirst-bench/report.go` — new. JSON serializer + markdown report generator.
- `internal/build/.sdp/evidence/f147/` — new directory. JSON output per classifier + aggregate report.md.
- `cmd/sdp-microfirst-bench/main_test.go` — new. Smoke test on tiny fixture corpus.

## Acceptance Criteria

- [ ] Bench запускает все 4 classifier'а; для каждого — оба режима (micro-only / micro+escalation-to-mock-llm).
- [ ] Per-classifier JSON content: `{total, micro_handled, escalated, fallback_rate, p50_ms, p95_ms, accuracy, llm_calls_saved, est_token_savings}`.
- [ ] Aggregate report.md содержит таблицу с этими метриками + summary.
- [ ] Aggregate `est_token_savings` ≥ 30% (требование exit criteria F147 epic'а).
- [ ] Aggregate accuracy не хуже llm-only baseline (no regression).
- [ ] ≥30 запросов на classifier (требование челленджа Day 10).
- [ ] Бенч runs hermetic — без live LLM/Ollama при `--mock` (default=true).
- [ ] Evidence коммитнут в `internal/build/.sdp/evidence/f147/`.
- [ ] Coverage harness ≥ 70% (CLI-tier).
- [ ] `go build ./...` and `go vet ./...` clean.

## Out of Scope

- Live LLM / live Ollama в CI (опасно для hermetic build; live mode — manual run).
- A/B production rollout dashboard (off-scope, follow-up если потребуется).
- Dashboard / web UI.
