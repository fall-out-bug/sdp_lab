## Implementation Notes

- From section 1.5: Go uses `go/packages` (native parser) with 90-95% import accuracy
- Strengths: static imports, module graph, interface detection
- Blind spots: build tags, CGo, dot imports, go generate output
- go/packages provides typed Package structs with Imports, Syntax, and TypesInfo — richer than regex
- Circular dep detection should use Tarjan's strongly connected components algorithm
- Package clustering heuristic: group packages by directory depth and shared internal/ prefix
- Interface detection: scan for `type Foo interface {}` declarations, then find types that satisfy them using go/types.Info
- Framework detection via import paths: github.com/gin-gonic/gin, github.com/labstack/echo, github.com/go-chi/chi, google.golang.org/grpc
- This is the highest-accuracy extractor due to Go's native tooling support
