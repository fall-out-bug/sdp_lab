# 00-F130-04: Harness adapter layer — rules file → harness-specific config files

Feature: F130 (AI Harness Config Auto-Provisioning)

## Goal

Transform the generated rules file into harness-specific formats. One source → N output files. Claude Code: inject as `## Language Patterns` section in CLAUDE.md. Cursor: generate `.cursorrules`. Codex CLI: generate `codex.yaml` rules block. OpenCode: generate `.opencode/rules.md`. Each adapter knows the format constraints of its target harness.

## Scope Files

- `internal/harnessadapter/adapter.go` (new — interface + implementations per harness)
- `internal/harnessadapter/adapter_test.go`
- `cmd/sdp-rulesgen/main.go` (add `--harness=cursor|claude|codex|opencode` flag)

## Acceptance Criteria

- [ ] Claude Code adapter generates CLAUDE.md section
- [ ] Cursor adapter generates .cursorrules
- [ ] Codex adapter generates codex.yaml rules block
- [ ] Existing content in target files is preserved (append/update, not overwrite)
- [ ] Adapters implement a common interface
