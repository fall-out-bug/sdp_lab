# 00-F130-04: CI integration — sdp-healthcheck as pre-push gate

Feature: F130 (Agent Code Quality Standards)

## Goal

Add sdp-healthcheck to scripts/hooks/pre-push (warn on failure, don't hard-block) and as a CI step in .github/workflows/ci.yml.

## Scope Files

- `scripts/hooks/pre-push` — new or update; warn on healthcheck failure
- `.github/workflows/ci.yml` — add healthcheck job
- `Makefile` — add healthcheck target

## Acceptance Criteria

- [ ] make healthcheck runs sdp-healthcheck
- [ ] pre-push hook warns on failure
- [ ] CI job runs healthcheck and uploads result as artifact
