# 00-106-01: LiveGateway — реализация ModelGateway для production LLM

Feature: F106 (agentloop Integration)

## Goal

Создать `internal/agentloop/gateway_live.go` — реализацию `agentloop.ModelGateway`, которая вызывает реальные LLM-провайдеры через существующий `modelgateway` пакет. Заменяет `StubGateway` в production path.

## Beads

- sdplab-c2gk

## Scope Files

- `internal/agentloop/gateway_live.go` — новый файл (создать)
- `internal/agentloop/gateway_live_test.go` — новый файл (создать)
- `internal/agentloop/gateway.go` — читать (не менять)
- `internal/agentloop/types.go` — читать интерфейс `ModelGateway` (не менять)
- `docs/MODEL_POLICY.md` — список allowed models

## Acceptance Criteria

- [ ] `LiveGateway` implements `agentloop.ModelGateway` interface: `Call(ctx, msgs, cfg) (<-chan Event, error)` и `IsAvailable(model string) bool`
- [ ] `IsAvailable` возвращает `true` для моделей из `MODEL_POLICY.md` allowlist, `false` для остальных (MVP: static check, без probe call)
- [ ] `Call` переводит `[]agentloop.Message` → HTTP request к provider, возвращает `chan Event` с `text_delta`, `tool_call`, `done` событиями
- [ ] При ответе провайдера с tool_calls: эмитится `tool_call` event с заполненным `ToolCalls []ToolCall` (ID, Name, Input)
- [ ] **ToolCall UUID**: если провайдер вернул пустой или отсутствующий `tool_call.id` — `LiveGateway` генерирует UUID (`uuid.NewString()`) перед эмиссией события
- [ ] **API key validation**: `NewLiveGateway(apiKey string) (*LiveGateway, error)` — возвращает `error` (не паника, не тихий fail) если `apiKey == ""`
- [ ] `go test ./internal/agentloop/ -run TestLiveGateway -race` PASS с `httptest.Server` вместо реального API
- [ ] `go build ./...` без ошибок
- [ ] `go vet ./...` чистый

## Implementation Notes

Интерфейс `ModelGateway` в `internal/agentloop/types.go`:
```go
type ModelGateway interface {
    Call(ctx context.Context, msgs []Message, cfg LoopConfig) (<-chan Event, error)
    IsAvailable(model string) bool
}
```

`LiveGateway` держит map[string]bool allowedModels из MODEL_POLICY.md (hardcoded для MVP).

Для `Call`: сделать один HTTP POST к OpenRouter API (endpoint: `https://openrouter.ai/api/v1/chat/completions`), получить JSON response, перевести в `chan Event`. API key передаётся в конструктор `NewLiveGateway(apiKey)`. Вызывающий (ServeBridge) делает `os.Getenv("OPENROUTER_API_KEY")` и передаёт в конструктор — `NewLiveGateway` не читает env самостоятельно.

**Сигнатура конструктора:**
```go
func NewLiveGateway(apiKey string) (*LiveGateway, error) {
    if apiKey == "" {
        return nil, errors.New("LiveGateway: OPENROUTER_API_KEY is required")
    }
    // ...
}
```

`agentloop.ToolCall`:
```go
type ToolCall struct {
    ID    string
    Name  string
    Input json.RawMessage
}
```

При non-streaming ответе с tool_calls: создать один `Event{Type: "tool_call", ToolCalls: [...]}`, затем `Event{Type: "done"}`.
При text response: `Event{Type: "text_delta", Delta: content}`, затем `Event{Type: "done"}`.

Тест: `httptest.NewServer` отдаёт JSON с tool_calls; assert что channel получает `tool_call` event с правильным `ToolCalls`.
