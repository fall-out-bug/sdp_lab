# 00-122-02: Query Surfaces — semantic, structural, navigational

Feature: F122 (Toolkit Index — persistent codebase memory)

## Goal

Ship the three query modes that make the index useful in practice: semantic lookup, dependency traversal, and exact symbol/path search.

## Beads

- sdplab-bi7k

## Scope Files

- `internal/index/search.go`
- `internal/index/pagerank.go`
- `internal/index/store.go`
- `internal/index/search_test.go`

## Acceptance Criteria

- [x] `sdp index query` returns relevant chunks with file path and line context
- [x] `sdp index deps` supports forward and reverse dependency traversal (edges may be empty until enricher populates them)
- [x] `sdp index find` supports exact identifier and keyword lookup
- [x] response shapes are stable enough for CLI, skills, and MCP consumers
- [x] search tests cover FTS, structural edges, and fused ranking behavior
