# 00-166-09: local chunked classifier implementation

Feature: F166 (sdplab-mp83)

## Goal

Implement the local OpenAI-compatible classifier layer specified by
`00-166-06`, after `00-166-08` has established the gateway surfaces it plugs
into. The classifier must chunk oversized prompts for small local context
windows, call a local classifier endpoint, parse strict structured JSON, reduce
chunk verdicts into one request verdict, preserve global byte spans, and emit
safe audit metadata.

## Ownership

This workstream owns classifier config, chunking, classifier client, structured
JSON parsing, reducer behavior, and audit fields. It must not implement Codex/Pi
HTTP surfaces; those belong to `00-166-08`. It may introduce
`internal/localmodel/` for the loopback OpenAI-compatible classifier client if
that keeps endpoint-client code out of the core scanner/redactor files. Do not
modify `internal/llmguard/gateway.go` or `internal/llmguard/types.go` without
explicitly coordinating with `00-166-08`.

## Acceptance Criteria

- [ ] Config accepts any loopback OpenAI-compatible classifier endpoint, model,
  timeout, total timeout, chunk size, overlap, max chunks, max parallel chunks,
  confidence threshold, and strict/demo mode.
- [ ] Non-loopback classifier URLs fail config validation at gateway startup
  unless an explicit future enterprise trust mode is added.
- [ ] Chunker preserves stable global byte offsets, structural splitting order,
  configured overlap, source message metadata, and deterministic chunk ids.
- [ ] Chunker generates synthetic boundary-window chunks for every adjacent
  normal-chunk pair using configured overlap bytes, assigns stable global
  offsets, and reducer completeness requires those boundary chunks.
- [ ] Fake local classifier endpoint receives one request per chunk with tools
  disabled and the chunk wrapped as untrusted data.
- [ ] Classifier parser accepts only the documented JSON schema and known enum
  values; malformed JSON/tool-call-shaped output follows `classifier_incomplete`
  policy.
- [ ] Reducer escalates block over redact over needs_review over allow, merges
  and bounds-checks spans, and cannot weaken deterministic high-severity blocks.
- [ ] Timeout/error behavior matches spec: strict mode fails closed before
  upstream egress; demo mode may continue deterministic-only only when the
  deterministic scanner found no high-severity finding.
- [ ] Audit records classifier enabled/completeness, model/endpoint kind, chunk
  count, failed chunk ids, reducer verdict, and no raw prompt chunks or secrets.
- [ ] Tests cover fake local endpoint calls, multi-chunk prompts, boundary
  overlap, global span preservation, reducer escalation, timeout/error paths,
  and malformed classifier JSON.

## Out of Scope

- Live local model tests in CI.
- Streaming classifier calls.
- Replacing deterministic scanner or redactor.
- Codex/Pi HTTP surface implementation; see `00-166-08`.
