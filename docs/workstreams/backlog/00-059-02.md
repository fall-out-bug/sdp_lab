# 00-059-02: Session evidence emitter

Feature: F059 (Ecosystem Synergies)

## Goal

Emit typed evidence events for every tool call during an OhMyOpenCode session. Events append to `.sdp/log/session.jsonl` with hash chain for tamper detection.

## Beads

- sdplab-2: F059-02 Session evidence emitter
## Scope Files

- `cmd/sdp-omc-emitter/` (new)
- `internal/evidence/session.go` (new)
- `internal/evidence/hashchain.go` (extend)

## Acceptance Criteria

- [x] Every tool call emits event: `{timestamp, tool, args, result_hash, prev_hash}`
- [x] Events append to `.sdp/log/session-{id}.jsonl`
- [x] Hash chain links each event to previous (SHA-256)
- [x] Session finalize computes root hash → evidence envelope
- [x] Configurable log level via `opencode.json` → `sdp.evidence.level`
