# 00-060-02: Hook → Guard scope bridge

Feature: F060 (Gas Town Adapter)

## Goal

Bridge Gas Town worktree hooks to SDP guard scope files. When Gas Town creates a worktree for a task, the scope file is written to `.sdp/guard-scope.json` in that worktree.

## Beads

- sdplab-5: F060-02 Hook-Guard scope bridge
## Scope Files

- `cmd/gt-adapter/hook_bridge.go` (new)
- `internal/guard/scope_file.go` (extend)

## Acceptance Criteria

- [ ] Gas Town worktree hook calls `sdp gt scope <task-json>`
- [ ] Scope file written to worktree `.sdp/guard-scope.json`
- [ ] Scope persists across agent crashes (worktree survives)
- [ ] Scope format: `{allowed_paths, allowed_commands, denied_patterns}`
- [ ] Integration test: worktree → scope → guard enforcement
