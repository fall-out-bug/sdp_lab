# 00-060-02: Hook → Guard scope bridge

Feature: F060 (Gas Town Adapter)

## Goal

Bridge Gas Town worktree hooks to SDP guard scope files. When Gas Town creates a worktree for a task, the scope file is written to `.sdp/guard-scope.json` in that worktree.

## Beads

- sdplab-5: F060-02 Hook-Guard scope bridge
## Scope Files

- `cmd/gt-adapter/main.go` (extended)
- `internal/guard/scope_file.go` (new)

## Acceptance Criteria

- [x] Scope file written to worktree `.sdp/guard-scope.json`
- [x] Scope persists across agent crashes (worktree survives)

- [ ] Integration test: worktree → scope → guard enforcement
