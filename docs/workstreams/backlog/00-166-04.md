# 00-166-04: thin HTTP demo proxy with rate limit

Feature: F166 (sdplab-mp83)

## Goal

Add a thin `cmd/sdp-llm-gateway` demo command over `llmguard` to satisfy the
day-13 proxy artifact without turning SDP into a generic provider gateway.

## Beads

- sdplab-w8v7

## Scope Files

- `cmd/sdp-llm-gateway/` (new command)
- `internal/llmguard/`
- `docs/plans/2026-05-03-f166-runtime-llm-guard-gateway-design.md`

## Acceptance Criteria

- [ ] Command exposes a minimal HTTP endpoint that accepts a chat-like JSON request and returns guarded JSON response/warning.
- [ ] Request/response JSON follows the simplified demo schema in the F166 design, not raw OpenAI/Anthropic provider API shapes.
- [ ] Demo uses `llmguard` core; it does not duplicate scanner/redactor logic.
- [ ] Per-IP in-memory rate limiting rejects requests above configured requests-per-minute.
- [ ] CI tests use `httptest` and fake providers only; no live OpenAI/Anthropic/OpenRouter calls.
- [ ] Audit output is JSONL and redacted.
- [ ] Demo docs state it is an acceptance/demo surface, not the production SDP model gateway.

## Out of Scope

- Multi-tenant production auth.
- Provider routing UI.
- Persistent rate-limit storage.
- Live-provider integration tests in normal CI.
