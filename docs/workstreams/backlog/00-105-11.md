## Acceptance Criteria

### Security Pipeline Binding
- [ ] SecureEnricher interface enforces: ScrubSecrets(input) -> SanitizeForLLM -> WrapForLLM -> API call
- [ ] Output pipeline: API response -> ScrubSecrets(output, JSON-aware) -> JSON parse -> SanitizeOutput(field-level)
- [ ] Per-request isolation: fresh crypto/rand delimiter, no shared state between goroutines
- [ ] LLMEnrichment stored in `map[string]LLMEnrichment` (sanitized HTML)

### LLM Client
- [ ] Pluggable provider interface: local models (Ollama/LM Studio), OpenAI, Anthropic
- [ ] No tool use / function calling parameters in ChatRequest
- [ ] No outbound HTTP from LLM generated content
- [ ] http field unexported

### Prompt Templates
- [ ] ArchitectureHypothesizer: scored style hypotheses across 8 ArchStyle types with confidence intervals
- [ ] PatternDetector: architectural patterns with evidence citations from CodebaseProfile
- [ ] RiskAssessor: architectural risks and debt indicators
- [ ] System prompt includes untrusted-content instruction for delimited code

### Output Parsing
- [ ] LLM output: JSON only (no markdown code blocks)
- [ ] Parser strips leading/trailing markdown fences defensively
- [ ] Rejects non-JSON responses
- [ ] Parsed into structured Go types (StyleHypothesis, PatternFinding, RiskFinding)

### Token Budget + Cost
- [ ] Tier 1 (~2K), Tier 2 (~5-15K per container), Tier 3 (~10-30K per component)
- [ ] Cost tracking: input/output tokens, model used, estimated cost per call
- [ ] Audit logging: sanitized input hash, timestamp, token count

### Error Recovery (from resilience.go in WS-01)
- [ ] Uses RetryConfig: 3 retries, 1s/2s/4s backoff with jitter
- [ ] Uses CircuitBreaker: per-provider, 5 failures -> 30s cooldown
- [ ] Returns EnrichmentResult with partial recovery per node

## Out of Scope

- Fine-tuning or training custom models
- Streaming LLM responses (batch only for MVP)
- RAG-based context retrieval
- Multi-model consensus at runtime

## Implementation Notes

- This workstream wires the security functions from WS-01 into the LLM pipeline
- The SecureEnricher interface is the binding contract — skipping any security step is a build-time error
- All LLMEnrichment fields store sanitized HTML (persistence format contract from security spec)
- Local LLM is default path; cloud providers require explicit AllowExternalLLM flag
- Low-confidence hypotheses explicitly marked "requires human validation"
