# 00-164-04: Live PI eval runner

Feature: F164 (sdplab-9wxx)

## Goal

Add an advisory live-provider prompt-injection eval runner that rotates GLM, Kimi, and MiniMax and records evidence without making normal PR CI depend on live providers.

## Beads

- sdplab-9wxx.4

## Scope Files

- `cmd/sdp-pi-eval/main.go`
- `cmd/sdp-pi-eval/main_test.go`
- `internal/evals/pi_live.go`
- `internal/evals/pi_live_test.go`
- `internal/pireview/evidence.go`
- `internal/pireview/evidence_test.go`
- `schema/pi-review-run.schema.json`
- `docs/security/f164-prompt-injection-test-cases.md`

## Dependencies

- 00-164-02
- 00-164-03

## Acceptance Criteria

- [ ] Runner supports provider rotation for `zai/glm-5.1`, `kimi-coding/k2p6`, and `minimax/MiniMax-M2.7`.
- [ ] Runner executes model calls with no tool access; if using `pi`, it passes `--no-tools --no-context-files --no-session`.
- [ ] Provider failure is recorded as evidence degradation, not PASS.
- [ ] Output records raw artifact hashes, verdicts, provider failures, and advisory status.
- [ ] Live evals are documented as advisory/manual/scheduled, not required blocking PR CI.
- [ ] `go test ./internal/evals ./cmd/sdp-pi-eval` passes without live provider credentials by using mocks.

## Out of Scope

- Requiring provider availability in normal CI.
- Proving any base model cannot be jailbroken.
