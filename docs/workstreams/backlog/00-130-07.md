# 00-130-07: Brownfield Mode — OpenSpec-inspired Delta Analysis

Feature: F130 (sdplab-9nb)

## Goal

Delta analysis over observed behavior for existing projects. Compare scout output against existing rules, emit only changed/added/removed markers.

## Beads

- sdplab-c08

## Scope Files

- `internal/bootstrap/brownfield.go` — new: delta analysis engine
- `internal/bootstrap/brownfield_test.go` — new: tests
- `internal/bootstrap/delta.go` — new: delta types and comparison

## Acceptance Criteria

- [ ] Reads existing AGENTS.md/CLAUDE.md and compares with fresh scout output
- [ ] Emits delta markers: ADDED/MODIFIED/REMOVED per section (OpenSpec-style)
- [ ] Delta report written to `.sdp/bootstrap-delta.json`
- [ ] Human review required before applying deltas (F130-09 contract)
- [ ] Unit tests: known changes produce correct delta markers

## Out of Scope

- Greenfield mode (F130-06)
- Auto-apply deltas (forbidden by F130-09)

## Implementation Notes

- Parse existing rules files into structured form
- Compare field-by-field with scout.Report + Conventions
- Delta format: {Section, ChangeType, Old, New, Evidence}
