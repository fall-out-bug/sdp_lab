## Acceptance Criteria

- [ ] Static/mock checks are available through an explicit command suitable for CI.
- [ ] Live-provider evals are excluded from blocking PR CI by default.
- [ ] CI/report output distinguishes blocking static/mock failures from advisory live-provider findings.
- [ ] Advisory-to-blocking transition requires a decision record and baseline trend evidence.
- [ ] Documentation tells maintainers what to do when advisory PI findings appear.
- [ ] Supply-chain prompt bundle checks from `PI-013` in `docs/security/f164-prompt-injection-test-cases.md` are included in static/advisory reporting.
- [ ] CI integration can proceed without live-provider credentials; live eval is skipped or marked advisory-degraded.

## Out of Scope

- Making live-provider availability a normal PR gate.
- Automatically reverting successful injections.
