# 00-126-01: MCP Server Skeleton and Tool Wrappers

Feature: F126 (Toolkit MCP — universal agent interface)

## Goal

Create the MCP server shell and wrap the core toolkit commands as MCP tools so the local CLI contracts become reusable across harnesses.

## Beads

- sdplab-dpl9

## Scope Files

- `cmd/sdp-mcp/main.go`
- `internal/mcp/server.go`
- `internal/mcp/tools.go`
- `internal/mcp/server_test.go`
- `internal/mcp/tools_test.go`

## Acceptance Criteria

- [ ] `sdp-mcp` starts as a stdio MCP server
- [ ] scout, architect, metrics, spec, index, and bootstrap are exposed as MCP tools
- [ ] tool handlers wrap stable CLI contracts instead of re-implementing business logic
- [ ] tool errors are translated into MCP-friendly output
- [ ] server and tool tests cover the basic happy path and failure path

## Out of Scope

- MCP resources
- MCP prompts
- harness-specific packaging

## Implementation Notes

- Design source: `docs/plans/2026-04-13-sdp-mcp-design.md`
- Plan source: `docs/plans/2026-04-13-sdp-mcp-implementation-plan.md`
- If a tool contract is unstable, fix the CLI first. Do not paper over it in the MCP layer.
