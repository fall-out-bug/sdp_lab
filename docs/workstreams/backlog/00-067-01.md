# 00-067-01: Discrepancy Detection

Feature: F067 (Auto-Attestation - Discrepancy Detection)

## Goal

Compare agent-generated attestation with CI-generated attestation. Detect discrepancies and flag as audit findings.

## Beads

- sdplab-2n7: F067-01 Discrepancy detection

## Scope Files

- `internal/evidence/discrepancy.go` (new)
- `internal/evidence/discrepancy_test.go` (new)

## Acceptance Criteria

- [x] Load agent attestation from `.sdp/evidence/run-*.json`
- [x] Load CI attestation from `.sdp/evidence/ci-auto-*.json`
- [x] Compare key fields: changed_files, test_results, coverage
- [x] Generate discrepancy report
- [x] Flag as audit finding if discrepancy detected
- [x] CI job runs comparison on PR merge
## Discrepancy Types

1. **File scope drift**: Agent claims different files than CI observed
2. **Test result mismatch**: Agent claims tests pass, CI shows failures
3. **Coverage mismatch**: Significant coverage difference
4. **Missing attestation**: Agent attestation not found
