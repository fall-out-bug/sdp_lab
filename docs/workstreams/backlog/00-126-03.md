# 00-126-03: Harness Configs and Packaging

Feature: F126 (Toolkit MCP — universal agent interface)

## Goal

Ship the reference configs and installation surface so supported harnesses can enable SDP toolkit capabilities without bespoke setup work.

## Beads

- sdplab-y2vd

## Scope Files

- `configs/mcp/claude-code.json`
- `configs/mcp/cursor.json`
- `configs/mcp/vscode.json`
- `configs/mcp/opencode.json`
- `docs/reference/installation.md`
- `cmd/sdp-mcp/main.go`

## Acceptance Criteria

- [ ] reference config exists for each supported harness named in the design
- [ ] install docs show how to point each harness at `sdp-mcp`
- [ ] config examples align with the actual tool and resource names from the server
- [ ] packaging guidance is explicit about local repo path expectations
- [ ] docs avoid implying support for harnesses not actually tested

## Out of Scope

- tool or prompt implementation
- cross-harness e2e validation
- public website docs

- Design source: `docs/plans/2026-04-13-sdp-mcp-design.md`
- Plan source: `docs/plans/2026-04-13-sdp-mcp-implementation-plan.md`
- Packaging is part of UX. If setup is vague, the server is effectively not shipped.
