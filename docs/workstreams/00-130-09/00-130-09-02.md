# 00-130-09-02: Pre-commit DRAFT guard

Feature: F130 (AI Harness Config Auto-Provisioning)

## Goal

Add DRAFT file rejection to the pre-commit hook generated by bootstrap. The hook must refuse any commit that includes files starting with `DRAFT-`.

## Beads

- sdplab-4xs

## Scope Files

- `internal/bootstrap/templates/pre_commit.tmpl` — add DRAFT file check block
- `internal/bootstrap/hooks.go` — ensure DRAFT check is always included in generated pre-commit
- `internal/bootstrap/hooks_test.go` — test DRAFT rejection behavior

## Acceptance Criteria

- [ ] Generated pre-commit hook contains a block that checks staged files for `DRAFT-*` pattern
- [ ] If DRAFT files are staged, hook prints clear error message with instructions (rename the file to remove DRAFT- prefix)
- [ ] Hook exits non-zero when DRAFT files detected
- [ ] Hook passes (exit 0) when no DRAFT files staged
- [ ] Unit test validates generated hook script contains DRAFT guard

## Out of Scope

- Doctor check (WS-03)
- CI flags (WS-04)

## Implementation Notes

The DRAFT check should come BEFORE other checks in the pre-commit hook (fail fast). Pattern: `git diff --cached --name-only | grep -q '^DRAFT-'` — simple, no dependencies.
