# 00-130-09-04: CI automation flags (--yes, --auto-curate)

Feature: F130 (AI Harness Config Auto-Provisioning)

## Goal

Add `--yes` and `--auto-curate` flags to `sdp bootstrap` that bypass the DRAFT prefix requirement for CI automation. When enabled, bootstrap writes files WITHOUT DRAFT- prefix and without TODO markers.

## Beads

- sdplab-4xs

## Scope Files

- `cmd/sdp/cmd_bootstrap.go` — add `--yes` and `--auto-curate` flags
- `internal/bootstrap/types.go` — add `AutoCurate` field to `BootstrapConfig`
- `internal/bootstrap/bootstrap.go` — respect `AutoCurate` flag to skip DRAFT prefix
- `internal/bootstrap/bootstrap_test.go` — test auto-curate path produces clean files

## Acceptance Criteria

- [ ] `sdp bootstrap --yes --auto-curate` writes files WITHOUT DRAFT- prefix and WITHOUT TODO markers
- [ ] Flag is NOT the default — standard `sdp bootstrap` still uses DRAFT prefix
- [ ] Help text clearly documents these flags are for CI automation only
- [ ] Unit test: verify auto-curate produces identical output to non-DRAFT path
- [ ] Unit test: verify default (no flags) still produces DRAFT files

## Out of Scope

- Pre-commit hook changes (WS-02)
- Doctor check changes (WS-03)

## Implementation Notes

`AutoCurate` field on `BootstrapConfig` — when `true`, set `UseDraft=false`. Single boolean controls both prefix and TODO markers. The `--yes` flag also auto-confirms any interactive prompts (standard CLI pattern).
