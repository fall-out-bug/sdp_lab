# 00-130-09-03: Doctor DRAFT check

Feature: F130 (AI Harness Config Auto-Provisioning)

## Goal

Add a check to `sdp doctor` that detects DRAFT- prefixed files in the project root and reports them as "bootstrap incomplete" (informational severity, not error).

## Beads

- sdplab-4xs

## Scope Files

- `internal/control/doctor.go` — add `checkDraftFiles()` function
- `internal/cli/control_tower_doctor.go` — render DRAFT check result in doctor output
- `internal/control/doctor_test.go` — test DRAFT file detection

## Acceptance Criteria

- [ ] `sdp doctor` detects any files matching `DRAFT-*` in project root
- [ ] Reports as `INFO` severity (not error, not warning): "bootstrap incomplete — N DRAFT file(s) require curation"
- [ ] Lists each DRAFT file found with path
- [ ] When no DRAFT files: check passes silently (no noise)
- [ ] Unit test with temp directory containing DRAFT- files and clean directory

## Out of Scope

- Auto-curation (human decision)
- CI flag bypass (WS-04)

## Implementation Notes

Use `filepath.Glob("DRAFT-*")` on project root — simplest approach. Follow existing check pattern: return `DoctorCheck` with CheckID, Severity, Message.
