### Phases 8-12: Workstreams Auto-Generated

Starting Phase 8, most workstream files are generated by `@feature` when a feature is picked up for development. Exception: trust-readiness features F078-F081 are pre-materialized for immediate execution.

---

## Workstream ID Format

`PP-FFF-SS` — Project (00), Feature (001–999), Step (01, 02, …)

Example: `00-028-01` = sdp_lab, F028 CI Cleanup, step 1
Example: `00-014-01` = sdp_lab, F014 CI Loop CLI, step 1 (poll + classify)

### Frontmatter: `repo` (optional)

When scope touches `sdp/` submodule, add `repo: sdp` so agent uses sdp commit workflow. Default: sdp_lab. Historical feature and bead IDs may still use `sdp_dev-*` as legacy labels for the same repo.

| repo | When |
|------|------|
| sdp_lab | (default) Scope in root, internal/, cmd/, docs/ |
| sdp | Scope under sdp/ — commit in sdp first, then update submodule |
| mixed | Scope in both — explicit two-step commit |
