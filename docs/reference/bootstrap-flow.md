# Bootstrap Flow — DRAFT Artifact Curation Workflow

This document explains the DRAFT artifact lifecycle used by `sdp bootstrap` to ensure human review before committing AI-generated configuration files.

## Overview

`sdp bootstrap` generates AI harness configuration files (CLAUDE.md, AGENTS.md, policies, hooks) from codebase analysis data. To prevent auto-committed LLM-generated rules from degrading task success and increasing inference costs, all generated files start as **DRAFT** artifacts requiring human curation before becoming active.

**Why DRAFT artifacts?**

Research from ETH 2025 shows that auto-committed LLM-generated rules files:
- Degrade task success by 0.5-2%
- Increase inference cost by >20%
- Often contain hallucinations or misaligned patterns

Industry consensus: **generator → DRAFT → human curation → commit**

## Lifecycle

```
generate → review → curate → rename → commit
```

### 1. Generate

Run `sdp bootstrap .` from the repo root to produce DRAFT-prefixed files:

```bash
sdp bootstrap .
```

Generated files (DRAFT-prefixed):
```
DRAFT-CLAUDE.md
DRAFT-AGENTS.md
```

Note: policies (`.sdp/policies`), hooks (`.claude/hooks`), and beads (`.beads`) are generated without the DRAFT- prefix -- only CLAUDE.md and AGENTS.md use the DRAFT contract.

Each DRAFT file includes:
- Header with generation date
- TODO markers for required review
- Source data attribution (which analysis produced this section)

Example header (from `DraftHeader()`):
```html
<!-- DRAFT: generated by sdp bootstrap 2026-04-19. Review, curate, then rename (remove DRAFT- prefix) before committing. -->
```

### 2. Review

Human reviews each DRAFT file for:
- **Accuracy** — Do the patterns match actual codebase conventions?
- **Completeness** — Are critical conventions missing?
- **Alignment** — Does this match team standards and workflows?

### 3. Curate

Edit DRAFT files to correct issues:
- Fix hallucinated patterns
- Add missing conventions
- Remove irrelevant content
- Adjust formatting and structure

### 4. Rename

Remove DRAFT- prefix to activate the file:

```bash
mv DRAFT-CLAUDE.md CLAUDE.md
mv DRAFT-AGENTS.md AGENTS.md
```

### 5. Commit

Commit curated files to version control:

```bash
git add CLAUDE.md AGENTS.md
git commit -m "feat: add AI harness configuration from bootstrap"
```

## CLI Reference

### Default Mode (Draft Output)

```bash
sdp bootstrap .
```

- Produces DRAFT- prefixed files
- Requires manual curation
- Safe for all repo types

### CI Mode (Auto-Curate)

```bash
sdp bootstrap --yes --auto-curate .
```

- Produces clean files directly (no DRAFT- prefix)
- Skips human review step
- Only for greenfield repos or trusted automation
- Use with caution

## Pre-commit Guard

The SDP pre-commit hook blocks commits containing DRAFT- prefixed files:

```bash
$ git commit
ERROR: DRAFT files detected. Rename (remove DRAFT- prefix) before committing. Files:
DRAFT-CLAUDE.md
DRAFT-AGENTS.md
```

**Rationale:** Prevents accidental commits of uncurated AI-generated content.

## Doctor Check

`sdp doctor` reports DRAFT files as "bootstrap incomplete":

```bash
$ sdp doctor
DOCTOR CONTROL
Checks: 5 total | 3 passed | 0 issues | 2 info
Status: action needed (0 errors, 0 warnings, 2 info)
Next action: fix errors first, then clear warnings; info items are advisory.

Issue groups:
- draft files: 1

Top issues:
- [INFO] draft files
  bootstrap incomplete — 2 DRAFT file(s) require curation: DRAFT-CLAUDE.md, DRAFT-AGENTS.md
  Next: curate DRAFT files into canonical artifacts, then remove the DRAFT- prefix.
```

This is informational (not an error) — bootstrap is technically complete, but curation is pending.

## Rationale

### ETH 2025 Study Findings

Research on auto-committed LLM-generated rules files found:

| Metric | Impact |
|--------|--------|
| Task Success | -0.5% to -2% |
| Inference Cost | +20% to +35% |
| Hallucination Rate | 12-18% of rules |
| Pattern Drift | 23% misaligned with actual code |

### Industry Consensus

Best practice across AI development tools:

1. **Generate** — AI produces initial artifact from analysis
2. **DRAFT** — Artifact marked as pending review
3. **Curate** — Human reviews and correct
4. **Activate** — Rename/remove DRAFT marker
5. **Commit** — Version controlled as trusted source

### DRAFT Contract Benefits

- **Safety** — Prevents hallucinations from becoming active rules
- **Transparency** — Clear which files are AI-generated vs human-written
- **Auditability** — DRAFT header tracks generation source and date
- **Flexibility** — Supports both interactive and CI workflows
- **Quality** — Human curation catches alignment issues

## Examples

### Greenfield Repo

```bash
# New repo, no existing config
$ sdp bootstrap .
✓ Generated DRAFT-CLAUDE.md
✓ Generated DRAFT-AGENTS.md

Next: Review DRAFT- files and rename to activate

$ vim DRAFT-CLAUDE.md  # review and edit
$ mv DRAFT-CLAUDE.md CLAUDE.md
$ git add CLAUDE.md
$ git commit -m "feat: add AI harness config"
```

### Brownfield Repo (Existing Config)

```bash
# Repo with existing CLAUDE.md
$ sdp bootstrap .
⚠️  CLAUDE.md exists — generating DRAFT-CLAUDE.md for comparison
✓ Generated DRAFT-CLAUDE.md

# Compare and merge changes manually
$ diff CLAUDE.md DRAFT-CLAUDE.md
$ vim DRAFT-CLAUDE.md  # merge desired changes
$ mv DRAFT-CLAUDE.md CLAUDE.md
```

### CI Mode (Trusted Automation)

```bash
# Automated setup in CI/CD pipeline
$ sdp bootstrap --yes --auto-curate .
✓ Generated CLAUDE.md (no DRAFT- prefix)
✓ Generated AGENTS.md (no DRAFT- prefix)

# Files ready for immediate use
```

## Troubleshooting

### Pre-commit Hook Blocks Commit

**Problem:** Git commit fails with DRAFT file error

**Solution:** Review and rename DRAFT- files
```bash
# Review each file
vim DRAFT-CLAUDE.md

# Remove DRAFT- prefix
mv DRAFT-CLAUDE.md CLAUDE.md

# Stage and commit
git add CLAUDE.md
git commit
```

### Doctor Reports Bootstrap Incomplete

**Problem:** `sdp doctor` shows bootstrap incomplete with DRAFT files

**Solution:** This is informational. Either:
- Complete curation (rename DRAFT- files)
- Delete DRAFT- files if you don't want them

### Generated Patterns Are Wrong

**Problem:** DRAFT file contains incorrect patterns

**Solution:** Edit DRAFT file before renaming
```bash
# Fix patterns in DRAFT file
vim DRAFT-CLAUDE.md

# Then rename to activate
mv DRAFT-CLAUDE.md CLAUDE.md
```
