# Release Surface Checklist

> F078-03: Release surface manifest alignment

## Overview

The release surface is the set of files, URLs, and metadata that must be consistent when publishing a release. This document defines the surface and provides a checklist for release validation.

## Release Surface Registry

### Manifest → Release Artifact Mapping

| Manifest Field | Release Artifact | Validation |
|---------------|-----------------|------------|
| `version` | GoReleaser tag version (`v{{.Version}}`) | Tag must match `version` in `sdp.manifest.yaml` |
| `version` | Binary ldflags (`-X main.version={{.Version}}`) | Auto-synced by GoReleaser |
| `version` | Archive name template (`sdp-evidence_{{.Version}}_...`) | Auto-synced by GoReleaser |
| `version` | Checksum filename (`checksums.txt`) | Generated by GoReleaser |
| `sdp_version` | Must equal `version` | `scripts/check-version-drift.sh` |

### Binaries

| Binary | Main Path | OS/Arch |
|--------|-----------|---------|
| sdp-evidence | `./cmd/sdp-evidence` | linux/amd64, linux/arm64, darwin/amd64, darwin/arm64, windows/amd64 |
| sdp-guard | `./cmd/sdp-guard` | linux/amd64, linux/arm64, darwin/amd64, darwin/arm64 |

### Signatures

All release checksums are signed with Sigstore (keyless cosign). The signature bundle is published alongside `checksums.txt`.

## Pre-Release Checklist

Before tagging a release:

- [ ] Run `scripts/check-version-drift.sh` — zero drifts
- [ ] Run `scripts/check-public-metadata.sh` — zero stale references
- [ ] Run `scripts/check-release-surface.sh` — manifest consistent
- [ ] Run `./scripts/run_go_quality_gates.sh` — all gates green
- [ ] Verify CHANGELOG entries are present for this version
- [ ] Confirm `sdp.manifest.yaml` version matches the tag being created

## Post-Release Verification

After GoReleaser completes:

- [ ] All binaries are present in the GitHub Release
- [ ] `checksums.txt` is present and signed
- [ ] Download URLs work (test one binary)
- [ ] Homepage/repository URLs in manifest resolve correctly

## Local Reproduce

```bash
# Validate release surface consistency (no tag needed)
scripts/check-release-surface.sh

# Validate with a specific tag version
VERSION=v1.0.0 scripts/check-release-surface.sh
```
