# Discovery Frame

**Raw idea:** память агентов по проекту и глобально: дистилляция из диалогов, поиск похожих кейсов, сжатие и гидрация контекста в AI workspace для консультантов

## Problem Statement

Consultants using AI workspaces struggle to efficiently leverage past project knowledge and conversations. They lack a systematic way to distill insights from dialogues, find similar historical cases, and dynamically compress or rehydrate context, leading to redundant work, missed connections, and slower, less informed decision-making.

## Jobs to Be Done

- Consultants need to automatically extract and store key insights from project dialogues to build a persistent, searchable knowledge base.
- Consultants need to quickly find similar past cases or conversations within a project or across all projects to inform current strategies and avoid reinventing solutions.
- Consultants need to intelligently compress long conversation histories into concise summaries and then rehydrate (expand) specific details on-demand to manage cognitive load and context switching within their AI workspace.

**Appetite:** medium

**Scope:** A feature within an AI workspace for consultants that provides automated distillation of key points from text-based dialogues, semantic search across project and global conversation history, and tools for context summarization and detailed recall.
