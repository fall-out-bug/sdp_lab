# Discovery Frame

**Raw idea:** улучшить продуктовый вижн агентов Faust Consulting: коммуникация между агентами, выбор моделей, режимы работы агентов

## Problem Statement

Faust Consulting's product vision for AI agents is hindered by inefficient inter-agent communication, suboptimal model selection for specific tasks, and inflexible operational modes, reducing overall agent effectiveness and team productivity.

## Jobs to Be Done

- Product Manager defines clear communication protocols between agents to ensure seamless data exchange and task handoff
- ML Engineer selects and integrates appropriate AI models for each agent's role to optimize performance and cost
- System Architect configures flexible operational modes (e.g., autonomous, collaborative, human-in-the-loop) to adapt to varying client needs

**Appetite:** medium

**Scope:** Internal tooling and configuration framework for Faust Consulting's AI agent system, excluding client-facing UI development or fundamental agent re-architecture.
