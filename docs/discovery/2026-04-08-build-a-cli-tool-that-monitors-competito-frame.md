# Discovery Frame

**Raw idea:** build a CLI tool that monitors competitor pricing in real time

## Problem Statement

Product teams lack real-time visibility into competitor pricing changes, leading to delayed strategic responses and missed opportunities in dynamic markets.

## Jobs to Be Done

- A product manager needs to monitor competitor pricing to adjust their own pricing strategy promptly.
- A pricing analyst needs to automate data collection to reduce manual research time and improve accuracy.
- A marketing strategist needs to identify pricing trends to craft timely promotional campaigns.

**Appetite:** small

**Scope:** A CLI tool that scrapes and displays competitor pricing data from specified sources in real time.
