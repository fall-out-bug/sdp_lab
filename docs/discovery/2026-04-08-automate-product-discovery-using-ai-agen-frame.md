# Discovery Frame

**Raw idea:** automate product discovery using AI agents

## Problem Statement

Product teams struggle to efficiently and consistently conduct user research, synthesize insights, and generate validated product ideas, leading to slow, biased, or misaligned discovery processes.

## Jobs to Be Done

- Product managers need to systematically identify and prioritize user problems to build the right solutions.
- Researchers need to scale qualitative and quantitative data collection and analysis to uncover deeper insights.
- Designers need to rapidly prototype and test concepts with users to validate assumptions and reduce risk.

**Appetite:** medium

**Scope:** An AI system that automates core discovery tasks: conducting user interviews via chat, analyzing feedback to surface patterns, generating problem hypotheses, and facilitating prioritization workshops.
