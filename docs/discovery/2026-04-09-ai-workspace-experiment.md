# Discovery Experiment Brief

## Format: wizard_of_oz

**Objective:** Validate whether consultants will trust and use a manually operated AI workspace feature that extracts insights from past project conversations, finds similar cases, and rehydrates context on demand.

**Hypothesis:** if we offer 10–15 target consultants a concierge version of the workflow using their past project data, then at least 40% will use it in a real working session and at least 30% will request a second use within 7 days

**Success metric:** 40% of participants complete one real task using the service and 30% return for a second request within 7 days

**Time box:** 7 days

**Testing claim:** Consultants would use a searchable knowledge base if it contained high-quality, structured insights from past projects

## Setup Steps

1. Recruit 10–15 consultants from 3–5 firms who actively work in AI-enabled workspaces and regularly reuse project knowledge.
2. Ask each participant to provide 1–3 recent project conversations or exports under their firm's approved sharing policy; if they cannot share raw data, use redacted transcripts or a synthetic but domain-matched sample to test workflow trust and utility.
3. Manually produce three outputs for each participant: a structured insight summary, 3–5 similar historical cases, and an expandable context brief; deliver them through a simple shared doc or messaging thread and observe whether they use them in a real task.
4. Track whether they open the output, apply it to a live decision or deliverable, and ask for a follow-up expansion or second run within the week.
5. Conduct a 10-minute debrief after each use to capture trust objections, missing structure, and what would need to exist for regular adoption.

## Required Tools

- Google Docs or Notion
- Slack or email
- Calendar
- Spreadsheet for tracking
- Manual analyst time
